# 데스크톱 오브 수동 점검

릴리스 빌드에서 아래 항목을 순서대로 확인한다.

1. 설정에서 어시스턴트 모드를 **데스크톱 오브**로 바꾸면 오브와 트레이 아이콘이 나타난다.
2. 트레이 메뉴의 **데스크톱 오브** 토글을 끄고 켤 때 설정, 오브, 트레이 상태가 함께 바뀐다.
3. 오브를 다른 위치로 끌고 앱을 다시 실행하면 같은 디스플레이의 유효 영역 안에서 위치가 복원된다.
4. 오브를 눌러 팝업을 열고 닫을 수 있고, 바깥으로 숨겼다가 다시 열어도 마지막 크기와 위치가 복원된다.
5. 팝업에서 과목을 고르고 질문을 보내면 데스크톱 대화가 열리며, 같은 과목에서 대화 ID가 유지된다.
6. 팝업의 **앱에서 열기**를 누르면 메인 창이 열리고 해당 과목과 대화로 이동한다.
7. `keepAliveOnClose`가 켜진 상태에서 메인 창을 닫으면 오브와 트레이가 남고, 꺼진 상태에서는 오브가 종료된다.
8. 첫 화면 보기 요청에서 권한 카드를 거부하면 캡처되지 않고, 허용하면 `desktop_screenshot` 결과로 답변하며 실행 상태가 팝업에 표시된다.
9. MCP 서버를 저장·테스트·삭제하면 목록이 즉시 갱신되고, 활성 서버의 도구가 데스크톱 대화에서만 노출된다.

## macOS 화면 기록 권한

화면 기록 권한을 처음 허용하거나 변경한 뒤에는 반달을 완전히 종료하고 다시 실행해야 TCC 상태가 새 프로세스에 반영된다. 계속 거부 상태로 보이면 **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음**에서 Bandal을 확인한 뒤 다시 시작한다.
