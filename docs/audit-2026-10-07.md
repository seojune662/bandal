# 전체 코드·사용자 흐름 검토 — 2026-10-07

기준 커밋: `bf9557c` (0.71.0). 검토 시작 시 작업 트리는 깨끗했다.

## 방법과 완료 조건

기능마다 정상 사용, 빈 상태, 실패·재시도, 취소, 연속 입력, 과목·자료 전환,
재시작·복원, 키보드, 작은 창, 데이터 저장·삭제를 가설로 검토한다.
확인한 결함은 가능한 경우 실패하는 회귀 검사로 먼저 재현하고 수정한다.
정적 검토, 모의 응답 검사, 실제 Electron 실행, 배포 앱 검증은 구분한다.
검토 범위가 넓어도 모든 환경의 모든 버그가 없음을 증명하지는 않는다.

## 주 검토에서 재현한 문제

1. 과목 보관·삭제 도중 다른 과목을 선택하면 늦은 응답이 새 선택을 바꾼다.
   반대로 삭제 대기 중 해당 과목을 선택하면 삭제된 과목 ID가 남는다.
   응답 완료 시점의 목록·선택을 사용하도록 수정. 두 동작의 양방향 회귀 4개 포함 11개 통과.
2. 자료 목록의 이전 로딩 상태가 캐시된 과목으로 돌아온 뒤에도 유지된다.
   선택 해제 뒤에는 펼친 폴더 캐시가 빈 상태로 덮인다. 선택한 과목에 맞춰
   로딩을 재계산하고 선택 해제 전에 캐시를 보존. 스냅샷 조회 실패는 실시간 트리
   조회로 복구하며 이전 과목 검색 요청을 차단. 실패 재현 4개 → 모두 통과.
3. 공통 포커스 트랩이 CSS로 숨긴 버튼, disabled fieldset 자식,
   disabled+tabindex 버튼을 탭 순서에 포함한다. 컨테이너 자체에서 Shift+Tab도
   빠져나간다. 실제 DOM 재현 5개 → 기존 포함 9개 통과.
4. 보드 편집에서 고른 색상을 updateTask 요청에 누락한다. 저장 요청에 포함하고
   실제 일정 E2E에 영속값 검증을 추가. 생성 푸시/응답 중복 행과 다른 태스크 편집 시
   이전 폼 상태 유지도 방지. E2E 검증 예정.
5. 메일 답장 전송 응답이 전송 후 새로 입력한 초안을 지운다. 보낸 문자열과 화면
   세대가 일치할 때만 초안을 비움. 실패 재현 후 기존 포함 5개 통과.
6. 빠른 파일 검색의 debounce 중 Enter가 이전 검색 결과를 연다. 검색어·과목 변경
   직후 이전 결과를 지우고 진행 중 열기를 막았다. 오류와 실제 빈 결과를 구분하고
   재시도 버튼을 제공한다. DOM 회귀 2개 통과.
7. 자료 이름 변경의 requestAnimationFrame 선택 범위 지정이 입력과 겹치면
   `renamed.md.md`가 될 수 있다. 레이아웃 효과에서 편집 시작 시 즉시 이름을 선택한다.
   지원 파일의 열기 안내도 실제 탭 지원 범위에 맞췄다.
8. 설정 푸시 이후 도착한 이전 설정 응답/실패, 이전 보관 필터의 과목 목록 응답이
   최신 화면을 덮는다. 설정 푸시 세대와 목록 요청 순서를 추적한다. 설정 캐시도
   최신 푸시가 있다면 이전 초기 읽기 실패에서 복구한다. DOM·스토어 회귀 통과.
9. 저장된 작업 공간 읽기 실패를 빈 레이아웃으로 취급해 원본 탭 구성을 덮을 수 있다.
   오류 상태에서는 저장하지 않고 원본을 유지하며 ‘다시 불러오기’를 제공한다.
   기존 포함 스토어 42개 및 실패 주입 Electron E2E 통과. 실제 오류 화면도 확인했다.
10. 편집기가 이미 처리한 단축키를 전역 핸들러가 다시 실행한다. defaultPrevented를
    존중하도록 수정했다. 메뉴 최초 포커스는 숨김/비활성 버튼을 건너뛰고, 메뉴의 Esc는
    뒤쪽 대화상자를 함께 닫지 않는다. 실제 DOM 회귀 통과.
11. 과목·그룹 생성 푸시가 응답보다 먼저 목록에 반영되면 항목이 중복된다. 생성 응답을
    ID별로 합친다. 지연 응답 회귀 2개 통과.
12. 피드백 전송 실패·요청 제한에도 창을 닫고 작성 내용을 지웠다. 성공한 경우에만
    초기화하고 실패는 초안·재시도 동작을 유지한다. 클립보드 복사 실패를 성공으로
    안내하지 않는다. 모의 전송·복사 실패 및 재시도 3개 통과(실제 메시지 전송 없음).
13. 사이드바 폭 조절은 마우스로만 가능했다. 좌우 방향키, Home/End 및 값/범위 접근성
    속성을 추가했다. 포인터 취소/캡처 상실은 시작 폭으로 복구한다. Electron 검사 예정.
14. 자료 작업이 늦게 끝나면 이전 과목 트리로 전환하거나 새 과목에 이전 자료를 연다.
    백그라운드 refresh는 활성 과목을 바꾸지 않으며 생성·이동·이름 변경·복사·붙여넣기
    후 UI 처리는 원래 과목이 보이는 경우만 적용한다. 전환 중 스캔과 새 필기 회귀 통과.
15. 화면 영역 선택은 초기 이미지 조회 실패를 표시하지 않고 취소도 Esc에만 의존했다.
    준비/실패 상태와 보이는 취소 버튼을 추가하고 우클릭·취소된 드래그는 제출하지 않는다.
    IPC/포인터 모의 DOM 회귀 2개 통과. 실제 화면 기록 권한은 조작하지 않았다.
16. 손상 파일 격리 이름에 ISO 시각의 `:`가 들어가 Windows에서 rename할 수 없다.
    Windows에서 사용할 수 있는 시각 파일명으로 바꾸고 충돌 시 원본을 보존한다.
    atomicWrite/설정/저장 로그인/MCP 회귀 통과.
17. Windows에서도 Finder라고 안내하던 자료 메뉴·삭제 문구를 OS 중립적으로 정리했다.
    렌더러 복구 안내는 미저장 내용까지 보존됐다고 단정하지 않도록 수정했다.

  샌드박스 bind 제한 때문에 동일 검사를 권한 허용된 프로세스에서 완료했다.

  보호와 빌드/서명 경로를 정적으로 검토했다. 실제 개인 캘린더 연결은 실행하지 않았다.

  미적용임을 확인했다. 독립 검토와 적용 확인 결과는 최종 배포 기록에 반영한다.

## 기존 릴리스 실패 조사

0.71.0 CI는 성공했지만 Release `37503250995`의 macOS 패키지 E2E가 실패했다.
70개 통과, 과목 이동 후 필기 이름 변경과 학습 모델 오류 표시 2개 실패.
실행 trace와 실패 화면을 받아 이름 선택 시점과 학습 초기 스냅샷의 실패 분류 경합을
확인했다. 학습의 실제 즉시 실패 노출은 별도 코드 수정했으며 E2E fixture도 초기
모델 로드 이후 주입하도록 동기화했다. 샌드박스 내 Electron 실행은
SIGABRT로 시작하지 못해, 동일 임시 프로필 검사만 권한이 허용된 실행으로 전환했다.

검토 결과와 관련 테스트가 완료되면 커밋·푸시·릴리스 공개 및 macOS/Windows
설치 파일·자동 업데이트 피드의 공개 상태를 기록한다.
