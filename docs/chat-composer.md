# AI 채팅 입력창과 승인

일반 채팅, 인앱 오브, 데스크톱 오브는 같은 `ChatSurface`와 입력창을 사용한다. 모델과 Effort는 입력창에서 바꾸며 대화별로 저장된다. 실행 중에는 변경할 수 없다. 설치된 Claude/Codex CLI가 보고한 Effort만 표시하고 Gemini와 지원 정보가 없는 모델에는 기본값만 제공한다.

`+` 메뉴에서 기기 파일, 과목 자료, 브라우저 페이지, 데스크톱 화면, 설치된 스킬을 선택한다. 첨부·스킬은 전송 전에 제거할 수 있고, 전송 실패 시 초안과 첨부를 유지한다. 일반 파일은 과목의 `첨부` 폴더에 복사하며 원본은 수정하지 않는다. 파일은 20개, 파일당 64MB, 붙여넣는 이미지는 5개, 이미지당 5MB까지다.

만들기 메뉴는 해당 제공자의 로컬 스킬을 발견한 경우 활성화된다. 제공자별 설정 폴더의 `skills`와 `plugins/cache`, 과목별 스킬을 탐색한다. Codex는 `CODEX_HOME`도 반영한다. 선택한 SKILL.md의 실제 경로를 AI에 전달하며, 생성물은 과목의 `생성 결과` 아래 별도 폴더에 저장하도록 요청한다. 존재하는 파일의 형식을 확인한 뒤 열기·폴더 보기 카드를 추가한다. 새 유료 API는 연결하지 않는다. 스킬이 요구하는 서비스·런타임의 이용 가능 여부는 실제 실행 시 확인되므로, 스킬 발견만으로 모든 생성 작업의 성공을 보장하지 않는다.

Claude에서는 스킬을 선택한 턴에만 스킬 실행과 승인 가능한 명령 실행을 활성화한다. 기존 권한 확인과 Codex 샌드박스는 유지한다. 브라우저·앱 도구 승인은 main의 상태가 기준이다. 처리 중, 실패, 만료, 취소를 모든 창에 전달하고 중복 응답은 다시 실행하지 않는다. 대기 요청은 한 장씩 표시하며 새 요청의 허용 범위는 다시 기본값에서 시작한다.

검증은 `pnpm test`, `pnpm typecheck`, `pnpm deadcode`, `pnpm build`와 `pnpm exec playwright test -c e2e e2e/chatUx.spec.ts e2e/desktopOrb.spec.ts`로 실행한다. 채팅 E2E는 실제 Electron 렌더러에 결정적인 AI 응답을 주입한다. 실제 계정의 모든 모델·스킬 생성 결과를 검증하는 테스트는 아니다.
