# AI 채팅 입력창과 승인

자료 옆 AI 사이드바와 확장된 AI 탭은 같은 `ChatSurface`와 입력창을 사용한다. 모델과 Effort는 입력창에서 바꾸며 대화별로 저장된다. 실행 중에는 변경할 수 없다. 설치된 Claude/Codex CLI가 보고한 Effort만 표시하고 Gemini와 지원 정보가 없는 모델에는 기본값만 제공한다.

`+` 메뉴에서 기기 파일, 과목 자료, 브라우저 페이지, 데스크톱 화면, 설치된 스킬을 선택한다. 첨부·스킬은 전송 전에 제거할 수 있고, 전송 실패 시 초안과 첨부를 유지한다. 일반 파일은 과목의 `첨부` 폴더에 복사하며 원본은 수정하지 않는다. 파일은 20개, 파일당 64MB, 붙여넣는 이미지는 5개, 이미지당 5MB까지다.

만들기 메뉴는 해당 제공자의 로컬 스킬을 발견한 경우 활성화된다. 제공자별 설정 폴더의 `skills`와 `plugins/cache`, 과목별 스킬을 탐색한다. Codex는 `CODEX_HOME`도 반영한다. 선택한 SKILL.md의 실제 경로를 AI에 전달하며, 생성물은 과목의 `생성 결과` 아래 별도 폴더에 저장하도록 요청한다. 존재하는 파일의 형식을 확인한 뒤 열기·폴더 보기 카드를 추가한다. 새 유료 API는 연결하지 않는다. 스킬이 요구하는 서비스·런타임의 이용 가능 여부는 실제 실행 시 확인되므로, 스킬 발견만으로 모든 생성 작업의 성공을 보장하지 않는다.

기본 허용 모드는 **자동 실행**이다. 자료 읽기·검색·파일 작성과 요청한 앱·브라우저 작업은 중간 승인창 없이 진행한다. 기존 대화에 저장된 이전 기본 설정도 자동 실행으로 읽으며, 사용자가 새로 선택한 항상 확인·읽기만 자동 설정은 유지한다. 화면 접근, 운영체제 권한, 실제 계정 연결과 학습 백그라운드 작업의 격리는 별도로 유지한다. 내부 실행 명령·도구 이름·원문 추론·완료된 승인 기록은 답변에 표시하지 않는다.

작성 중에는 생각 중·자료를 살펴보는 중·답변 작성 중 가운데 현재 단계 하나만 표시한다. 위로 스크롤하면 자동으로 아래로 끌어내리지 않으며 최신 답변 이동 버튼을 제공한다. 완료된 답변은 복사할 수 있다. 예외적으로 사용자가 확인 모드를 선택했거나 별도 접근이 필요한 경우에만 입력창 위에 작은 확인 영역을 표시하며, 입력 중인 글과 포커스를 유지한다. 처리 중·실패·만료·취소는 main의 상태를 기준으로 모든 창에 동기화한다.

답변은 CommonMark와 GFM 표·중첩 목록을 렌더링하고, `$...$`, `$$...$$`, `\(...\)`, `\[...\]` 수식은 KaTeX로 표시한다. 작성 중 미완성 수식은 완성될 때까지 준비 표시로 대체한다. 표와 긴 수식은 답변 전체를 밀어내지 않고 해당 영역 안에서 스크롤한다. 코드 블록의 원문은 수식으로 변환하지 않으며, 원시 HTML과 위험한 링크는 실행하지 않는다.

검증은 변경된 채팅 렌더러·허용 정책·제공자 어댑터의 단위 검사와 해당 영역 타입 검사를 선택한다. `pnpm build` 후 `pnpm exec playwright test -c e2e e2e/chatUx.spec.ts`로 실제 Electron 화면의 작성 상태·수식·표·복사·스크롤·예외 확인 흐름을 확인한다. 채팅 E2E는 결정적인 AI 응답을 주입하므로 실제 개인 계정의 모든 모델·스킬 결과와 운영체제 권한 승인을 검증하지 않는다.
