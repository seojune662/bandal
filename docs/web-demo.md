# 실제 앱 코드로 만드는 웹 체험

`pnpm build:web-demo`는 `web-demo/dist`에 정적 브라우저 빌드를 만듭니다. 웹사이트 저장소에서 `pnpm sync:demo`로 이 빌드를 가져옵니다.

`web-demo/bootstrap.ts`가 Electron IPC 대신 브라우저 저장 어댑터를 먼저 설치하고, 실제 `AppShell`, Dockview, PDF.js, Milkdown, 페이지 필기, 보드·달력, AI 채팅 컴포넌트를 렌더링합니다. 제품 화면을 흉내 낸 HTML이나 고정 스크린샷을 사용하지 않습니다. PDF는 가상의 강의자료입니다.

PDF 펜 필기, 일반·페이지별 마크다운 편집, 탭 분할, 스크롤 연결, 과제 편집·일정 추가, 필기 내보내기를 지원합니다. 파일은 방문자의 디스크에 직접 접근하지 않고 브라우저 localStorage에 보관합니다. 저장소가 차단된 환경은 현재 창에서만 유지하고, 저장 공간 부족은 오류로 표시합니다. 미리보기 종류와 언어별로 저장 공간을 분리합니다.

AI 모델·Effort·첨부 메뉴와 입력창은 실제 UI이며 답변은 명시된 예시입니다. 실제 AI 요청, 계정 연결, 도구 실행은 하지 않습니다. Apple 캘린더, 녹음과 로컬 파일 가져오기 등 네이티브 기능은 설치 앱 안내를 표시합니다.

같은 출처의 상위 사이트와 검증된 `postMessage`로 테마를 즉시 동기화합니다. 아직 사용자가 조작하지 않은 iframe의 자동 포커스·스크롤은 상위 사이트를 움직이지 않습니다. 초기화는 확인 대화상자를 거치며 내보내기를 먼저 할 수 있습니다.

배포 출처는 웹 저장소 `public/app-demo/source.json`에 기록합니다. 웹의 Chrome·WebKit 검사는 36개 테마, 실제 PDF 필기, 저장·복원·내보내기, AI 메뉴, 달력, 모바일과 저장소 제한을 확인합니다.
