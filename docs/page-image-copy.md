# PDF·PPTX 페이지를 이미지로 복사

페이지의 빈 곳이나 원본 내용에서 우클릭하면 두 가지 메뉴가 나타납니다.

| 메뉴 | 복사되는 내용 |
| --- | --- |
| 이미지로 복사 | 원본과 반달에서 추가한 필기, 텍스트 형광펜, 텍스트 상자, 이미지 |
| 원본만 이미지로 복사 | 원본 PDF 페이지 또는 PPTX 슬라이드. 원본에 들어 있던 주석과 이미지는 유지 |

우클릭한 **한 페이지 전체**를 흰 배경의 PNG로 복사합니다. 화면에서 일부만 보이거나 확대·축소해도 같은 페이지를 복사하며, 도구 버튼·선택 테두리·페이지 필기 패널은 들어가지 않습니다. 기본 너비는 1,600px이고, 긴 변이 4,096px을 넘는 경우 비율을 유지해 줄입니다.

복사 후 반달 노트, 화이트보드, PDF 필기 공간 또는 이미지를 붙여넣을 수 있는 앱에서 붙여넣으세요. 텍스트를 편집하는 상자 안에서는 원래 텍스트 편집 메뉴를 유지합니다. 복사 메뉴는 방향키로 이동하고 Enter로 실행하거나 Escape로 닫을 수 있습니다.

필기나 이미지가 아직 로딩 중이면 로딩이 끝난 뒤 다시 시도하세요. 원본을 정확히 그릴 수 없는 PPTX의 간단 미리보기에서는 이미지 복사가 비활성화되고 이유가 표시됩니다. 복사 중인 탭을 닫거나 문서를 바꾸면 진행 중인 작업이 취소됩니다. 렌더링에 실패한 경우 기존 클립보드 내용은 유지됩니다.

## 구현과 검증

- `pageImageCopy/`가 메뉴, 중복 실행 방지, 클립보드 쓰기와 임시 이미지 정리를 공통으로 처리합니다.
- PDF는 현재 열려 있는 PDF.js 문서에서 별도 캔버스와 렌더 작업을 만들고, PPTX는 기존 렌더 캐시를 사용합니다. 열린 문서와 화면용 캔버스를 파괴하지 않습니다.
- `captureInkSnapshot`은 페이지의 필기 SVG와 PDF 텍스트 형광펜을 캡처하고, 글꼴·삽입 이미지와 함께 원본 위에 합성합니다. 저장 전 편집 내용도 현재 DOM에서 읽습니다.
- 단위 검사는 취소·문서 교체·탭 종료·실패 시 클립보드 보존·키보드 메뉴·지원하지 않는 미리보기를 검증합니다.
- Electron E2E는 실제 OS 클립보드의 PNG 크기와 픽셀, 클릭한 페이지, 확대·축소·창 크기, 가로·세로·긴 페이지, 노트·PDF·화이트보드 붙여넣기를 검사합니다. 릴리스는 macOS·Windows 패키지에서도 이 검사와 기존 PPTX 복사 검사를 통과해야 공개됩니다.
- 외부 앱마다 붙여넣기 지원 방식은 다릅니다. 외부 앱별 호환성은 이 자동 검사의 범위에 포함되지 않습니다.
