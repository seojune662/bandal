# 폴더에 쌓이는 학습

과목은 수업의 원본 자료·필기·일정을 관리하고, 학습 공간은 기사·표현·퀴즈·카드·학습 기록을 관리한다. 왼쪽 **학습** 아이콘에서 영어 이어읽기와 과목 복습 공간을 구분해 열 수 있다. 플러그인은 실행할 기능을 제공하고, AI는 연결한 제공자와 모델로 검색·설명·생성을 수행한다.

새 영어 공간은 과목과 분리된 전용 폴더로 만든다. 이름, 최대 3개의 관심 주제, 영어 수준, 읽기 시간, 연결한 AI와 모델을 모두 확인해야 생성할 수 있다. 관심 주제는 보기에서 선택하며 중급과 3~5분은 추천 표시만 제공한다. 읽기 시간은 분당 150단어를 기준으로 계산한 예상치다.

얇은 왼쪽 메뉴의 **AI**는 현재 자료의 기존 대화와 초안을 이어 열고 입력란으로 이동한다. **플러그인**은 과목 목록 자리에서 기능 검색과 실행창을 연다. 현재 자료와 선택한 글, PDF 페이지를 표시하고 선택한 부분·현재 자료·과목 전체 중 지원하는 범위를 고를 수 있다. 과목 목록과 실행창의 검색·스크롤·너비는 전환해도 유지한다.

영어 이어읽기는 현재 영어 공간, 최근 사용한 영어 공간, 공간 선택·생성 순서로 이어간다. 일반 과목 복습 공간을 영어 공간으로 재사용하지 않는다. 브라우저의 **현재 글을 영어 학습에 추가**는 실제 현재 URL을 가져온다. 학습 기사와 단어장에서는 각각 해당 원문과 표현으로 퀴즈·카드를 생성한다. 실행창 하단의 **플러그인 관리**에서 설치·권한·활성화를 관리하며, 변경한 목록은 실행창과 우클릭 메뉴에 즉시 반영된다. 사용자 v1 팩은 문서 생성 팩으로 표시하고 기존 마크다운 실행을 유지한다.

영어 본문에서 단어를 클릭하거나 짧은 표현을 선택해 저장하면 원문 문장과 선택 위치가 즉시 남는다. 문맥 설명은 별도의 AI 실행으로 보충한다. 같은 표현의 여러 예문을 단어장에서 비교하고 뜻·원형·품사·익숙함을 수정할 수 있다. 읽기 위치는 자동 저장하고 완료는 사용자가 표시한다.

체크한 표현이 없으면 선택한 관심 주제의 기사부터 찾는다. 주제를 여러 개 골랐다면 매 검색에서 하나를 선택해 실행 기록에 남긴다. 현재 열린 과목 파일에서 단어를 추출하지 않는다. 표현을 체크한 이후에는 복습 오답과 낯선 표현 중 최대 5개를 다음 검색의 목표로 잡는다. 검색은 공간에서 선택한 AI 제공자의 검색 기능 또는 내장 브라우저를 사용한다. 앱은 로그인 없는 별도 브라우저에서 Mozilla Readability로 본문을 추출하고 영어, 길이, 중복, 실제 표현 출현을 확인한다. 검증한 글만 최대 3개 저장하며 원문 HTML은 학습 화면에 실행하지 않는다. 본문에 목표 표현이 없는 후보도 재등장 수를 표시한다.

일반 자료의 AI 학습 도구에서도 퀴즈와 카드를 생성할 수 있다. 과목마다 연결된 독립 복습 공간을 처음 한 번 만들고 결과와 학습 기록을 쌓는다. 원본 과목의 ID·자료 경로·내용 식별 정보를 보존하고, PDF의 실제 텍스트와 페이지, 일반 자료의 텍스트, 저장한 기사 문장으로 생성 결과의 출처를 확인한다. 텍스트가 없는 스캔 PDF는 텍스트 자료로 변환해야 한다.

공간 상단의 학습 AI 설정에서 제공자·모델을 바꾸고 모델 목록을 새로고침할 수 있다. 학습 실행은 명시적으로 고른 모델을 사용하며 일반 채팅의 설정이나 외부 CLI 설정 파일을 변경하지 않는다. 모델 목록과 캐시는 실제 계정의 실행 가능성을 보장하지 않으며, 모델 거절·로그인 필요·한도·연결 오류와 결과 검증 실패를 구분해 안내한다. 재시도는 현재 공간의 설정으로 새 실행 기록을 남긴다.

전용 학습 세션에서 Codex의 실시간 웹 검색과 Claude의 WebSearch·WebFetch를 사용할 수 있다. 일반 대화의 검색·권한 설정은 변경하지 않는다. 후보의 읽기 시간이 맞지 않으면 AI에 실제 시간·단어 수와 허용 범위를 알려 다음 후보를 조정하게 한다. 검증 때문에 사용자의 읽기 시간을 자동으로 바꾸지는 않는다.

객관식은 선택지 ID, 빈칸은 명시한 허용 답안과 대소문자·앞뒤 공백으로 채점한다. 자유 답변은 모범 답안과 확인 기준을 보고 사용자가 평가한다. 자동 채점 점수와 자기평가를 구분하며 답안과 완료된 시도는 각각 보존한다. 카드의 기억함 간격은 1·3·7·14·30일, 어렵게 기억은 현재 단계에서 다음 날, 기억 안 남은 첫 단계로 돌아가 10분 뒤다. 같은 카드의 재생성은 기존 복습 기록을 이어받는다.

## 저장과 복원

```text
학습 공간/
├── 기사/
├── 단어장.md
├── 예문 모음.md
├── 복습/
├── 학습노트/
└── .bandal/learning/
```

`.bandal/learning`의 버전 있는 JSON이 기록의 원본이다. 기사 본문, 생성 자료, 완료 결과를 별도 스냅샷으로 보존하고 SQLite는 다시 만들 수 있는 연결·검색 캐시로 사용한다. 폴더를 복사하고 과목으로 연결하면 기록을 복원한다. 같은 내부 ID의 복사본도 실제 연결 경로별로 독립된 공간이다.

컨테이너의 `workspaceKind`는 과목과 독립 학습 공간을 구분하고, 학습 기록의 `purpose`는 영어 읽기와 과목 복습을 구분한다. 기존 폴더는 이동하지 않는다. 이전 일반 복습 공간은 복습 화면으로 열고, 용도가 불명확한 공간은 종류 확인 전 영어 자동 재개에서 제외한다. 과목 루트에 보관된 기존 공간을 독립 공간으로 표시하려면 사용자가 설정에서 폴더 분류를 명시적으로 확인한다.

저장은 공간별로 직렬화하고 이전 정상 상태를 남긴다. 손상된 상태 파일은 빈 기록으로 덮어쓰지 않는다. 정상 사본이 있으면 복구 사실을 알리고, 없으면 원본을 보존한 채 복원 오류를 표시한다. 사용자가 편집한 Markdown을 자동 갱신할 때는 새로운 갱신 사본을 만든다. 원문이 삭제되거나 달라져도 이미 저장한 예문과 풀이 기록은 유지한다.

## AI 실행과 팩 계약

학습 공간 목록의 이름 변경은 표시 이름을 바꾸고 폴더 경로를 유지한다. 목록 삭제는 파일 삭제가 아니다. 공간의 `deletedAt`을 저장해 재탐색에서도 목록에서 제외하며, 독립 공간은 과목 엔진 등록도 제거한다. 기존 과목 하위 공간과 과목 루트의 학습 기록은 부모 과목을 제거하지 않는다. 삭제한 공간 목록에서 복원하면 원래 과목 ID·프로젝트 ID·자료·풀이·복습 간격이 유지된다. 보존된 폴더가 이미 다른 과목에 연결되어 있으면 복원을 거절한다. `learning:list`의 `includeDeleted`는 복원 목록에 사용하며 일반 조회·변경과 AI 실행은 삭제된 공간을 사용할 수 없다.

삭제는 신규 실행과 대기 작업 시작을 차단하고, 진행 중 작업의 취소·제공자 정리·저장이 끝난 뒤 처리한다. 삭제한 기본 복습 공간을 다음 생성 요청에서 자동 복원하지 않으며 새 공간을 만든다. 옛 공간을 명시적으로 복원해도 이후 생성은 더 최근에 만든 기본 공간에 쌓인다. 새 과목 복습 공간은 `학습노트`와 `복습` 폴더로 시작하고 영어용 빈 기사·단어장 파일을 만들지 않는다. 기존 폴더와 사용자가 편집한 파일은 정리하거나 덮어쓰지 않는다.

실패 알림 숨김은 `learning:dismissRun`으로 `dismissedAt`만 저장한다. 오류 이유와 원본 대상, 실행 기록은 남고 재시도는 숨기지 않은 새 실행을 만든다. 완료 실행은 같은 저장에 실제 `resultArticleIds`와 `resultArtifactIds`를 기록하므로 UI는 마지막 파일이나 입력 자료를 추측하지 않고 정확한 결과를 연다. 이 필드가 없는 옛 실행은 공간 보기로 연결한다.

`learning:run`과 `study:generate`는 실행 ID를 즉시 반환한다. 전용 `study` 대화는 일반 대화 목록에 나타나지 않는다. 대기·실행·검증·완료 또는 실패·취소·중단 상태를 저장하며 실제 제공자 종료 이벤트와 결과 검증·저장이 모두 끝나야 완료가 된다. 작업은 공간마다 순서대로 실행하고 앱 재시작으로 중단된 실행은 다시 시도할 수 있다. 기존 Markdown 가져오기는 미리보기에서 수정·검증한 뒤 저장한다.

`learning:updateSettings`는 공간별 AI와 확인한 영어 설정을 저장한다. `study:generate`의 `courseId`는 원본 과목, `binding`은 결과 공간을 가리킨다. 예전 요청에서 결과 공간을 생략하면 과목에 연결된 복습 공간을 찾아 사용한다. 실행 기록은 명시적 모델, 실제 사고 수준, 전용 세션 ID와 제공자의 실패 이유를 보존한다. 재시도는 이전 실패를 유지하고 원본 대상을 그대로 사용한다.

학습 전용 세션은 전달된 자료와 허용된 학습·읽기 도구를 사용한다. 제공자가 셸·직접 파일 작업이나 추가 권한 승인을 요청하면 즉시 거절해 숨겨진 대화에서 승인 응답을 기다리지 않게 한다. 일반 대화의 승인 방식은 유지한다. 자료 폴더 이름 변경과 이동은 해당 과목의 감시 핸들 해제와 진행 중인 스캔 종료를 확인한 뒤 실행하고, 변경 후 감시를 복원한다.

학습 도구의 웹 접근과 사용자 설치 팩 실행 승인은 앱 창에 연결된 승인창으로 표시한다. 승인 대기 중에도 조회와 취소가 응답하고, 실행 취소·승인 만료·창 닫기·앱 종료는 대기 중인 창을 닫는다. 표시할 앱 창이 없으면 실행을 허용하지 않는다.

공개 기사를 검증하는 익명 브라우저 뷰는 본문 추출이 끝날 때까지 소유하고, 성공·실패·취소 시 콘텐츠와 연결을 닫는다. 화면에 붙지 않은 뷰도 메모리 정리 때문에 읽는 도중 사라지지 않는다.

기존 단어장 표는 원본 행과 뜻을 확인해 공통 단어장으로 가져오고, 퀴즈·카드·기사 노트는 출처가 연결된 새 학습 자료로 저장한다. 원본 파일은 유지한다.

팩 v2는 `experience: article-vocabulary | quiz | flashcards`를 제공한다. `vocab-chain-en`, `quiz`, `flashcards` ID를 유지하고 기존 v1 팩과 `study:run → { relPath }`도 지원한다. 팩을 비활성화해도 이미 저장한 자료와 복습 기록은 사용할 수 있다. 자유 답변 AI 채점, 기기 간 동시 편집 병합, 제3자 코드 플러그인의 범용 학습 SDK는 후속 범위다.

실행창과 기존 학습 메뉴는 같은 문맥 resolver와 dispatcher를 사용한다. 실제 패널 ID로 복제한 자료를 구분하고, 저장 전 필기는 저장 성공을 확인한 뒤 생성한다. 원본 닫힘·이동·저장 충돌은 실행을 멈추며 다른 자료로 대체하지 않는다. v2 실행은 저장된 상태를 표시하고, v1 Markdown 실행은 생성 요청과 파일 출현을 구분해 요청 접수를 완료로 표시하지 않는다.

## 검증

`tests/main/learning`은 본문 검증, 출처와 선택 위치, 복구·복사·이동, 카드 간격, 퀴즈 채점, 실행 종료·취소·재시도와 과목별 독립 복습 공간을 검사한다. `tests/renderer/learning`은 선택·표현 매칭과 학습 화면을 검사한다. `e2e/learning.spec.ts`는 고정 기사와 실제 폴더 저장으로 제품 흐름을 확인하고 AI 작업 예약만 고정 응답으로 바꾼다. `e2e/learningSpaces.spec.ts`는 학습 목록 분리, 필수 설정, 연결·모델 선택, 주제 검색과 실패 안내를 확인한다. 실제 네이티브 승인 대기 중 조회·취소 응답과, 익명 기사 로딩 중 강제 메모리 정리를 해도 추출이 완료되고 콘텐츠가 닫히는지 검사한다. 실제 AI 검색 연결 확인은 이 재현 가능한 제품 검사와 별도로 수행한다.
