# 반달 v0.60.0 — 로고와 AI 대화

확정한 두 달의 벡터와 4,097개 회전 자세를 `src/shared/moonGeometry.json`에 보관한다. 모든 로고는 같은 원본을 사용한다. 각각의 중심과 80% 크기를 유지하며 반복은 4초, 시작은 2초다. 반복 회전 중 커서가 떠나면 현재 바퀴를 마친다. 숨겨진 화면과 동작 줄이기 설정에서는 애니메이션을 중단한다. 앱 테마 설정은 그대로 유지한다.

독립 대화창은 420×600px, 최소 360×420px이며 불투명하다. 오브의 지연 호버 메뉴에서 영역·현재 자료·화면·파일 질문을 선택한다. 모델·추론 강도와 대화별 허용 모드는 입력창 아래에 있다. 승인 요청은 약 300px 너비의 별도 창에서 한 장씩 표시하고 입력 초점을 가져가지 않는다. 창과 탭 사이 초안, 첨부, 진행 중 답변을 동기화한다.

전송 직전 과목, 마지막 자료, PDF 페이지·슬라이드, 선택 글, 저장 전 필기와 브라우저 탭을 스냅샷으로 확정한다. AI 탭을 자료로 인식하지 않는다. 진행 중 대화의 과목을 유지하고 자동 연결 칩을 제거할 수 있다. 같은 자료의 본문을 매번 재전송하지 않으며, 갱신 실패는 모델에 명시한다. 화면은 사용자가 화면/영역 질문을 선택했을 때 가져오고 미리보기 후 전송한다.

CLI와 반달 도구 승인은 main 프로세스에서 관리한다. 대화·턴·요청 ID와 revision을 사용해 중복과 오래된 상태를 제거한다. 거절·취소·만료된 동일 작업은 같은 턴에서 다시 묻지 않는다. 자동 판단은 기본값이며, 직접 파일 변경과 확인이 필요한 접근은 공통 승인창을 사용한다. 전체 허용도 선택한 확인 생략 범위만 적용하며 OS 권한 및 기존 사이트 권한과 분리된다.

Codex는 App Server, Gemini는 ACP로 연결한다. 검증한 최소 CLI 버전은 Codex 0.158.0, Gemini 0.58.0이다. 이전 버전에는 업데이트 안내를 표시한다. Gemini 설정은 세션별 임시 디렉터리로 격리하고 이미지 데이터를 실제 ACP 이미지 블록으로 전달한다. MCP 도구는 실제 읽기/쓰기 속성을 제공하고 동일 요청 ID의 실행 결과를 재사용한다.

## 검증

- 단위 회귀: 승인 중복·연속 응답·취소·만료·제공자 측 해결, 상태 revision, RPC 이미지·재개·취소, 세션 설정 격리, 스트리밍 도중 창 이관과 이벤트 순서, 같은 문맥 중복 전송 방지, 파일 경로·심볼릭 링크 범위, 회전 겹침·반복 연결, 배율별 크롭.
- Electron: 오브 호버와 메뉴 이동, 회전 종료와 동작 줄이기, 420×600 창, 밝고 어두운 테마, 승인창 입력 초점과 재시도, 모델·초안 이관, PDF 2쪽 문맥, 필기 수정 후 질문, 과목 전환, 영역 선택 취소와 크롭 이미지 미리보기.
- 실제 Codex 0.158.0 계정: 이미지 질문, 승인 후 임시 파일 쓰기, 종료 후 대화 재개, 응답 중 취소, MCP 쓰기 도구 실행 확인.
- 실제 Claude 2.1.286 계정: 동일 항목 확인.
- Gemini 0.58.0: ACP 모의 서버의 이미지·승인·취소·재개 및 세션 설정 격리 통과. 실제 OAuth 계정은 Google 서버가 Gemini Code Assist 클라이언트 지원 종료 오류를 반환했다. API 키 또는 다른 제공자 연결 안내를 표시하며, 이 계정의 실제 응답 검증은 통과로 간주하지 않는다.
- 화면 선택 E2E는 합성 화면과 허용된 OS 권한 응답을 사용한다. 실제 macOS·Windows 권한 허용, 여러 물리 모니터와 Windows 배율 환경에서의 수동 검증을 대신하지 않는다. 좌표 변환은 100·125·150·200% 배율로 검사한다.

배포 시 `scripts/affected-checks.mjs`가 영향받은 코드 검사와 패키지 E2E를 선택한다. 서명·공증과 설치 파일·업데이트 피드 검증은 기존 릴리스 워크플로를 따른다. Windows 설치 파일은 프로젝트의 기존 배포 정책에 따라 미서명이다.
