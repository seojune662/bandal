# 녹음 및 탭 설정 UX 개선 — v0.48.0

2026-09-11. v0.47.0 사용 피드백을 반영했다. 이 변경은 음성 모델이나
장시간 발열 검증 결과를 바꾸지 않는다.

## 변경 사항

- 헤더에서 설정·자료 패널 전체를 접고 펼친다. 선택은 앱 설정에 저장한다.
  패널 안의 녹음 설정과 각 모델 설명도 따로 접을 수 있다. 좁은 분할
  화면에서는 자막을 가리지 않도록 패널을 처음에 접고 필요할 때 연다.
- 자막 안쪽 스크롤을 없애 본문과 설정 열이 각각 한 스크롤만 갖도록 했다.
  녹음 중 자동 따라가기는 사용자가 위로 스크롤하면 멈춘다. 종료된 녹음은
  첫 자막부터 읽고, 긴 기록은 200개씩 조회한다.
- 오디오 재생 상태와 마이크 레벨을 별도 컴포넌트로 격리했다. 재생 시각이
  바뀔 때 자막 검색·자료 트리 평탄화·전체 설정 화면을 다시 계산하지 않는다.
  확정 자막 행은 메모이제이션하며 재생 속도·10초 이동·탐색 바를 제공한다.
- 자료 트리에서 기존 `audio.wav`를 누르면 해당 세션 제목의 녹음 탭을 연다.
  세션별 탭 ID로 중복을 방지하고 재시작 후 복원한다. 경로는 DB에서 과목별로
  조회하며 원음 파일을 이동하거나 사용자 폴더를 일괄 변경하지 않는다.
- 전역 녹음 표시는 이미 해당 세션을 보여주는 창을 우선 활성화한다.

## 새 탭 및 기본 설정

| 순서 | 탭 | macOS 기본 단축키 |
| --- | --- | --- |
| 1 | 마크다운 | ⌘⇧M |
| 2 | 브라우저 | ⌘⇧B |
| 3 | AI | ⌘⇧A |
| 4 | 녹음 | ⌘⌥R |
| 5 | 화이트보드 | ⌘⌥W |
| 6 | 학업 보드 | ⌘⌥D |

Windows에서는 Command 대신 Ctrl, Option 대신 Alt를 사용한다. 단축키는
기존 설정 화면에서 변경하거나 해제할 수 있다. 포커스된 웹 페이지에서도
같은 탭 생성 명령을 전달하며, macOS Option 기호 키는 물리 키 코드로 보완한다.

설정 → 탭에서 여섯 종류를 전환해 다음 항목을 관리한다.

- 마크다운: 본문 글꼴과 새 파일 제목 접두어.
- 브라우저: 기존 홈페이지·검색 엔진·줌·링크·보안 등 브라우저 설정 전체.
- AI: 기존 엔진 선택과 제공자 연결/실행 상태 관리.
- 녹음: 기본 모델 및 다운로드, 마이크, 재생 속도, 패널 표시, 실시간 따라가기.
- 화이트보드: 새 보드의 기본 배경. 기존 보드는 변경하지 않는다.
- 학업 보드: 시작 화면(캘린더/칸반), 완료 항목 숨기기.
- 공통: 새 탭 삽입 위치, 마지막 과목과 탭 배치 복원.

## 검증

일반 테스트 3,121개 및 녹음·탭 설정·설정 셸 E2E 11개 통과.
타입 검사, 미사용 코드 검사, 프로덕션 빌드와 밝은/어두운/좁은 화면 확인.
실제 large-v3-turbo 전사·내보내기·재시작, AudioWorklet 수집·일시정지·탭 이동,
엔진 장애 복구, PDF 연결은 기존 실동작 테스트로 재검증했다.

UX 테스트는 별도 임시 프로필과 무음 WAV/250개 자막 fixture로 직접 파일 열기,
독립 세션 탭, 스크롤 이동, 패널 접기 및 복원, 재생·속도 변경을 검증했다.
재생 시각을 12회 갱신해도 자막 DOM 변경은 0회였다. 이는 UI 격리 회귀 검사이며
실제 강의 정확도, 장시간 발열, 모든 기기에서의 프레임률 보장을 의미하지 않는다.
