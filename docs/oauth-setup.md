# OAuth 연결 — 돌아오신 뒤 하실 것

Phase 2(그룹 채팅)의 마지막 잠금 해제 단계다. **앱 코드는 이미 준비돼 있고**, 여기 나온 대시보드 설정만
끝나면 로그인이 동작한다. 소요 시간 약 10분.

Supabase 프로젝트: `https://ukacrkcwiqafwpppshxb.supabase.co`
(URL과 publishable 키는 `.env.local`에 이미 저장돼 있고 gitignore로 커밋이 차단돼 있다.)

---

## 왜 OAuth인가 — 이메일로는 안 되는 이유

현재 프로젝트는 **이메일 인증만 켜져 있다.** 그런데 Supabase 기본 SMTP는 무료 티어에서
**시간당 2~3통**이 한계다. 강의실에서 조원 5명이 동시에 가입하면 그 자리에서 막힌다.
"카톡보다 빠르게"라는 제품 목표와 정면으로 충돌하므로 OAuth가 사실상 필수다.

**권장: 구글 먼저.** 카카오가 한국 학생 커버리지는 압도적이지만 개발자 앱 등록 + 동의항목 설정 +
경우에 따라 비즈앱 심사가 붙어 일정을 막는다. 구글로 열어두고 카카오는 나중에 추가하면 된다.

## 1. 구글 OAuth 클라이언트 만들기 (약 5분)

1. https://console.cloud.google.com/apis/credentials 접속 (프로젝트가 없으면 아무 이름으로 하나 생성)
2. **사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 동의 화면을 아직 안 만들었다면 먼저 만들라고 나온다. **외부(External)** 선택,
     앱 이름 `반달`, 지원 이메일 본인 것, 나머지는 기본값으로 넘어가면 된다.
   - 테스트 사용자에 본인 계정을 추가해 두면 심사 없이 바로 쓸 수 있다.
3. 애플리케이션 유형 **웹 애플리케이션**
4. **승인된 리디렉션 URI**에 아래를 정확히 붙여넣기:
   ```
   https://ukacrkcwiqafwpppshxb.supabase.co/auth/v1/callback
   ```
5. 생성 후 나오는 **클라이언트 ID**와 **클라이언트 보안 비밀**을 복사

## 2. Supabase에 넣기 (약 2분)

1. Supabase 대시보드 → **Authentication → Sign In / Providers → Google**
2. 토글 켜고 위에서 복사한 Client ID / Secret 입력 → 저장

## 3. ⚠️ 리디렉션 URL 등록 — 빼먹으면 로그인이 "조용히" 실패한다

Supabase 대시보드 → **Authentication → URL Configuration → Redirect URLs** 에 추가:
```
bandal://auth/callback
```
에러 메시지 없이 그냥 아무 일도 일어나지 않는 형태로 실패하므로, 이 단계가 가장 잘 빠뜨리는 곳이다.

## 4. 그 밖의 대시보드 설정

- **Database → Extensions** 에서 `pg_cron` 활성화
  (안 켜면 메시지 보존 정책이 안 돌아 무료 DB 500MB가 약 60일에 찬다.
   마이그레이션은 pg_cron이 없어도 에러 없이 NOTICE만 남기고 넘어간다.)
- **Settings → General** 에서 **리전 확인**. `ap-northeast-2 (Seoul)`가 아니면
  실시간 채팅 지연이 체감된다. 데이터가 아직 없으므로 **지금 새 프로젝트로 다시 만드는 게
  나중에 옮기는 것보다 훨씬 싸다.**

## 5. 스키마 적용

`supabase/migrations/`의 `0001` ~ `0009`를 **파일 단위로 통째로, 번호 순서대로**
대시보드 SQL 에디터에 붙여넣어 실행한다. (부분 실행 금지 — 파일 앞부분의
`set check_function_bodies = off` 가 빠지면 실패한다.)

실행할 때마다 **Notices 탭을 확인**할 것. `0008`(실시간)과 `0009`(cron)는 실패해도
에러가 아니라 NOTICE로 넘어가므로, 조용히 안 걸린 걸 모르고 지나치기 쉽다.

적용 후 `supabase/tests/rls_verification.sql` 상단 두 줄에 실제 계정 uuid 2개를 넣고
전체를 실행하면 **38행이 전부 ✅**여야 한다. 자세한 절차는 `supabase/README.md` §6.

## 6. 아직 결정이 필요한 것

| 항목 | 선택지 |
|---|---|
| 무료 프로젝트 7일 무활동 시 일시정지 | 수용(수동 재개) / 주 1회 자동 핑(GitHub Actions, 5분) / Pro 전환 |
| 메시지 보존 정책 | 그룹당 5,000건 · 180일 자동 삭제 승인 여부 + 사용자 고지 문구 |
| 카카오 추가 여부 | 커버리지는 최고, 대신 개발자 앱 등록·동의항목·심사 필요 |
| 개인정보처리방침 / 이용약관 | 닉네임과 채팅 기록을 저장하므로 **배포 전 필수**. 초안이 필요하면 요청 |
