# 설정·플러그인 품질 점검

이 문서는 이번 변경의 구현 범위와 실제 검증 범위를 구분합니다. ‘앱의 모든 버그가 없음’을 증명하는 문서는 아닙니다. 검증은 실제 사용자 데이터 대신 임시 프로필·임시 과목·격리된 Supabase 프로젝트에서 수행했습니다.

## 수정한 주요 문제

- 브라우저·알림·실험 기능·데스크톱 오브의 부분 설정 변경이 같은 그룹의 다른 값을 되돌리던 문제: 메인 프로세스에서 최신 값에 병합합니다.
- 늦게 도착한 초기 설정 응답이 새 push 상태를 덮어쓰던 문제: 초기 조회와 변경 이벤트의 순서를 구분합니다.
- 설정 파일 읽기 실패를 손상으로 취급해 초기화할 수 있던 문제: I/O 오류와 잘못된 JSON을 분리합니다. 저장 실패는 사용자에게 알리고 이전 값을 유지합니다.
- 잘못된 홈페이지를 저장할 때 정상 주소를 비우던 문제와, 정상적인 URL 정규화를 오류로 알리던 문제를 수정했습니다.
- 설정 검색 결과가 카테고리만 보여 주던 문제: 개별 항목 이동·강조·포커스, 플러그인 스키마 검색과 접힌 설정 펼치기를 추가했습니다.
- 플러그인 활성화 중 승인된 설정 API 호출이 거절되던 문제, 한 호스트 장애가 다른 플러그인에 영향을 주던 구조를 수정했습니다.
- 설치/업데이트의 레지스트리 저장 실패 시 이전 실행 파일·승인 상태를 되돌리며, 패널 자산 변경도 재승인을 요구합니다.
- 카탈로그의 워크플로 팩 업데이트가 기존 팩을 그대로 반환하던 문제를 수정했습니다. 업데이트는 기존 ID를 유지하고 승인을 초기화합니다.
- ZIP 압축 해제 시 전체 파일을 먼저 할당하던 경로를 스트림 예산 검사로 바꿨습니다.
- 넓은 화면에서 새 플러그인 편집 메뉴가 기존 compact-only CSS 때문에 숨겨지던 문제를 실행 테스트로 발견하고 수정했습니다.
- 플러그인 테마와 같은 기본 모드를 눌렀을 때 플러그인 테마가 해제되지 않던 문제를 수정했습니다.

## 설정 18개 카테고리

모든 카테고리의 실제 렌더링·사이드바 이동·검색은 `e2e/settingsShell.spec.ts`에서 확인했습니다. 이것만으로 외부 서비스의 실제 로그인·알림·결제/구독 상태까지 검증했다고 보지는 않습니다.

| 카테고리 ID | 점검 대상 | 추가 근거·제한 |
| --- | --- | --- |
| `ai` | 엔진 선택, 설치/준비 상태 | provider·autoProvider·agentAccess 테스트; 실제 유료 계정으로 요청하지 않음 |
| `assistant` | 화면 도우미, 오브 모드·표시 | 부분 저장, desktopPermissionsSlot, desktopOrb E2E |
| `account` | 계정/미연결 상태 표시 | 인증 관련 기존 테스트; 운영 OAuth 로그인은 별도 확인 |
| `general` | 언어, 탭 동작, 온보딩 재실행 | 설정 저장/롤백, 실제 탭 E2E; 일반 토글 저장 실패 알림 |
| `mcp` | 서버 등록·가져오기·권한 | mcpRegistry·mcpServersPanel·mcpImport 테스트; 개인 서버 연결 미실행 |
| `university` | 학교 선택·저장 로그인 | universityStore 테스트; 실제 학교 계정 로그인 미실행 |
| `packs` | 탐색·설치·업데이트·개발자 | v1/v2 실제 설치·활성화·명령·메뉴·패널·설정·감시·복원 E2E |
| `browser` | 홈페이지·검색·줌·링크·접근 | 부분 병합, 잘못된 URL 보존, browser E2E(복원/검색/다운로드 등) |
| `appearance` | 테마·팔레트·밀도·글꼴·배율 | appearance 테스트, 36조합 대비 검사, 테마 전환·복원 E2E |
| `notifications` | 마감·응답·다운로드·소리·억제 | notifier·deadlineScheduler·toggleLeadDay 테스트; 실제 OS 배너는 별도 확인 |
| `shortcuts` | 재지정·충돌·웹뷰 우선권 | ShortcutsPanel·shortcutModel·shortcuts 테스트, ⌘/ E2E |
| `usage` | 사용량·시간·제공자 표시 | formatUsage 및 기존 집계 테스트; 실제 과금 확인 아님 |
| `permissions` | 시스템 권한 상태·설정 이동 | systemPermissions·permissionTone 테스트; macOS 권한을 실제 변경하지 않음 |
| `privacy` | 진단·피드백·데이터 안내 | 기존 진단 관련 테스트; 외부 피드백 제출 미실행 |
| `advanced` | 폴더·캐시·설정 초기화 | 초기화 확인 UI, 설정 복구/원자적 저장 테스트; 사용자 데이터 초기화 미실행 |
| `experimental` | 런타임·오브 실험 플래그 | 부분 병합, 토글 상태 동기화, runtime 검증 |
| `courses` | 보관·복원·목록 | courseArchiveUi, course/material/tab E2E |
| `about` | 버전·업데이트·관련 링크 | aboutPanel·버전 판별 테스트; 서명된 실제 업데이트 배포 미실행 |

## 배포 전 남는 확인

- Windows는 타입·공유 로직·기존 플랫폼 분기 테스트만 확인했습니다. 실제 Windows 실행·설치 패키지와 네이티브 UI는 별도 검증해야 합니다.
- macOS Keychain, 화면 기록·손쉬운 사용 권한 변경, 학교·개인 MCP·유료 AI 계정, 실제 OS 알림은 사용자 환경에서 확인해야 합니다. E2E는 키체인 프롬프트를 피하기 위해 safeStorage를 비활성화한 임시 프로필입니다.
- 운영 마켓플레이스는 배포하지 않았습니다. 서비스 URL·비밀 키·TLS·역할·백업·외곽 rate limit 설정과 스테이징 승인이 필요합니다. [운영 문서](marketplace.md)에 절차와 용량 제한을 정리했습니다.
- 플러그인은 신뢰하는 코드만 실행해야 합니다. VM/프로세스 분리는 OS 수준 보안 샌드박스가 아니며, 설치 파일과 DB의 전원 차단까지 완전한 트랜잭션을 보장하지 않습니다.
- 게시 중단은 신규 다운로드를 차단하지만 이미 설치한 플러그인을 원격으로 자동 삭제하지 않습니다. 사용자 공지는 운영 채널로 별도 제공해야 합니다.

실행 결과를 확대해 ‘모든 설정이 모든 외부 환경에서 완벽하다’고 해석하지 마세요. 확인된 회귀와 로컬 동작은 자동 테스트로 고정했고 외부 확인 항목은 위와 같이 분리했습니다.
