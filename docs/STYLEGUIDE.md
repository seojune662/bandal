# 반달 UI·UX 기준 — 0.58

콘텐츠를 읽고 다루는 데 필요한 위계만 남긴다. 앱의 배경·탐색·버튼은 무채색으로 통일하고 과목 구분색, 상태, 사용자가 작성한 필기 색은 보존한다.

## 단일 기준

- `src/shared/theme.ts`: 활성 모드, 이전 설정 변환, native 창 배경색.
- `src/renderer/src/styles/themes/light.css`, `dark.css`: 의미별 색상 토큰.
- `src/renderer/src/styles/tokens.css`: 시스템 글꼴, 간격, 치수, 모션, 고대비 지원.
- `src/renderer/src/features/settings/settingsTheme.ts`: 모든 렌더러의 테마 해석과 적용.
- `src/renderer/src/app/bootstrapAppearance.ts`: 설정을 읽은 뒤 첫 화면을 렌더링한다. 그 전에는 native 창의 배경이 유지된다.

컴포넌트는 역할에 맞는 토큰을 사용한다. 이전 팔레트 CSS나 플러그인 전역 색상 덮어쓰기를 추가하지 않는다. 같은 선택자를 파일 끝에 다시 선언해 기존 규칙을 덮지 않고, 원래 규칙을 수정하거나 교체한다. 문서 종이, 사용자가 고른 색, 코드 구문 강조와 외부 웹 콘텐츠는 앱 외형 토큰으로 강제 변환하지 않는다.

## 외형과 호환

`ThemePreference`는 `system | light | dark`다. 신규 설치 기본값은 `system`이며, 실제 CSS 모드는 항상 `light | dark` 중 하나다.

| 역할 | 라이트 | 다크 |
|---|---|---|
| 작업 공간 `bg-app` | `#ffffff` | `#212121` |
| 탐색 영역 `bg-surface` | `#f9f9f9` | `#181818` |
| 선택·입력 표면 `bg-raised` | `#eeeeee` | `#303030` |
| 팝오버 `bg-overlay` | `#ffffff` | `#292929` |
| 본문 `text-primary` | `#0d0d0d` | `#ececec` |

`sepia`, `high-contrast`는 라이트로, `midnight`, `graphite`는 다크로 읽는다. 기존 `system`은 유지한다. 이전 `palette`, `pluginTheme`는 설정 읽기 호환 값이며 외형에 적용하지 않는다. 설치된 플러그인의 다른 기능과 데이터는 보존한다. 테마 편집기는 이번 버전에 없다.

PDF와 프레젠테이션 종이는 흰색이다. PDF 주석 도구의 팝오버는 문서와 같은 필기 색을 표시한다. 과목·오류·녹음·할 일 상태는 의미에 맞는 색을 유지한다.

## 화면 구조

전역 레일 48px → 과목 사이드바 240px → 작업 공간 → 자료 패널 288px. 상단은 44px다. 과목·자료 패널의 폭 조절과 기존 저장 폭은 유지한다. 창 버튼과 사이드바 토글은 `ShellChrome`에서만 관리한다. 탭과 창 드래그 영역을 구분하고 Windows 창 제어 버튼 영역을 비운다.

전역 레일에는 과목, 학업 보드, 함께하기, 더 보기를 위쪽에, 계정과 설정을 아래쪽에 둔다. 연결 그래프와 도움말은 더 보기에서 연다. 로그인 복원과 새 소식 표시를 레일 수명에 연결하여 과목 사이드바를 접어도 유지한다.

과목 사이드바는 학교, 검색, 목록 순서다. 과목 제목과 같은 뜻의 영문 소제목을 반복하지 않는다. 빈 즐겨찾기는 안내 한 줄로 표시한다. 행의 보조 동작은 hover와 focus-within에서 드러나며, 키보드로 항상 접근할 수 있어야 한다.

탭은 옅은 선택 배경을 사용한다. 모든 탭 사이에 선을 넣거나 활성 탭에 색 밑줄을 더하지 않는다. 분할 경계와 패널 경계는 얇은 선 하나로 구분한다.

PDF 기본 행에는 페이지, 배율, 주석 진입을 둔다. 주석 작업을 켰을 때 선택·펜·형광펜·지우개·실행 취소를 표시한다. 도형·텍스트·내보내기는 더 보기, 색·굵기·투명도는 스타일 팝오버로 모은다. 좁은 작업 공간에서는 라벨을 줄이고 도구 행을 배치하되 기능 접근을 없애지 않는다.

설정은 왼쪽 카테고리와 오른쪽 설정 행으로 구성한다. 라이트·다크 미리보기 외에 불필요한 카드 테두리를 중첩하지 않는다. 글자 크기, 필기 글꼴, 밀도와 어시스턴트 기능을 유지한다.

## 글꼴·간격·경계

OS 시스템 글꼴을 우선하고 한국어 대체 글꼴을 지정한다. 기본 UI는 14px, 보통 항목은 400, 제목·선택 항목은 500을 사용한다. 노트 본문·사용자가 지정한 서식·코드 글꼴은 별도다. 간격은 공통 4px 계열 토큰을 사용한다.

선을 추가하기 전에 여백이나 배경으로 구분할 수 있는지 확인한다. 테두리와 그림자로 같은 경계를 두 번 강조하지 않는다. 그림자는 실제로 떠 있는 팝오버·대화상자에 한정한다. 검색창과 보조 버튼은 낮은 대비의 배경을 사용하며, 위험 동작·포커스의 대비를 약하게 만들지 않는다.

새 버튼·메뉴·설정 행은 기존 공통 요소를 사용한다. 화면의 책임이 커지면 역할별로 분리한다. 과목 목록의 행은 `CourseListItem`, 드래그 수명은 `useCourseDrag`, 메뉴의 닫힘·포커스 복귀는 `useDismissableMenu`, 설정 행은 `features/settings/primitives`를 기준으로 한다.

## 접근성과 상호작용

- 키보드 포커스는 `focus-ring`으로 명확하게 표시한다. 선택 배경과 구별한다.
- 아이콘 버튼에는 접근 가능한 이름을 제공한다. 단축키는 입력창과 숨겨진 문서에서 실행하지 않는다.
- 팝오버는 Escape와 바깥 클릭으로 닫고, Escape 후에는 실행 버튼으로 포커스를 돌려준다. 창 경계와 확대 상태에서는 `useViewportBounds`로 위치를 보정한다.
- 테마 선택은 방향키·Home·End를 지원하는 라디오 그룹이다.
- `prefers-contrast: more`, `forced-colors: active`, `prefers-reduced-motion`을 존중한다.
- 본문/표면 대비 4.5:1, 의미 있는 상태·과목 색 3:1을 검증한다. PDF 하이라이트는 흰 종이와 검은 본문 기준으로 검사한다.

## 성능·검증

초기 설정 조회는 `ensureSettingsLoaded()`로 공유한다. 변경 방송은 동일한 캐시를 갱신한다. 화면의 구독은 사용하는 상태에만 연결한다. 숨겨진 과목·탭은 입력을 처리하지 않는다. 기존 작업 프로세스, 과목 캐시, 문서 지연 로딩, 자료 목록 가상화를 보존한다.

대표 화면은 합성 자료를 사용하는 실제 Electron 창에서 라이트·다크 및 1024×640/1440×900으로 확인한다. 테마 변경·이전 설정 변환·재시작·별도 창 동기화와 과목/자료/즐겨찾기/탭 드래그를 검사한다. CSS 변경도 `scripts/affected-checks.mjs`가 관련 테마·사이드바·설정 검사를 선택한다.

측정은 같은 기기와 임시 프로필에서 비교한다. 시작은 여러 실행의 중앙값, 상호작용은 프레임 반영 시간의 P95로 기록한다. 목표는 과목 전환 P95 <150ms, 100회 전환 후 GC 힙 증가 <32MB, 50개 탭 복원 시 선택한 노트만 읽기다. 수치가 이미 충분히 낮다면 개선으로 과장하지 않고 유지 여부를 보고한다.
