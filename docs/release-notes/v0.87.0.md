# v0.87.0 — 공식 커뮤니티와 공부 도구 공모

왼쪽 학습자료 마켓플레이스를 **공식 커뮤니티**로 교체한다. 기존 계정과 닉네임으로 공모 참여·공부법 공유·질문과 피드백을 작성하고 댓글·공감·신고를 남긴다. 운영자는 공지를 고정하고 게시글·댓글을 숨기며 신고를 처리할 수 있다. 사용자 커뮤니티 생성·학교 인증·채팅은 이번 버전에 포함하지 않는다.

‘반달에 있었으면 하는 공부 도구 공모전’은 공부 상황·현재의 불편·도움받을 순서·사용 장면의 네 항목으로 응모한다. 1등 한 명 10만 원, 2등 한 명 5만 원이며 실제 도움 40점·사용 과정의 구체성 30점·구현 가능성 20점·독창성 10점으로 운영자가 심사한다. 공감 수는 참고만 한다. 수상과 개발 채택은 별도이며 같은 글에 개발 상태와 검토 이유를 남긴다.

공모는 **미공개 준비 상태, 모든 일정 미정**으로 배포한다. 운영자가 일정과 모집 요강을 확정해 공개한 뒤 앱과 웹에서 같은 서버 상태를 읽어 안내한다. 접수 중 앱 안내창은 공모별 한 번 표시하고 커뮤니티 배너를 유지한다. 웹 `/community/contest`는 모집 안내만 제공하며 응모작은 공개하지 않는다. 휴대폰에서는 컴퓨터 참여 안내와 링크 복사, 컴퓨터에서는 앱 열기와 다운로드를 제공한다.

로그인 후 응모로 복귀하고 작성 실패 시 계정별 초안을 보존한다. 서버에서 작성자·운영자 권한, 요청 중복과 접수 마감을 검증하며 접수 내용의 변경 불가 사본을 남긴다. 마감 후 응모 내용 변경을 막고, 결과 공개 전 수상 정보는 운영자만 확인한다.

자료 판매 메뉴와 신규 거래는 종료한다. 종료 전 운영 DB에서 주문·상품·정산 기록이 각각 0건임을 확인했다. 기존 거래·환불·구매 자료 처리와 사용자 자료는 보존하며 설정의 플러그인 마켓은 유지한다.

## 검증 범위

- 커뮤니티 API·딥링크·작성 초안·로그인 복귀·신고 및 운영자 화면, 신규 자료 거래 차단과 기존 구매 처리의 관련 단위 검사를 수행한다.
- 실제 임시 PostgreSQL에서 RLS·익명 접근 제한·작성자/운영자 권한·마감·심사 사본·계정 삭제·동시 요청 및 수상 경쟁을 검증한다.
- Electron에서는 커뮤니티 전환과 기존 작업 보존, 준비 중 홍보 숨김, 안내창 한 번 표시, 실패 후 응모 재시도·댓글·공감을 확인한다. 기존 구매 이력·자료 가져오기 회귀도 유지한다.
- 웹에서는 준비·예정·접수·마감 상태, 모바일 안내·링크 복사·앱 열기, 익명 안내 전용 통신과 기존 결제 복귀를 Chromium·WebKit에서 확인한다.
- 앱 패키지의 macOS 서명·공증, Windows 설치 파일과 공개 업데이트 피드는 기존 릴리스 절차로 확인한다. 실제 개인 계정의 외부 OAuth 로그인과 상금 지급은 모의 응답·DB 자동 검사와 구분한다.
