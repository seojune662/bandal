# v0.90.3 — 과목·프로젝트와 통합 AI

홈에서 **과목 / 프로젝트**를 전환하고, 가운데에서 여러 자료를 열어 작업하며, 오른쪽에서 **자료 / AI**를 사용한다. 문서 안에 반복되던 미니 AI와 왼쪽의 독립 학습·AI·도구 진입을 정리했다.

- 과목과 프로젝트는 같은 폴더형 목록으로 탐색한다. 프로젝트 그룹 생성·이름 변경·이동·드래그 정렬을 지원하며, 영어 읽기와 과목 복습은 프로젝트 종류로 표시한다. 목록 탭 전환은 현재 작업 공간을 바꾸지 않는다.
- 프로젝트마다 문서 탭과 분할 배치, 오른쪽 패널, 선택한 대화와 작성 중인 내용을 보존한다. 글·단어장·퀴즈·카드를 독립 탭으로 동시에 열 수 있다. 연결된 원본 자료도 프로젝트 안에서 열며 명시적으로 원본 과목을 열 때만 공간을 바꾼다.
- 자료 상단에 보기 방식·가져오기·생성하기·새로고침을 배치했다. 목록·아이콘·열·갤러리를 유지하며 파일 가져오기·생성·붙여넣기·드롭은 현재 프로젝트의 자료 루트를 따른다.
- AI는 Chat·퀴즈·플래시카드·예상 문제 모드를 제공한다. 전환만으로 요청을 실행하지 않으며 대화·초안·첨부를 유지한다. 생성 결과에는 저장 위치와 열기 동작을 제공하고, 추가 조건과 여러 원본 자료를 생성 요청에 전달한다. 추가 AI 도구는 AI 더보기, 일반 플러그인은 앱 더보기에서 실행한다.
- 자료 선택기로 여러 파일을 첨부하거나 Annotate로 PDF·웹페이지·마크다운·이미지의 부분을 계속 모을 수 있다. 선택 당시의 본문·위치·캡처와 사용자 코멘트를 보존하고, 여러 분할 화면에서 모은 참조를 한 질문에 전달한다. 선택 모드는 완료·Esc·전송·공간 변경으로 종료된다. 전송 실패 시 초안과 참조를 보존한다.
- 브라우저 선택은 살아 있는 페이지의 의미 있는 요소를 사용한다. PDF는 열을 구분한 텍스트 후보, 이미지·스캔 문서는 페이지 또는 직접 영역 선택을 제공한다. 작은·큰 후보를 조정할 수 있으며 OCR은 추가하지 않았다. 한 번에 최대 20개 참조를 명시적으로 제한하고 오래된 참조를 자동 삭제하지 않는다.
- 기존 폴더·학습 ID·풀이 기록·카드 일정·출처를 유지한다. 과거 중앙 AI와 미니 AI 대화는 같은 대화 ID로 오른쪽에서 접근한다. 레이아웃 이전 전 원본을 보존하고, 프로젝트 폴더 이동·복사·삭제·복원 시 관련 메타데이터를 함께 처리한다.

## 검증 범위

변경된 저장소·작업 공간·학습·자료·AI·Annotate의 단위 회귀와 node/web/web-demo 타입 검사를 수행한다. 영향 검사 선택기에 Annotate·통합 AI 생성·프로젝트 그룹 시나리오를 연결했다.

실제 Electron 검사에는 과목·프로젝트 전환과 재시작 복원, 그룹 정렬, 독립 자료의 분할과 기록 저장, 네 가지 자료 보기, 경로 분리, AI 모드·실패·취소·기존 대화, PDF·웹·마크다운 연속 참조, 원문 수정·탭 닫기·실패 후 참조 보존, 네이티브 브라우저 상호작용, 밝은/어두운 테마·좁은 창·키보드 탐색을 포함한다.

AI 응답·로그인·생성 결과와 외부 사이트는 임시 프로필과 고정 fixture로 검사한다. 개인 계정의 실제 AI 응답·로그인, OS 권한 허용은 자동으로 수행하지 않는다. iPad는 디자인 참고이며 이번 UI 변경 대상은 데스크톱이다. 실제 기출 수집·풀이와 스캔 OCR은 포함하지 않는다.

Windows 설치 파일은 기존 배포 설정과 같이 미서명이다. macOS ARM·Intel의 Developer ID 서명·공증, 모든 설치 파일과 업데이트 피드의 버전·무결성·공개 상태는 릴리스 작업으로 검증한다.

## 공개 검증

v0.90.0은 Windows 설치본 검사 160개 중 158개가 통과했고, 좁은 탭을 선택하려던 검사 클릭이 중앙의 닫기 버튼을 눌러 두 항목이 실패했다. 공개하지 않았으며 v0.90.1에 검사 수정을 포함했다. 기존 hover 닫기 동작은 유지하고 키보드로 탭을 활성화해 탭 수·네이티브 페이지·필기 연결이 보존되는지 확인한다.

v0.90.1도 공개하지 않았다. Windows 설치본 검사 160개 중 159개가 통과했으나, PDF 지연 복원 검사에서 10쪽 이동 후 11쪽이 표시되어 실패했다. 좁은 문서 영역에서 가로로 짧은 10쪽은 상단에 정상 배치됐고, 화면 중앙이 11쪽에 있어 중앙 페이지를 표시하는 기존 동작과 검사 전제가 충돌했다. 저장 위치 응답을 반환하기 전 발생한 현상으로, 지연 복원이 사용자 이동을 덮어쓴 문제는 아니었다. 후속 v0.90.2는 세로 문서로 복원 우선순위를 검사하고 목표 페이지가 화면 중앙을 포함하는지도 확인한다. macOS도 160개 중 159개를 통과했으나, 부분 선택 후 즉시 완료하면 진행 중인 캡처를 폐기하여 참조가 빠지는 경합을 발견했다. 선택 UI의 종료와 이미 클릭한 참조의 저장을 분리하고 전송 전에 남은 캡처를 기다리는 수정을 v0.90.2에 포함한다.


v0.90.2는 macOS 설치본 검사 160개 모두 통과했지만 Windows에서 160개 중 159개가 통과해 공개하지 않았다. 첫 사용자 AI 연결이 빠르게 완료되면 실제 로그인 탭이 열린 직후 내부 탭 목록이 갱신되기 전 종료 신호가 도착하여 임시 탭 하나가 남았다. 후속 v0.90.3은 실제 Dockview 패널을 우선 조회하고, 종료된 요청의 지연 탭 열기를 차단한다. 같은 과목의 프로젝트 사이에서도 로그인 탭의 원래 작업 공간을 유지한다.
