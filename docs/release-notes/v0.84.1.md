# v0.84.1 — 읽기 편한 AI 대화

- AI가 자료를 읽고 요청한 작업을 진행할 때 매번 허용을 누르지 않아도 됩니다. 새 대화와 이전 기본 설정의 대화에 자동 실행을 적용하며, 직접 선택한 제한 설정은 유지합니다.
- 실행 명령과 내부 추론 대신 현재 진행 상태 하나만 보여줍니다. 완료 후에는 답변 본문에 집중할 수 있습니다.
- 수식, 표, 중첩 목록을 읽기 좋은 형태로 표시합니다. 작성 중인 수식도 원문 기호가 화면에 쏟아지지 않습니다.
- 답변 복사와 최신 답변으로 이동을 추가했습니다. 이전 내용을 읽거나 다음 질문을 입력하는 동안 화면과 포커스가 유지됩니다.
- 별도 확인이 필요한 경우 입력창 위에 간결한 확인 영역을 표시합니다.

## 검증 범위

허용 정책·기존 대화 설정 전환·제공자 실행 옵션·수식/Markdown·대화 표시 회귀 검사를 수행합니다. Electron 화면에서는 실제 렌더러에 재현용 응답을 주입해 작성 상태, 수식·표, 좁은 패널, 밝은/어두운 테마, 스크롤, 입력 유지와 예외 확인 처리를 검사합니다. 릴리스 CI는 동일 커밋의 검사 결과와 양쪽 플랫폼의 패키지 검증을 통과한 뒤 설치 파일과 업데이트 피드를 공개합니다.

실제 개인 계정 인증, 서비스별 모델 응답, 운영체제의 화면 접근 허용은 모의 응답 검사와 구분합니다. macOS 설치 파일은 서명·공증하며, Windows 설치 파일은 기존과 같이 코드 서명이 없습니다.

기존 iPad 연동 변경에 추가된 PDF 주석 갱신 이벤트의 테스트 구독을 보완하고, 저장 중 외부 주석 갱신과 구독 해제를 검증했습니다. v0.84.0은 공개 전 검사에서 중단됐으며 사용자에게 배포하지 않았습니다.
