# v0.97.0 — 탭에도 꾸미기, 오른쪽 위 공유 버튼

v0.96의 글래스·팔레트는 양쪽 사이드바에만 적용되고 탭 줄, 탭이 없을 때의 가운데 화면, 오른쪽 사이드바 아래 위젯 영역에는 적용되지 않았다. 이번에 이 부분까지 넓혔다. 열린 탭을 바로 공유하는 버튼도 추가했다.

## 바뀌는 점

- **탭 줄**: 탭 줄 바탕이 사이드바와 같은 글래스로 바뀌어 고른 팔레트 색이 비친다. 선택한 탭은 아래 문서와 같은 색으로 이어지고, 맞닿는 양쪽 아래 모서리를 안쪽으로 둥글게 처리해 탭과 문서가 한 장처럼 보인다. 지금 작업 중인 분할의 탭은 위쪽 테두리선, 아이콘, 위에서 내려오며 옅어지는 바탕에 팔레트 강조색을 쓴다. 분할 화면에서 다른 쪽의 선택 탭은 강조색 없이 조금 흐리게 보인다. 선택하지 않은 탭은 마우스를 올리면 팔레트 색 알약으로 표시된다.
- **탭이 없을 때**: 가운데 빈 화면에도 꾸미기를 옅게 입혔다. 종이 바탕 아래로 팔레트 메시가 살짝 비치고, 반달 로고는 팔레트 색에 옅은 강조색 그림자를 띤다. 새 필기·웹 탐색·AI와 공부 카드는 글래스 카드에 강조색 아이콘을 쓴다. 분할 화면의 빈 영역 로고도 같은 색을 쓴다.
- **오른쪽 사이드바 아래**: 외부 자료와 위젯(투두·보드·메일) 영역의 불투명 회색 바탕을 없애 사이드바 글래스가 끝까지 이어진다. 위젯 카드는 밝은 반투명 카드로, 아이콘은 팔레트 강조색으로 바꿨다. 다크 모드에서 카드 안 입력칸과 범위 선택이 새까맣게 뜨던 것도 글래스 입력칸으로 맞췄다.
- **공유 버튼**: 오른쪽 위 모서리 버튼 묶음(탭 바, 윈도우 관리, 사이드바) 맨 왼쪽에 공유 버튼을 추가했다. 지금 열린 탭을 그대로 공유한다.
  - PDF: 필기와 하이라이트를 넣은 PDF(원본 파일 이름 그대로)
  - 마크다운 노트: 저장을 마친 `.md` 파일
  - 이미지·문서 파일: 파일 그대로
  - 브라우저: 지금 보고 있는 페이지 주소
  - macOS는 시스템 공유 메뉴(AirDrop·메일·메시지·카카오톡 등)를 버튼 아래에 띄운다. Windows에는 Electron이 쓸 수 있는 공유 창이 없어서 링크는 클립보드에 복사하고, 파일은 탐색기에서 위치를 연다.
  - 채팅·보드·화이트보드·녹음·학습 탭에서는 버튼이 비활성화된다.

## 검증

- 단위 검사: `tests/main/share/shareSheet.test.ts`. macOS 메뉴 항목(파일·링크), 주석 PDF 사본의 이름과 다음 공유 때 이전 사본 정리, 공유 메뉴가 없을 때 링크 복사와 파일 위치 열기, http(s)가 아닌 주소와 잘못된 대상 거절을 확인한다.
- 단위 검사: `tests/renderer/app/shareTabButton.test.ts`. 브라우저 탭은 현재 주소를, 없으면 마지막 이동 주소를 쓰고 웹 주소가 없으면 공유하지 않는지 확인한다. 노트는 저장 후 바뀐 이름으로 공유하고 저장 실패 시에는 공유하지 않으며, 채팅·보드 탭은 공유 대상이 아닌지도 확인한다. `workspaceControls.test.tsx`는 버튼 순서(공유가 맨 앞)를 갱신했다.
- E2E: `e2e/shareTab.spec.ts`. 탭이 없으면 버튼이 비활성화되고, PDF와 마크다운 탭에서 이름이 바뀌며, 각각 맞는 공유 요청(PDF는 주석 포함)을 보내는지 확인한다.
- 탭 영향 E2E(`tabDrag`, `workspaceWindows`, `workspaceNarrowTabs`, `sidebars`, `designRefresh`)가 통과한다. 처음 구현에서는 두 가지 문제로 실패했다. 탭 상자 안쪽 여백 때문에 가장자리 가운데 버튼 클릭이 닫기 처리기에 닿지 않았고, 탭 밖으로 그린 둥근 모서리가 탭 줄을 넘쳤다. 그래서 탭 상자 전체를 클릭 영역으로 되돌리고 모서리를 탭 상자 안에 그렸다. `workspaceWindows`의 모서리 버튼 개수 기대값은 3에서 4로 바꿨다.
- `newTabCycle`의 "네 번째·다섯 번째 종류" 검사는 이번 변경 전 `main`(v0.96.2)에서도 실패한다. v0.96에서 AI가 탭 대신 왼쪽 AI 패널로 열리게 된 뒤 검사를 갱신하지 않았기 때문이다. 이번 범위가 아니라 고치지 않았다.
- macOS 개발 빌드에서 실제 공유 메뉴가 버튼 아래에 뜨는 것을 직접 확인했다. 라이트·다크와 새벽·노을·숲 팔레트로 탭 줄, 분할 화면, 위젯 영역 스크린샷도 확인했다.
- 2026-11-12 공개했다. 릴리스 커밋은 `d23ff2d`, 릴리스 run은 43224572523이다. 첫 실행에서 macOS 빌드가 러너를 받지 못해 0단계로 15분 만에 취소됐다(arm64 러너 부족, 코드 문제 아님). Windows 빌드는 성공해 유지했고, `gh run rerun --failed`로 macOS 빌드와 게시만 다시 돌려 모두 성공했다. iPad 도우미 3종도 성공했다.
- 태그 전에 같은 커밋에서 `pnpm deadcode`를 통과했다. 설치본 E2E가 고를 영향 스펙 12개(`shareTab`, `workspaceWindows`, `shareImport`, `accountProfileBackup`, `theme`, `sidebars`, `settingsShell`, `uiRedesign`, `tabDrag`, `favoritesDrag`, `materialsDrag`, `viewportMenus`)도 개발 빌드에서 통과했다.
