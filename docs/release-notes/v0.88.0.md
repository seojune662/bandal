# v0.88.0 — Cmd+T 탭 선택과 학교 위치

학교 이름과 바로가기를 제목 막대에서 과목 사이드바 안으로 옮겼다. 학교는 AI 바로 위에 같은 왼쪽 정렬로 표시하며, 일반 창과 전체화면 모두 창 버튼 아래 간격을 유지한다.

Cmd(macOS) 또는 Ctrl(Windows)를 누른 채 T를 누를 때마다 브라우저 → 마크다운 → 노트 → AI → 녹음 → 브라우저 순서로 선택한다. 보조키를 놓으면 선택한 종류의 탭 하나만 열린다. 선택 중에는 탭을 만들지 않으며, T를 길게 누르는 자동 반복은 무시한다. Esc나 다른 앱으로 전환하면 취소한다. 브라우저 페이지에 키보드 초점이 있어도 같은 동작을 지원한다.

세 번째 노트는 추가 선택창 없이 설정의 기본 종이·방향으로 바로 생성한다. + 메뉴의 검색·URL 입력·종이 선택과 종류별 전용 단축키는 유지한다. 새 탭 메뉴와 탭 설정도 브라우저·마크다운·노트·AI·녹음 순서로 맞췄다. 사용자가 새 탭 단축키를 다른 조합으로 재설정한 경우 기존 검색 메뉴 동작을 유지한다.

## 검증 범위

- 학교 위치 오류를 기존 빌드에서 재현하고, 수정 후 일반 창·전체화면의 AI 정렬을 확인한다.
- 키 순환·되돌아오기·빠른 해제·중복 해제·자동 반복·취소·사용자 단축키와 기본 종이 생성·과목 전환 중 저장을 단위 검사한다.
- 실제 Electron과 배포용 macOS·Windows 앱에서 새 탭 생성, 네이티브 브라우저 입력과 분할 영역 배치를 확인한다.
- 릴리스는 같은 커밋의 CI 결과를 재사용하며 macOS 서명·공증, 설치 파일 업로드 무결성과 양쪽 업데이트 피드 공개를 확인한 뒤 완료한다.

실제 OS 마이크 권한·녹음, 외부 AI 로그인과 개인 데이터 연동은 이번 변경의 자동 검사 대상이 아니다. Windows 설치 파일은 기존과 같이 미서명이다.
