# v0.55.0 — 주소창과 방문 기록 바로가기

브라우저 주소창은 평소에 `youtube.com`처럼 도메인만 간결하게 표시합니다. 클릭하거나 ⌘L / Ctrl+L을 누르면 원래 주소 전체를 선택해 편집·복사할 수 있습니다. 영상 ID·재생목록·언어 등 실제 주소의 매개변수는 이동할 때 그대로 보존합니다. HTTP 주소의 보안 표시는 유지합니다.

- 주소창을 누르면 최근 방문 페이지와 저장한 바로가기를 보여줍니다.
- 입력한 제목·주소를 방문 기록, 즐겨찾기, 학교 바로가기, 현재 열린 탭에서 함께 찾습니다. 여러 단어와 한글 경로로도 검색할 수 있습니다.
- 추천에 ‘방문 기록’, ‘즐겨찾기’, ‘열린 탭’을 표시하고 ‘바로가기’ 아래에 모았습니다. 열린 탭은 처음 연 주소 대신 현재 페이지 제목과 주소로 찾습니다.
- 기본 Enter는 입력한 주소 이동 또는 웹 검색을 실행합니다. 방향키나 마우스로 고른 바로가기는 해당 페이지를 엽니다. 늦게 도착한 추천이 선택한 항목을 바꾸지 않으며 Escape는 편집을 취소합니다.
- 한글 조합 중 Enter로 이동하는 문제와 이전 검색 결과가 잠깐 섞이는 문제를 수정했습니다. 시크릿 탭은 추천에서 제외하고 시크릿 모드에서는 방문 기록을 조회하지 않습니다.
- 추천 목록은 웹페이지 위에 표시하고 창 크기에 맞게 높이를 제한합니다. 좁은 분할 화면에서는 주소창에 별도 줄을 배정해 입력 공간을 확보합니다.

검증: 타입 검사·미사용 코드 검사·전체 단위 검사, 실제 Electron에서 주소 보존·편집 취소·최근 방문·마우스/키보드 선택·작은 창과 확대 화면을 확인했습니다. 주소창 E2E는 macOS·Windows 설치 파일 게시 전에도 실행합니다.
