# v0.81.1 — 가려진 페이지의 구글 계정 선택 보존

## 변경

- 구글에서 B 계정 선택이 완료되는 순간 주소 제안이나 툴팁이 브라우저를 가리고 있어도, 다시 표시될 때 선택을 한 번 반영한다. 유튜브를 열 때 A 계정으로 되돌아가는 앱 내부 타이밍 문제를 수정한다.
- 로그아웃·쿠키/사이트 데이터 삭제·새 계정 선택·탐색 실패 후에는 대기 중인 오래된 선택을 폐기한다. 이전 구글 탭을 다시 표시하는 것만으로 이미 사용한 계정 선택을 반복 적용하지 않는다.
- 구글에서 선택한 계정을 유튜브 첫 요청에 전달하는 기능과, 인증·API·영상 요청의 불필요한 추적 검사 콜백 제거를 포함한다. 상세 동작과 범위는 [v0.80.3 변경 기록](v0.80.3.md)을 따른다.
- 계정 전환 E2E가 이전 탭이나 이전 탐색 완료를 새 결과로 오인하지 않도록 보완한다. 브라우저 배치 검사는 툴팁을 닫은 실제 표시 상태에서 수행하며, 실패 시 겹치는 UI와 위치 정보를 기록한다.

## 검증

- 가려진 페이지에서 완료한 구글 계정 선택을 놓치는 단위 재현을 수정 전 실패·수정 후 통과로 확인했다.
- 계정 선택과 네이티브 탭 관련 단위 검사 99개, 메인 TypeScript 검사를 통과했다.
- 최신 변경을 합친 앱에서 격리된 HTTPS 페이지를 사용하는 Electron 계정 전환과 브라우저 배치 E2E 2개를 통과했다. 패키지 배포는 변경 영역의 macOS·Windows E2E, macOS 서명·공증, 설치 파일 무결성·업데이트 피드 공개를 확인한다.

## 외부 검증 범위

개인 Google 계정 2개를 이용한 실제 로그인·계정 전환과 Google 서버 응답 시간, 실제 영상 버퍼링은 자동 검증하지 않았다. 계정 번호가 명시된 구글 탐색의 전달과 앱 내부 요청 처리 경로를 검증하며, 외부 서비스의 속도나 계정 처리 결과를 보장하지 않는다.
