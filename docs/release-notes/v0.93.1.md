# v0.93.1 — 로그인 선택화와 Bandal Sync 종료(D0)

2026-11-04(D0) 릴리스다. 반달 서버를 거치던 Bandal Sync를 끝내고 로그인을 선택으로 바꾼다. D0 진행표는 [`../sync-retirement-d0.md`](../sync-retirement-d0.md)를 따른다.

## 바뀌는 점

- 로그인은 선택이다. 로그인하지 않아도 자료와 필기 기능을 모두 쓴다. 커뮤니티처럼 계정이 필요한 기능에서만 로그인을 요청한다(#2).
- 계정 동기화와 Paddle 구독 화면을 숨긴다. 카카오 로그인을 없앤다(#2).
- 자료 폴더 위치를 옮길 수 있다. Windows 설치본 E2E로 옮기기·중단·재설치를 검사한다(#2, #26).
- 메일 위젯의 Gmail 받은편지함을 웹메일 버튼으로 바꾼다. 저장된 Gmail 로그인은 설정에서 연결 해제할 수 있다(#18, #19).
- 설정창을 공용 설정 키트로 다시 만든다. 검색 순위와 설정 딥링크를 추가한다(#29).
- 과목 색에 빨강을 추가한다(#5). 셸 토큰·포커스·검색 표시를 다듬는다(#10).
- Windows에서 제거할 때 `bandal://` 레지스트리를 정리한다(#27).
- Windows에서 앱이 자료 폴더를 옮기다 강제 종료된 뒤 다시 옮기면 `ENOTEMPTY`로 실패하던 문제를 고친다. 남은 임시 폴더(`.partial`)를 지울 때 잠깐 잡혀 있는 파일 핸들을 기다려 다시 시도한다.
- 새 iCloud·Google Drive 동기화 엔진은 들어 있지만 플래그 뒤에 있어 사용자에게 보이지 않는다(#8–#24). 플래그 제거(#22)는 동기화 출시일에 한다.

## v0.93.0을 공개하지 않은 이유

v0.93.0은 패키지 앱 E2E에서 두 검사가 macOS·Windows 모두 실패해 공개하지 않았다. 둘 다 v0.92.9에서도 실패하는 오래된 검사였고 제품 회귀가 아니다. v0.92.9 릴리스는 영향 범위 선택에서 이 검사를 고르지 않아 드러나지 않았다.

- `pluginsV2` 패널 다시 열기: 새 탭 메뉴는 v0.88.0부터 기본 탭 종류만 보여 준다. 검사가 플러그인 패널을 새 탭 메뉴에서 찾고 있었다. 자료 메뉴에서 다시 여는 방식으로 고쳤다.
- `interactionStability` 탭 복귀: 자료 목록은 2026-10-29부터 보이는 줄만 그린다. 목록이 스크롤된 뒤 `note-0.md` 줄이 DOM에 없었다. 줄이 생길 때까지 목록을 스크롤한 뒤 누르도록 고쳤다.
- macOS의 `workspaceCourseDrop` 그룹 합치기 실패는 로컬 재실행에서 통과해 일시적 실패로 본다.
