# v0.84.6 — Sync 구독 관리와 동기화 이용 안내

- iPad 메뉴의 **구독 관리**에서 반달 웹사이트의 이용권·결제수단·영수증·갱신 해지를 확인할 수 있습니다.
- 동기화에 이용권이 필요하거나 5 GiB 저장 공간을 초과하면 이유와 해결 방법을 안내합니다. 서버의 내부 오류나 개인 파일 정보는 안내에 노출하지 않습니다.
- 구독이 끝나도 기존 자료를 내려받고 반영할 수 있습니다. 새로운 업로드·수정은 보류하며, 기기의 파일과 대기 중인 변경을 보존합니다. 로컬 기본 기능과 수동 파일 전송은 유지합니다.
- 웹사이트에 월간 4,900원·연간 49,000원(VAT 포함) Live 구독 결제와 사용량 표시를 추가했습니다. Sandbox 결제는 실제 동기화 권한을 주지 않습니다.

## 검증 범위

결제 정책·서비스 61개, 실제 격리 Auth/Postgres 결제 검사 16개, 실제 Storage HTTP·동시 용량 검사 10개, 연결 도구 Python 검사 10개와 Electron 구독 메뉴 검사를 통과했습니다. 메인 타입·앱 빌드와 Deno 진입점 검사도 통과했습니다. CI와 설치 파일 검사는 변경 기능에 맞춰 선택합니다.

Live 결제 설정과 실제 금액 청구는 구분합니다. 자동 검사는 실카드 청구·환불·정산을 실행하지 않습니다. iPad 앱은 개발 배포 단계이며, 이용 가능한 iPad 앱 설치를 확인한 뒤 구독하도록 웹사이트에서 안내합니다. 이번 변경은 iPad 공개 App Store 배포나 실제 두 기기의 동시 편집 검증을 의미하지 않습니다.

macOS 설치 파일은 서명·공증하고, Windows는 기존처럼 코드 서명이 없습니다. 두 플랫폼 설치 파일과 자동 업데이트 피드를 모두 확인한 뒤 공개합니다.
