# v0.87.3 — 브라우저 입력·자료 검색과 공식 커뮤니티

왼쪽 사이드바의 학교와 과목 목록을 약 44px 위로 당기고, 로그인된 ChatGPT의 Home 아이콘 hover가 막히던 입력 처리를 수정한다. 웹사이트가 지정한 창 드래그 스타일을 브라우저 페이지에서 초기화하며, 새로고침·새 탭·팝업에서도 적용한다. HTTP 인증 입력과 취소를 구분하고 인증서·권한창 실패 시 요청을 완료한다. 실제 로그인 확인과 점검 범위는 [브라우저 변경 안내](v0.87.1.md)와 [감사 기록](../audit-browser-2026-10-21.md)에 기록했다.

자료 검색 결과가 화면에 나타나지 않던 CSS 오류도 수정한다. 검색 행에 미리보기의 숨김·고정 위치 스타일이 잘못 적용되어 클릭할 수 없었다. 검색 행과 미리보기의 스타일을 분리해 목록에서 자료를 열 수 있게 복원한다.

공식 커뮤니티와 공부 도구 공모 기능, 기존 거래·자료 기록의 보존을 포함한다. 공모는 **미공개·일정 미정** 상태를 유지한다. 기능과 운영 준비 범위는 [커뮤니티 변경 안내](v0.87.0.md)와 [통합 안내](v0.87.2.md)를 따른다.

## 공개 전 검사에서 수정한 문제

v0.87.0은 통합 배포를 위해 중단했고, v0.87.1은 커뮤니티 검사 누락으로 공개하지 않았다. v0.87.2는 패키지 검사에서 위 자료 검색 오류와 Windows 자동 hover의 툴팁 표시 실패를 발견해 공개하지 않았다. Windows 검사는 OS 커서와 자동 입력 좌표를 맞추고 실제 툴팁 표시·페이지 복원을 확인하도록 보완했다. macOS에서는 OS 커서를 조작하지 않는다.

macOS·Windows 설치본의 변경 기능 E2E, macOS 서명·공증, 업로드 무결성과 공개 업데이트 피드를 검증한 뒤 배포한다. 실제 OS 장치 권한, 학교 SSO, 개인 인증서·브라우저 로그인 가져오기와 공모 상금 지급은 자동 검증 범위와 구분한다.
