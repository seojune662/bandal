# v0.80.3 — 구글 계정 전환과 브라우저 요청 처리 개선

## 변경

- 구글 페이지에서 A→B 계정으로 전환한 뒤 유튜브를 열 때, 명시된 계정 번호를 첫 탐색에 한 번 전달한다. 주소창·새 탭과 구글 페이지의 링크에 적용하며 유튜브가 열린 뒤에는 사이트 자체 계정·채널 선택을 따른다.
- 인증 쿠키를 복사하거나 변경하지 않는다. 선택 정보는 프로필·시크릿 세션별 메모리에만 두고, 로그아웃·쿠키/사이트 데이터 삭제·시크릿 종료 시 폐기한다. URL에 계정 정보가 없거나 인증 콜백이면 계정을 추측하지 않는다.
- 모든 URL에 걸려 있던 추적 검사 콜백을 알려진 추적 도메인과 로컬 파일, 필요한 계정 탐색으로 제한한다. Google 인증·YouTube API·Googlevideo 요청은 이 추적 검사 때문에 메인 프로세스를 왕복하지 않는다. 기존 추적 방지 설정과 로컬 파일 차단은 유지한다.

## 검증

- 수정 전 격리 Electron 재현에서 구글 B 선택 후 유튜브가 계정 정보 없이 열리는 것을 확인했다.
- 계정 전달·명시적 계정 선택·프로필/시크릿 분리·로그아웃/삭제·탐색 수명에 대한 단위 검사와 관련 TypeScript 검사를 수행한다.
- 격리된 HTTPS 테스트 페이지로 첫 유튜브 요청에 B가 전달되는지, 중복 요청이 없는지, 이후 사이트 자체 계정 전환을 보존하는지 검사한다.
- 실제 앱에 등록된 Chromium 필터로 인증·API·영상 요청 240건을 처리하면서 불필요한 추적 검사 콜백이 0회임을 검사한다. 추적 도메인·trailing-dot 별칭·설정 즉시 변경·로컬 파일 차단도 확인한다.
- 배포는 동일 커밋 CI를 재사용하고 macOS·Windows 패키지의 영향 범위 E2E, macOS 서명·공증, 설치 파일 무결성·자동 업데이트 피드 공개를 확인한다.

## 외부 검증 범위

실제 개인 Google 계정 2개를 이용한 로그인·계정 전환과 Google 서버의 응답 시간, 실제 영상 버퍼링은 자동 검증하지 않았다. 테스트는 반달의 계정 선택 전달과 불필요한 요청 처리 제거를 검증하며, 특정 시간만큼 빨라진다고 보장하지 않는다. YouTube가 계정 번호를 처리하는 결과는 서비스 정책과 세션 상태에 영향을 받는다.
