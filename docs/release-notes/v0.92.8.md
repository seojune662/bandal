# v0.92.8 — 미리보기로 찾고 넓게 보는 자료

자료의 첫 페이지 미리보기 목록·폴더 탐색·정렬·넓게 보기와 폴더별 본문 검색을 추가한다. 열지 않은 긴 PDF도 별도 백그라운드 프로세스에서 색인하고, 저장된 첫 페이지 필기·하이라이트를 미리보기에 반영한다. 기존 간단히·아이콘·열·갤러리 보기와 프로젝트 자료를 유지한다. 전체 구현 범위는 [v0.92.6](v0.92.6.md)에 기록했다.

v0.92.6과 v0.92.7은 공개 전 검증에서 중단됐다. AI 단축키 검사는 연결·미연결 상태를 고정하여 오른쪽 AI와 원래 과목·브라우저가 유지되는지 확인한다. 개인 CLI 로그인 여부에 따라 결과가 달라지지 않으며 실제 AI 요청을 보내지 않는다.

좁은 창의 분할 조절 검사에서 닫힌 자료 목록이 저장 후 갱신될 때 선택된 행의 scrollIntoView가 문서 전체를 가로로 밀어내는 문제를 확인했다. 자료의 선택 항목 스크롤을 자료 컨테이너 내부로 제한하고, 앱 루트의 프로그램적 스크롤을 차단해 기존 작업 화면의 위치를 보존한다. 자료·편집기·PDF 내부의 스크롤은 유지한다.

## 검증

- 앞선 CI에서 관련 225개 파일·1,549개 단위 검사와 main/renderer/demo 타입 검사, 영향 검사 선택기 87개 및 대비 검사를 통과했다.
- 앞선 설치본에서 새 자료 목록·확장·저장 필기 미리보기·205페이지 본문 검색과 이동은 macOS·Windows 모두 통과했다.
- 수정 전 앱에서 닫힌 자료 목록 갱신 후 문서 가로 이동 106px를 재현했다. 수정 후 내부 스크롤 관련 단위 18개, AI 연결·미연결 상태 검사 2개, 좁은 창·4분할·자료 확장·보기 전환·PDF 스크롤 E2E 5개와 renderer 타입 검사·빌드를 통과했다.
- 최종 앱 커밋 `7cc23b87b7b8b2469f5f2bea0b5d9efb3d93d54f`의 [CI](https://github.com/seojune662/bandal/actions/runs/40878291272)는 영향받는 226개 파일·1,553개 단위 검사와 main/renderer/demo 타입 검사, 영향 검사 선택기 87개 및 대비 검사를 통과했다.
- 같은 커밋의 [릴리스 작업](https://github.com/seojune662/bandal/actions/runs/40878318113)은 macOS·Windows 패키지 E2E 각각 97개를 통과했다. 미리보기 목록·폴더 탐색·확장과 포커스 복원·저장 필기 미리보기·205페이지 PDF 본문 검색과 해당 페이지 이동·닫힌 자료 목록 갱신 후 분할 조절을 포함한다. 패키징된 `.app`과 `win-unpacked`를 실행한 결과이며 DMG·EXE 설치 마법사 조작 검사는 아니다.
