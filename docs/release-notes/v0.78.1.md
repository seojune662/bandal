# v0.78.1

- 왼쪽 다운로드 버튼을 36px에서 28px로, 내부 아이콘을 20px에서 16px로 줄였습니다. 다운로드 진행률 링과 주변 버튼의 정렬도 맞췄습니다.
- 탭을 과목 폴더 행으로 끌어가면 300ms 대기 없이 해당 과목으로 전환합니다. 여러 과목을 연속으로 지나도 잡고 있는 탭을 유지하고, 원하는 영역이나 탭 순서에 놓을 수 있습니다.
- 과목 폴더 구역에 들어갈 때 기존 화면의 분할 안내를 바로 해제합니다. 드롭 위치는 현재 포인터가 가리키는 작업 영역으로 판단합니다.
- 드래그 준비 시점부터 내장 브라우저가 마우스 이벤트를 받지 않게 하여, 빠른 이동에서 드래그가 끊기는 경합을 줄였습니다. 드래그가 아닌 일반 클릭이나 취소 뒤에는 브라우저 조작을 복원합니다.

## 검증

과목 진입·영역 판정·브라우저 이벤트 차단의 단위 회귀와 renderer 타입 검사를 실행합니다. 실제 Electron 마우스로 빠른 과목 진입, 여러 과목 왕복, 폴더 구역의 분할 안내 해제, 대상 화면 분할·탭 삽입·취소를 확인합니다. 브라우저 검사에서 인위적으로 드래그를 늦추던 대기를 제거했습니다.

CI는 변경 파일의 의존 관계에 연결된 검사만 선택하며 릴리스는 같은 커밋의 성공한 CI 결과를 재사용합니다. macOS·Windows 패키지의 관련 E2E, macOS 서명·공증, 설치 파일과 자동 업데이트 피드의 업로드 무결성 및 공개 여부를 확인합니다. Windows 설치 파일은 기존 정책대로 서명하지 않습니다.

자동 검사는 임시 프로필과 로컬 웹 페이지를 사용합니다. 실제 개인 사이트 로그인, 사용 중인 앱의 업데이트 설치·재시작과 사용자별 OS 환경은 직접 검증한 범위에 포함하지 않습니다.
