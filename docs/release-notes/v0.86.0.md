# v0.86.0 — 자료 보기와 외부 자료 가져오기

자료 패널에서 **아이콘·목록·열·갤러리** 보기를 선택할 수 있다. 선택한 보기를 기억하며, PDF·이미지·노트의 미리보기와 폴더 탐색을 제공한다. 기존 파일 열기·이름 변경·이동·삭제·드래그 기능을 함께 사용할 수 있다.

오른쪽 **외부 자료** 패널에서 폴더를 연결하거나 사진을 선택해 작은 목록으로 확인한다. 선택한 파일을 과목에 가져오고, 이미지는 PDF나 Markdown 편집기로 드래그해 추가할 수 있다. Finder와 사진 앱 자체의 창을 임베드하는 방식이 아니라, 사용자가 고른 자료를 반달 패널에서 다룬다.

macOS 공유 메뉴에 **반달** 공유 확장을 추가한다. 외부 앱이 전달한 파일·텍스트·링크를 받은 뒤 반달에서 과목과 폴더를 선택해 저장한다. 앱이 닫혀 있던 경우에도 전달된 자료를 보존한다. 공유 확장은 앱과 같은 팀으로 서명하고 macOS App Group을 통해 자료를 전달한다. 팀 식별자 형식의 macOS App Group은 별도 프로비저닝 프로필이 필요하지 않다([Apple 문서](https://developer.apple.com/documentation/xcode/accessing-app-group-containers)).

Windows 설치 파일에도 자료 보기와 외부 파일 기능을 포함한다. 현재 NSIS 설치 방식에는 Windows 시스템 공유 대상 등록이 포함되지 않는다.

## 검증

- 자료 보기·외부 자료·공유 수신의 새 단위 검사 16개와 관련 이미지 드래그·자료 표시 회귀 검사를 통과했다. main·renderer·web-demo 타입 검사와 검사 선택 스크립트 검사도 통과했다.
- 실제 Electron 앱에서 보기 전환·폴더 탐색·보기 설정 유지, 외부 폴더 파일 가져오기·이미지 드래그 전달, Markdown/PDF 이미지 저장·재열기, 공유 자료의 재시작 보존·과목/폴더 선택·기존 파일 보존, 첫 과목 생성 등 4개 E2E를 통과했다. OS 선택기는 격리된 시험 폴더로 대체했고, 이미지 드롭은 동일 이미지 바이트로 재현했다.
- 사진 선택 도우미와 공유 확장을 macOS arm64·x64로 컴파일했다. 사진 도우미 자체 검사와 공유 확장의 로컬 서명 구조 검사를 통과했다. 배포에서는 Developer ID 서명·공증 및 시스템 공유 확장 등록 검사를 추가한다.
- 실제 개인 사진 보관함 선택, 카카오톡 등 외부 앱별 공유 화면, OS 설정에 따른 공유 확장 활성화는 자동 검사와 구분한다. macOS 13 이상은 시스템 사진 선택기를, macOS 12와 Windows는 이미지 파일 선택기를 사용한다.
