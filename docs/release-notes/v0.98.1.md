# v0.98.1 — iPad 같은 설정창, 동기화 탭 (v0.98.0 공개분)

v0.98.0의 변경([`v0.98.0.md`](v0.98.0.md))을 모두 담는다. iPad 같은 설정 구역, 설정 › 동기화 탭, 동기화 폴더가 비었을 때 멈춤, iCloud 접근 안내, iPad 도형 보존, 로그인 수단 연결 표시가 여기에 들어 있다. v0.98.0은 macOS 설치본 E2E에서 아래 문제가 드러나 공개하지 않았다.

## 바뀌는 점 (v0.98.0 대비)

- **설정 바로가기 스크롤**: ⌘/로 단축키 패널을 열 때처럼 구역의 두 번째 이후 패널로 바로 가면, 그 패널로 스크롤한 뒤 위쪽 패널 내용이 늦게 불러와지며 늘어나 대상 패널이 화면 밖으로 밀려났다. 느린 기계(`macos-15` 러너)에서 드러났다. 이제 대상 패널을 맨 위에 붙잡아 둔다. 위쪽 패널 크기가 바뀌면 다시 맞추고, 사용자가 스크롤·클릭·키 입력을 하거나 2초가 지나면 그만둔다.
- **데스크톱 버전 전달**: 반달 서버로 보내는 요청의 User-Agent를 `node`에서 `Bandal-Desktop/<버전> (<OS> <아키텍처>)`로 바꿨다. Auth가 원래 세션마다 저장하는 값이라 새로 수집하는 정보는 없다. bandal.io/admin의 플랫폼·버전 화면이 이 값으로 데스크톱 버전을 구분한다.
- 같은 PR에 bandal.io/admin용 서버 코드(migration `20261118000000`, admin 함수)가 포함됐다. 앱에는 영향이 없고, 운영 적용은 따로 한다.

## 검증

- v0.98.0 릴리스 run 44236912193에서 Windows 빌드와 설치본 E2E는 통과했다. macOS 설치본 E2E에서는 3개가 실패했다.
  - `settingsShell`의 ⌘/ 검사: 단축키 패널의 viewport ratio가 0이었다.
  - 같은 앱 인스턴스를 이어 쓰는 다음 검사가 그 여파로 실패했다.
  - `favoritesDrag`: 놓는 지점(마지막 탭의 오른쪽 끝 2px)이 좁은 창에서 탭 줄 오른쪽 버튼에 가려졌다.
- 새 E2E `e2e/settingsDeepLink.spec.ts`는 CPU를 20배 느리게 하고 창 높이를 700으로 줄여 ⌘/를 두 번 확인한다. 수정 전 코드에서는 CI와 똑같이 "viewport ratio 0"으로 실패했고, 수정 후에는 통과한다.
- `settingsShell`의 카드 여백 검사는 설정창이 닫힌 새 인스턴스에서도 스스로 설정을 연다. `favoritesDrag`는 탭 오른쪽 절반의 3/4 지점에 놓는다.
- 설치본 E2E가 고를 영향 스펙 19개(검사 51개)가 개발 빌드에서 통과한다. 설정·계정·관리자 단위 검사 194개, 타입 검사(`tsconfig.web.json`, `tsconfig.node.json`), `pnpm deadcode`도 통과한다.
