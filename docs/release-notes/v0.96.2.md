# v0.96.2 — iPad 디자인으로 다시 그린 데스크톱

iPad 앱(SwiftUI)의 디자인을 데스크톱으로 옮겼다. 기능은 그대로 두고 화면만 바꿨다. 기준은 iPad 저장소의 `seojune662/decor-foundation` 브랜치이며, Swift 코드의 색·크기·수식을 CSS와 React로 직접 옮겼다.

## 바뀌는 점

- **왼쪽 레일**: 홈·AI·학업 보드, 아래쪽 프로필·설정 다섯 개만 남겼다. 홈과 AI는 레일 옆 같은 자리에 열리며 동시에 열리지 않는다. 열린 버튼을 다시 누르면 닫힌다. 열린 버튼은 패널과 이어진 탭 모양으로 표시한다(iPad `NativeRailTab`). 사이드바 오른쪽의 작은 AI 손잡이는 없앴다.
- **프로필 메뉴**: 레일에서 빠진 플러그인·커뮤니티·도움말과 둘러보기를 프로필 메뉴(276px 글래스 카드)로 옮겼다. 로그인하지 않았을 때도 같은 버튼에서 로그인으로 이어진다. 업데이트 버튼은 받을 업데이트가 있을 때만 레일 아래쪽에 나타난다.
- **사이트 타일**: 홈 사이드바 위쪽의 학교·AI 바로가기를 타일로 바꿨다. 학교 기본 링크 4개, 직접 추가한 사이트, 앱 브라우저에서 3번 이상 방문한 사이트를 방문 순으로 최대 12개 보여 준다. 우클릭으로 고정·삭제하고, `+` 타일로 주소를 추가한다(AI 사이트 추천 포함). 설정 키 `homeSites`는 iPad와 같다.
- **글래스와 꾸미기**: 창이 직접 그린 OKLCH 메시 배경과 그레인 위에 레일·패널을 반투명 글래스로 올렸다. 에디터는 불투명 종이로 남긴다. 팔레트 8개(새벽·벚꽃·노을·숲·바다·라벤더·먹·모노)와 세기를 설정 › 화면 › 꾸미기에서 고른다. OS 투명 효과는 쓰지 않으며, "투명도 줄이기"를 켜면 글래스가 불투명해진다.
- **화면별 다듬기**: 설정은 가운데 뜨는 글래스 시트(940×760)로, 학업 보드는 반경 28 시트와 iPad식 세그먼트·칩·카드로, 탭은 31px 알약으로, AI 대화는 accent 말풍선과 둥근 입력창으로 바꿨다. 라이트·다크 기본 색도 iPad 값으로 맞췄다(대비 검사 통과 값 유지).
- **업데이트 인사**: 온보딩을 마친 사용자에게 한 번 "반달이 새로워졌어요"를 띄운다. 모양(라이트·다크·시스템)과 색·세기를 바로 고를 수 있다. 처음 쓰는 사용자는 온보딩 카드에서 색을 고른다. iPad 앱 공지는 이 인사를 닫은 뒤 다음 실행부터 보인다.

## 검증

- v0.96.1도 macOS 설치본 E2E의 판매 대화상자 검사가 실패해 공개하지 않았다(Windows는 통과). 원인은 v0.95.4에도 있던 기존 문제로, 스크롤 영역이 `<fieldset>`이라 Chromium이 그 안의 항목을 보이도록 스크롤하지 못했다. 그래서 창 높이가 낮으면 권리 확인 체크박스가 하단 줄 밑에 가려 클릭·키보드 포커스로도 드러나지 않았다. v0.96.2는 판매·판매자 등록 대화상자의 스크롤을 감싸는 `div`로 옮겼다. 684px 높이 창에서 v0.95.4와 v0.96.1 모두 같은 실패를 재현했고, 수정 후 통과했다.

- v0.96.0은 설치본 E2E에서 실패해 공개하지 않았다. Windows에서는 학업 보드가 열린 동안 위로 올라온 레일이 왼쪽 위 사이드바 토글을 가렸다(새 레일이 창 위쪽까지 이어지면서 생긴 회귀). v0.96.1은 보드 위에서 창 모서리 제어를 레일보다 위에 둔다. macOS에서는 `macos-15` 러너 화면이 900px보다 낮아 창이 684px로 줄었다. 그래서 1440×900 탭 검사가 창 크기를 맞추지 못했고, 판매 대화상자의 체크박스가 고정 하단 줄 바로 밑으로 스크롤됐다. 탭 검사는 화면 작업 영역에 맞춘 크기로 비교하고, 판매 대화상자 본문에는 스크롤 여백을 둬 하단 줄 밑에 항목이 걸리지 않게 했다.

- 단위 검사: 꾸미기 수식(OKLCH→sRGB, 알파 보간, 투명도 줄이기), 사이트 순위, 홈·AI 한 자리 규칙, 프로필 메뉴 키보드·로그아웃 복구를 추가·갱신했다.
- E2E: `designRefresh` 스펙을 추가했다(레일 한 자리 규칙, 팔레트 8개 적용, 인사 1회 표시·저장, 온보딩 색 선택, 라이트·다크·1024px 스크린샷). 기존 스펙은 새 레일·프로필 메뉴·사이트 타일 기준으로 고쳤다.
- 실기기 검증은 하지 않았다. OS 권한과 실제 설치 업데이트 흐름은 자동 검사 범위 밖이다.
