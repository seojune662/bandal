# v0.80.1 — 영어 이어읽기 첫 사용 안내

영어 글 읽기를 처음 열면 **글 찾기 → 단어 담기 → 이어 읽기**를 알려주는 소개 팝업이 표시됩니다. 관심 주제·읽기 수준·시간·AI 선택, 단어 클릭과 표현 드래그, 뜻과 원문 문장 저장, 읽기 완료 후 다음 글 찾기를 화면 예시와 함께 설명합니다.

새 공간을 만들기 전과 기존 영어 공간의 첫 진입을 모두 지원합니다. 안내를 마치거나 건너뛰거나 닫으면 같은 앱 프로필에서는 자동으로 다시 나타나지 않습니다. 학습 화면의 **사용 방법**에서 언제든 다시 볼 수 있습니다. 안내를 여는 것만으로 공간을 만들거나 AI를 실행하지 않습니다.

밝은·어두운 테마를 지원하고, 좁은 창에서는 설명에 집중하도록 예시 그림을 숨깁니다. 작은 창에서도 하단 버튼은 유지되며 본문은 마우스와 키보드로 스크롤할 수 있습니다. Tab 포커스 순환과 Escape 닫기도 지원합니다.

## 검증

- 렌더러 TypeScript 검사와 프로덕션 빌드.
- 첫 진입의 3단계 이동, 건너뛰기, 닫기·Escape, 다시 열기와 재로드 후 표시 이력 유지, 기존 영어 공간 진입과 안내 재열기, 과목 복습 공간 제외.
- 안내에서 AI·공간 생성이 일어나지 않는지 확인, 안내 종료 후 설정 입력란으로 포커스 이동, 키보드 포커스 순환·본문 스크롤.
- 1280×800·600×650 창과 밝은·어두운 테마의 화면 확인.
- 기존 영어 공간 생성과 작은 확대 화면에서의 설정·기존 하위 폴더 연결 회귀 검사.

릴리스는 같은 커밋의 CI 결과와 macOS·Windows 패키지의 관련 E2E를 확인하고, macOS 서명·공증, 설치 파일 업로드 무결성과 두 플랫폼 업데이트 피드를 검증한 뒤 공개합니다. 실제 외부 AI의 기사 추천 결과나 개인 계정 연결은 이번 안내 UI 검증 범위에 포함하지 않습니다.
