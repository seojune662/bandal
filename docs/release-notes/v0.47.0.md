# v0.47.0 — 강의 녹음과 로컬 자막

## 새로운 기능

- 새 탭 메뉴에 **녹음**을 추가했습니다. 과목별로 강의를 녹음하고 세션을 관리할 수 있습니다.
- **Whisper large-v3-turbo FP16**을 기본 모델로 사용합니다. 최초 모델 다운로드는 약 1.63 GB이며, 설치 후 음성 인식은 기기 안에서 실행합니다. 음성이나 자막을 STT 서버로 전송하지 않습니다.
- 녹음 중 임시 자막을 갱신하고 더 긴 문맥으로 보정·확정합니다. Apple Silicon에서는 Metal GPU를 사용합니다.
- PDF 페이지와 마크다운 필기를 녹음 시간에 연결하고, 자막의 시간을 눌러 다시 듣거나 자막을 새 마크다운 필기로 내보낼 수 있습니다.
- 탭을 이동하거나 닫아도 녹음을 유지하고 전역 녹음 표시를 보여줍니다. 원음 우선 저장, 엔진 장애 후 재전사, 앱 재시작 후 세션 복구를 지원합니다.
- 모델 다운로드 진행률·취소·재시도와 파일 무결성 검증을 제공합니다. Zipformer Korean과 SenseVoice도 선택할 수 있습니다.

## 사용 전 확인

- 강의 녹음에 필요한 동의를 받고 사용해 주세요.
- macOS에서 기본 Whisper 모델을 실행하려면 **macOS 15 이상**이 필요합니다. 앱 전체의 최소 지원 버전은 변경하지 않았습니다.
- 실시간 자막은 초기 기능입니다. 임시 자막은 최소 약 4초 분량부터 생성하며, 발화 감지와 기기 성능에 따라 더 늦어질 수 있습니다. 확정 자막은 약 12~28초 문맥으로 처리합니다.
- 수식·기호·전공 용어 오인식이 남아 있으므로 중요한 내용은 원음과 대조해 주세요.
- M4 / 16 GB에서 실제 강의 전사와 3분 실제 시간 백그라운드 입력을 확인했습니다. **2~4시간 연속 사용의 발열·배터리·지연 안정성, Intel 및 Windows 실기기에서의 Whisper 성능은 아직 검증하지 않았습니다.**
- 과열이나 처리 지연 시 자막 갱신을 줄이거나 추론을 미룰 수 있습니다. 발열이 없거나 지연이 항상 일정함을 보장하지 않습니다.
- 원음 저장에는 시간당 약 115 MB가 필요합니다. 모델 설치 공간과 녹음 저장 공간을 확보해 주세요.
