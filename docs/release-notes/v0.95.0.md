# v0.95.0 — 자료 목록 보기에서 폴더를 제자리에서 펼침

자료 패널의 "목록" 보기를 간단히 보기처럼 동작하도록 바꾸고, 한 화면에 더 많은 자료가 보이게 행을 줄였다(#41).

## 바뀌는 점

- 목록 보기에서 폴더를 누르면 폴더 안으로 들어가지 않고 그 자리에서 펼쳐진다.
  - 하위 자료는 깊이만큼 들여쓴다. 펼친 폴더는 셰브런이 아래를 향한다.
  - 펼침 상태는 간단히 보기와 공유한다.
- 목록 행 높이를 줄였다. 사이드바는 100px에서 52px로, 넓게 보기는 116px에서 64px로 바뀌었다.
  - 이름은 한 줄로 보인다. 날짜·크기·종류는 그 아래 한 줄에 모았다.
  - 마크다운·텍스트 썸네일은 위쪽부터 보인다.
- 폴더 안으로 들어가 보는 방식과 "현재 폴더" 검색은 아이콘·열·갤러리 보기에 남는다. 목록 보기의 검색은 간단히 보기처럼 전체 자료를 대상으로 한다.
