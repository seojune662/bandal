# v0.82.0 — 내 공부를 사고파는 마켓플레이스

왼쪽 사이드바의 **도구와 더보기 사이**에 마켓플레이스를 추가했습니다. 앱에서 선택한 대학교를 기준으로 자료를 모아 보고, **둘러보기·구매한 자료·판매 관리**에서 필요한 일을 이어갈 수 있습니다. 학교 선택은 재학생 인증을 의미하지 않습니다.

- 과목 이름으로 자료를 찾고, 내 과목을 연결해 듣는 수업의 자료만 좁혀 볼 수 있습니다. 자료 상세 창에서 구성 파일·가격·공개 미리보기를 확인합니다.
- 과목이나 자료의 우클릭 메뉴에서도 판매를 시작할 수 있습니다. **과목·파일 선택 → 제목·설명·가격·미리보기 → 공개 내용·판매 권한 확인**의 세 단계로 진행하며, 판매자 등록 전에도 초안을 저장할 수 있습니다.
- 직접 고른 PDF·Markdown·텍스트·이미지·DOCX·PPTX·XLSX를 묶음으로 판매합니다. 선택한 파일은 로컬 사본으로 고정하고, 공개 미리보기는 별도로 확인한 이미지로 만듭니다. 원래 과목 폴더를 수정해도 이미 게시하거나 구매한 자료는 바뀌지 않으며, 판매 파일 변경은 새 버전으로 등록합니다.
- 결제는 시스템 브라우저에서 열고 앱의 구매 내역에 상태를 반영합니다. 구매 자료는 기존 과목 또는 새 과목에 가져올 수 있습니다. 다운로드 주소가 만료되면 다시 발급받고, 파일 크기·해시를 검증한 뒤 묶음 전체를 저장합니다. 중간 실패로 일부 파일만 구매 폴더에 남지 않습니다.
- 판매 관리에서 판매 중지·재개, 새 버전 등록과 지급 내역을 확인하고, 구매한 자료에서 결제 영수증을 열 수 있습니다. 거래 정책은 총 수수료 10%, 결제 후 7일 경과 및 지급 가능 잔액 확인 후 금요일 정산입니다. 은행 휴일에는 확인된 다음 영업일로 미룹니다.
- 자료 제공 전 7일 이내 환불은 자동 처리하고, 제공 후 환불은 운영 검토로 접수합니다. 운영 권한이 있는 계정에는 신고·환불·판매 제한·지급 보류·학교 등록을 처리하는 화면을 제공합니다.

## 검증 범위

직접 영향을 받는 렌더러·메인 프로세스·백엔드 검사와 타입 검사, Electron의 학교 선택·검색·판매 준비·미리보기·구매 자료 가져오기·실패 후 재시도를 대상으로 검증합니다. 학교나 계정 변경 후 이전 응답이 화면에 섞이지 않는지, 원본 사본 고정, 경로 이탈·파일 변조 차단, 만료 주소 갱신, 환불·지급의 중복 처리 방지도 확인합니다.

백엔드 자동 검증은 격리된 **실제 로컬 Supabase Auth·Postgres·비공개 Storage**를 사용하며, **Toss API는 모의 응답**으로 검증합니다. 이는 실제 Toss 결제나 은행 지급 성공을 의미하지 않습니다. 정확한 검사 결과와 공개 배포 정보는 릴리스 검증 완료 후 기록합니다.

## 실거래 및 배포 상태

Toss 결제·지급대행 계약과 운영 준비가 완료되지 않아 **실결제·실정산은 비활성화**되어 있습니다. 준비 상태에서는 자료를 둘러보고 판매 초안을 만들 수 있습니다. 개인 판매자의 실제 본인인증·KYC, 실제 소액 결제·환불·은행 정산은 별도 확인이 필요하며 이번 자동 검증에 포함하지 않습니다.

앱 공개는 같은 커밋의 CI와 macOS·Windows 패키지의 관련 E2E, macOS 서명·공증, 설치 파일 업로드 무결성 및 두 플랫폼 업데이트 피드를 확인한 뒤 진행합니다. Windows는 기존 정책대로 미서명 배포이며, 이번 변경으로 Windows 서명이 추가되지는 않습니다.
