# v0.51.1 — Apple 캘린더 연결 수정

- macOS에서 **Apple 캘린더 연결**을 눌러도 권한 창이 나타나지 않고 연결이 차단되는 문제를 수정했습니다. 앱과 캘린더 연결 도구의 배포 서명에 필요한 권한을 추가했습니다.
- 배포 과정에서 macOS 앱과 캘린더 도구의 실제 서명을 검사하도록 보완했습니다. 필요한 권한이 누락되면 설치 파일 공개 전에 배포를 중단합니다.
- 웹 체험에서 필기 모드를 바꿀 때 이미 읽은 PDF를 유지하고, 분할 화면과 대화상자 포커스 복원을 개선했습니다.

업데이트 후 **설정 → 달력 → Apple 캘린더 연결**을 누르고 macOS에서 전체 접근을 허용하세요. 선택한 캘린더의 일정을 조회하고 과제를 직접 전송할 수 있습니다. macOS 전용이며, 자동 양방향 동기화는 지원하지 않습니다.

검증 범위: 캘린더 관련 단위 검사 26개와 서명된 로컬 앱의 UI E2E 2개 통과. E2E는 합성 캘린더 응답을 사용하며, 실제 개인 캘린더의 권한 허용·일정 전송은 사용자가 확인해야 합니다. 정적 검사·전체 단위 검사와 macOS·Windows 빌드 결과는 이 릴리스의 GitHub Actions에서 확인할 수 있습니다.
