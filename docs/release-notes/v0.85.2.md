# v0.85.2 — 노트·계정·동기화 통합

[v0.85.0의 기능 변경](v0.85.0.md)과 [v0.85.1의 PDF 수정](v0.85.1.md)을 포함한다. 창 추가와 탭 종류는 노트 → 브라우저 → 마크다운 → AI → 녹음 순서다. PDF 노트·편집 가능한 화이트보드 이전·계정별 로컬 프로필·로그인 전 백업·동기화 동의·공통 구독·탈퇴 경로를 연결한다.

Windows 실제 클라우드 첫 수신에서 iPad용 POSIX 경로 코드가 Windows 드라이브 경로를 잘못 해석하는 문제를 발견했다. 자료를 덮어쓰지는 않았지만 정상 다운로드가 충돌로 보존되어 공개를 중단했다. Windows 경로의 드라이브·UNC·상위 경로·대소문자 처리와 허용 폴더 검증을 보완한다. 공통 원본과 양쪽 배포물을 함께 갱신한다.

## 검증 상태

- 변경 전 기준 f922의 CI는 타입 검사·대상 스크립트·Python·백엔드 검사와 Vitest 249개 파일, 1,948개 검사에 통과했다(2개 파일·12개 검사 제외). Windows 수정 후 필요한 검사는 별도로 수행한다.
- 실제 Mac ↔ 운영 Supabase ↔ iPad에서 PDF·Markdown·v5 필기·페이지 재구성 왕복과 동일 파일 해시를 확인했다. 최종 대기·충돌은 0이었다. 권한 만료 후 쓰기 차단·기존 다운로드와 QA 계정/자료 정리도 확인했다.
- Windows 수정 후 실제 왕복, 최종 CI, 설치본 E2E, macOS 서명·공증, 공개 자산·체크섬·업데이트 피드는 성공을 확인한 뒤 기록한다.

## Apple 외부 준비

`app.bandal.ipad` Bundle ID와 Apple 로그인 capability를 등록했다. API가 primary 옵션의 활성 값을 생략하여 Developer Portal에서 해당 설정 확인이 필요하다. App Store 앱 record·구독 그룹·상품은 아직 미등록이며 별도 IAP 서버 키·로그인 키·계약/정산 설정, 실제 Sandbox·TestFlight·심사·공개 검증이 남아 있다. Apple 구매는 준비 완료 전 서버에서 비활성 상태를 유지한다. [등록 기록](../apple-ipad-register.md)을 따른다.

사용자의 실제 OAuth 로그인·Apple 결제 또는 개인 자료 전체를 검증한 것으로 보고하지 않는다. Windows의 기존 미서명 설치 상태와 macOS의 서명·공증을 구분한다.
