# v0.85.2 — 공개 보류

Windows 패키지 검사에서 동기화 충돌 목록의 한글을 Python 기본 문자 인코딩으로 출력하지 못하는 제품 오류를 발견해 공개하지 않았다. 녹음 목록과 편집기 단축키 테스트의 전제도 보완한다. 수정은 후속 v0.85.3에 포함한다.

[v0.85.0의 기능 변경](v0.85.0.md)과 [v0.85.1의 PDF 수정](v0.85.1.md)을 포함한다. 창 추가와 탭 종류는 노트 → 브라우저 → 마크다운 → AI → 녹음 순서다. PDF 노트·편집 가능한 화이트보드 이전·계정별 로컬 프로필·로그인 전 백업·동기화 동의·공통 구독·탈퇴 경로를 연결한다.

Windows 실제 클라우드 첫 수신에서 iPad용 POSIX 경로 코드가 Windows 드라이브 경로를 잘못 해석하는 문제를 발견했다. 자료를 덮어쓰지는 않았지만 정상 다운로드가 충돌로 보존되어 공개를 중단했다. Windows 경로의 드라이브·UNC·상위 경로·대소문자 처리와 허용 폴더 검증을 보완한다. 공통 원본과 양쪽 배포물을 함께 갱신한다.

## 검증 상태

- 최종 커밋 `e684fdcade3cffc16a0a35f86f2d90118158f8fd`의 [CI](https://github.com/seojune662/bandal/actions/runs/38990696831)가 타입 검사·대상 스크립트·Python·백엔드 검사와 Vitest 250개 파일, 1,951개 검사에 통과했다(2개 파일·12개 검사 제외). 릴리스는 같은 커밋의 성공 결과를 재사용한다.
- 실제 Mac ↔ 운영 Supabase ↔ iPad에서 PDF·Markdown·v5 필기·페이지 재구성 왕복과 동일 파일 해시를 확인했다. 최종 대기·충돌은 0이었다. 권한 만료 후 쓰기 차단·기존 다운로드와 QA 계정/자료 정리도 확인했다.
- Windows 실제 실행 환경에서 수정 전 다운로드 충돌 4건을 재현하고, 수정 후 PDF·Markdown·v5 필기를 포함한 5개 레코드가 충돌 없이 적용되는 것을 확인했다. 드라이브·UNC 경로와 허용 폴더 밖으로 나가는 경로/정션 차단도 검사했다.
- [실제 Windows ↔ 운영 Supabase ↔ iPad 왕복](https://github.com/seojune662/bandal/actions/runs/38990356385)이 통과했다. 기존 Mac·Windows 필기는 1쪽에서 2쪽으로 이동하고 iPad 새 필기는 3쪽에 저장됐다. Windows에서 받은 PDF 해시가 기기 결과와 일치했고 Markdown도 일치했다. 최종 대기·보류·충돌은 0이었다.
- 설치본 검사에서 브라우저 임시 파일 `DIPS-journal`이 사라지는 순간 로그인 전 백업이 실패하는 문제를 발견했다. 사용자 콘텐츠의 누락은 오류로 처리하면서 Chromium의 임시 상태만 백업 대상에서 제외하도록 보완했다. 관련 단위 검사 8개와 실제 macOS arm64 패키지의 로그인 전 백업 E2E 2개가 통과했다.
- [최종 릴리스 검사](https://github.com/seojune662/bandal/actions/runs/38990731549)에서 macOS arm64·x64 서명·공증과 Mac 패키지 E2E 120개가 통과했다(3개 제외). Windows는 117개 통과·3개 제외·3개 실패로 공개가 차단됐다. 한글 충돌 목록 출력 오류와 녹음/단축키 검사의 전제는 v0.85.3에서 수정한다. v0.85.2 설치 파일·업데이트 피드는 공개하지 않았다.

## Apple 외부 준비

`app.bandal.ipad` Bundle ID와 Apple 로그인 capability를 등록했다. API가 primary 옵션의 활성 값을 생략하여 Developer Portal에서 해당 설정 확인이 필요하다. App Store 앱 record·구독 그룹·상품은 아직 미등록이며 별도 IAP 서버 키·로그인 키·계약/정산 설정, 실제 Sandbox·TestFlight·심사·공개 검증이 남아 있다. Apple 구매는 준비 완료 전 서버에서 비활성 상태를 유지한다. [등록 기록](../apple-ipad-register.md)을 따른다.

사용자의 실제 OAuth 로그인·Apple 결제 또는 개인 자료 전체를 검증한 것으로 보고하지 않는다. Windows의 기존 미서명 설치 상태와 macOS의 서명·공증을 구분한다.
