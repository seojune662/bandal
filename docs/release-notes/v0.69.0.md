# 반달 v0.69.0

- 첫 실행 안내를 두 달 로고와 두 가지 시작 버튼이 있는 환영 화면 하나로 줄였습니다. 기존 안내 완료·건너뛰기 기록은 유지하며 설정에서 다시 볼 수 있습니다.
- 핵심 기능을 과목별 자료 모으기, PDF와 필기, 현재 자료에 AI 질문하기, 퀴즈·카드 복습, 영어 글과 표현 학습의 정확히 5단계로 소개합니다. 실제 예시 자료를 사용하며 끝내거나 건너뛰면 예시 자료를 정리하고 이전 화면으로 돌아갑니다. AI 요청이나 학습 생성은 자동 실행하지 않습니다.
- 플러그인과 외부 서비스를 하나의 목록으로 모았습니다. 기능 설명·상태·사용 여부를 바로 확인하고 검색과 종류 필터로 찾을 수 있습니다. 연결 정보·권한·로그는 선택한 도구의 상세에서 확인합니다.
- 외부 서비스는 설정 저장 후 연결을 확인하고 성공한 경우에만 사용을 켭니다. 꺼진 서비스도 저장된 인증으로 검사하며 주소·인증 변경 시 이전 검사 결과를 초기화합니다. 기존 연결 설정 진입도 새 플러그인 화면으로 연결합니다.
- 온보딩과 AI 대화의 로고를 공통 두 달 로고로 통일했습니다. 큰 로고는 기존 회전 주기와 모션 감소 설정을 따릅니다.

자동 검증은 고정 자료와 모의 연결 응답을 사용합니다. 실제 개인 계정의 서비스 접근과 운영체제 권한 허용은 자동 검사에 포함하지 않습니다. Windows 설치 파일은 기존과 같이 미서명입니다.
