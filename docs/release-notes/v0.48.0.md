# v0.48.0 — 녹음 화면 개선과 탭별 설정

## 녹음과 복습

- 녹음 설정·자료 패널을 접고 펼칠 수 있으며 선택을 저장합니다. 좁은 화면에서는 자막을 먼저 보여줍니다.
- 중첩 스크롤을 정리하고, 오디오 재생·마이크 레벨 갱신을 자막 화면과 분리해 불필요한 렌더링을 줄였습니다.
- 재생기에 10초 이동, 배속, 탐색 바를 추가했습니다. 종료된 녹음은 첫 자막부터 읽고, 녹음 중 위로 스크롤하면 자동 따라가기가 멈춥니다.
- 자료 목록의 기존 `audio.wav`를 누르면 해당 녹음의 제목·재생기·자막이 있는 개별 탭이 열립니다. 원음 파일은 이동하거나 변경하지 않습니다.
- 전역 녹음 표시를 누르면 같은 녹음 화면을 중복으로 열지 않고 이미 열려 있는 화면으로 돌아갑니다.

## 탭과 설정

- 새 탭 메뉴를 **마크다운 → 브라우저 → AI → 녹음 → 화이트보드 → 학업 보드** 순서로 정리했습니다.
- 여섯 종류 모두 설정에서 변경할 수 있는 단축키를 제공합니다. macOS 기본값은 각각 **⌘⇧M, ⌘⇧B, ⌘⇧A, ⌘⌥R, ⌘⌥W, ⌘⌥D**입니다. Windows에서는 Command 대신 Ctrl, Option 대신 Alt를 사용합니다.
- **설정 → 탭**에서 탭별 설정을 관리합니다. 마크다운 글꼴·새 파일 제목, 기존 브라우저·AI 설정, 녹음 모델·마이크·재생·화면 기본값, 새 화이트보드 배경, 학업 보드 시작 화면·완료 항목 표시를 지원합니다.

## 검증과 사용 전 확인

- 일반 테스트 3,121개와 녹음·탭 설정 E2E 11개, 타입 검사·미사용 코드 검사·프로덕션 빌드를 통과했습니다.
- 기본 STT 모델은 **Whisper large-v3-turbo**로 유지됩니다. 이번 변경은 UI·탭 동작 개선이며, 2~4시간 연속 사용의 발열·배터리·인식 지연을 새로 검증한 것은 아닙니다.
- 기존 녹음·파일을 그대로 사용합니다. 녹음에 필요한 동의를 받고, 중요한 수식·전공 용어는 원음과 대조해 주세요.

자세한 변경·검증 범위: [녹음 UX 검증 기록](https://github.com/seojune662/bandal/blob/v0.48.0/docs/recording-ux.md).
