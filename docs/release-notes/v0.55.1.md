# v0.55.1 — 다운로드한 한글 주석 표시 수정

주석 포함 PDF를 내려받아 macOS 미리보기 등에서 열 때 한글이 기호·숫자로 바뀌는 문제를 수정했습니다. 한글 글꼴의 CFF 부분 포함 방식이 PDF 엔진에 따라 다르게 해석되는 것이 원인이었습니다. 텍스트 추출은 정상이어서 기존의 파일·문자열 검사만으로는 발견할 수 없었습니다.

- 글자 모양을 벡터로 보존해 확대하거나 인쇄할 때도 선명하게 표시합니다. 일반·굵게·기울임 등 서식과 검색·복사 기능을 유지합니다.
- PDF 주석, 필기를 포함한 슬라이드 PDF, 화이트보드가 같은 문자 출력 코드를 사용합니다.
- 한글 글꼴을 읽지 못했을 때 물음표로 바뀐 파일을 저장하던 대체 동작을 제거했습니다. 오류를 알리고 기존 파일을 보존합니다.

검증은 내보내기 회귀 사례와 실제 배포용 앱의 다운로드 경로에 집중했습니다. macOS에서는 미리보기와 같은 CoreGraphics로 렌더링한 이미지의 한글을 OCR로 확인해, 텍스트 데이터만 정상인 경우도 검출합니다.

검사 과정도 변경 범위에 맞게 조정했습니다. CI는 관련 단위 검사·타입 검사만 선택하고 릴리스는 동일 커밋의 성공한 결과를 재사용합니다. 배포용 앱에서 매번 반복하던 무관한 기능 검사와 성능 검사 2회 반복을 제거했습니다. 서명·공증·설치 파일과 자동 업데이트 피드 검증은 유지합니다.
