# v0.92.9 — Gmail 연결 토큰 교환 수정

Google 토큰 엔드포인트가 데스크톱 OAuth 클라이언트의 PKCE 교환에서도 `client_secret`을 요구해 Gmail 연결이 `client_secret is missing.`으로 실패하던 문제를 수정한다. 인증 코드 교환과 토큰 갱신이 공통으로 거치는 교환 함수에서 `MAIN_VITE_GOOGLE_DESKTOP_CLIENT_SECRET` 값을 함께 보낸다. 값이 없으면 이전과 같은 요청을 보낸다. 설치형 앱의 이 값은 Google이 기밀로 취급하지 않는다.

## 검증

- main 타입 검사를 통과했다.
