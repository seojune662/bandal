# v0.92.9 — Gmail 연결 토큰 교환 수정

Google 토큰 엔드포인트가 데스크톱 OAuth 클라이언트의 PKCE 교환에서도 `client_secret`을 요구해 Gmail 연결이 `client_secret is missing.`으로 실패하던 문제를 수정한다. 인증 코드 교환과 토큰 갱신이 공통으로 거치는 교환 함수에서 `MAIN_VITE_GOOGLE_DESKTOP_CLIENT_SECRET` 값을 함께 보낸다. 값이 없으면 이전과 같은 요청을 보낸다. 설치형 앱의 이 값은 Google이 기밀로 취급하지 않는다.

## 검증

- main 타입 검사를 통과했다.
- 앱 커밋 `fc02498`의 [릴리스 작업](https://github.com/seojune662/bandal/actions/runs/41020337444)이 같은 커밋의 CI 재사용과 macOS·Windows 빌드·패키지 검사를 통과했다.

## 공개 결과

- [v0.92.9](https://github.com/seojune662/bandal/releases/tag/v0.92.9)를 2026-10-30 16:41 KST에 공개했다. 자산 12개이며 `latest/download`의 `latest-mac.yml`·`latest.yml`이 모두 `0.92.9`다.
- 공개 macOS ARM64 업데이트 ZIP의 `app.asar`에 `MAIN_VITE_GOOGLE_DESKTOP_CLIENT_SECRET` 값이 들어간 것을 확인했다(값은 출력하지 않음).
- 홈페이지 [동기화](https://github.com/seojune662/bandal_web/actions/runs/41021734595)가 웹 커밋 `48ae6fe`로 성공했고 한국어·영어 홈이 HTTP 200·`0.92.9`를 표시한다.

실제 Google 계정으로 Gmail 연결을 완료하는 과정은 자동 검증하지 않았다.
