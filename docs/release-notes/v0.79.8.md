# v0.79.8

- 일반 브라우저에서도 인증 비교 앱의 `native identity` 조건처럼 런타임의 원래 브라우저 식별값을 유지합니다. 기존에는 대학 사이트 호환성을 이유로 Electron과 앱 이름을 지워 Google 계정 추가 시 로그인 거절이 발생할 수 있었습니다.
- 일반 탭, 리디렉션, 새 탭으로 열린 팝업, 추가 프로필과 시크릿 모드에서 요청과 페이지의 식별값을 일관되게 유지합니다. 기존 프로필과 로그인 데이터는 초기화하지 않습니다.
- v0.79.6의 `native` 옵션은 시험 앱에만 적용됐고 일반 제품에는 반영되지 않았습니다. 이번 버전은 이 차이를 제품 코드에서 제거합니다.

## 검증 범위

단위 검사는 일반·추가·시크릿 파티션과 기존 probe 명령의 원래 식별값 유지, UA 및 Client Hints 보존, 권한·로컬 파일 차단 정책 유지를 검사합니다. 실제 HTTP 서버를 사용하는 Electron 회귀는 요청 헤더와 `navigator.userAgent`를 비교하고, 리디렉션·자식 탭·프로필 변경·시크릿 인증 창에서도 동일한 값인지 확인합니다. 연세대·KAIST의 공개 브라우저 검사 스크립트도 원래 UA의 Chrome 버전을 인식하여 통과함을 확인했습니다. 학교 계정의 전체 로그인 검증과는 구분합니다.

사용자는 앞서 제공된 v0.79.6 `product / native identity` 시험에서 로그인 성공을 보고했습니다. 자동 회귀는 실제 Google 계정 로그인 성공을 대신하지 않습니다. v0.79.8 일반 앱에서 계정 추가·2단계 인증·계정 왕복 전환은 별도 실제 검증 대상입니다.

macOS·Windows 배포 앱에서 관련 브라우저 호환성 검사를 실행하며, macOS 서명·공증과 모든 업로드 파일의 무결성·버전·자동 업데이트 피드 공개를 확인합니다. Windows 설치 파일은 기존과 같이 미서명입니다.
