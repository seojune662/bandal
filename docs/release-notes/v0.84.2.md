# v0.84.2 — iPad 필기 호환성과 동기화 복구

- iPad의 새 곡선 필기를 데스크톱에서도 같은 모양으로 표시하고 PDF·화이트보드 PDF로 내보냅니다. 지우개도 실제로 보이는 곡선을 따라 작동합니다.
- 기존 필기의 모양을 유지하면서 원래 위치·압력·입력 시각·기울기 정보를 보존합니다. 예측점과 화면 표시용 보간점은 저장된 필기에 섞지 않습니다.
- 데스크톱에 포함된 iPad 연결 도구도 새 필기 형식을 지원합니다. PDF 회전과 양방향 동기화에서도 형식과 원본 데이터를 유지합니다.
- PDF 원본 식별과 자료 이동·이름 변경 후 복구를 보강했습니다. 중단된 이동이 다시 처리될 때 PDF 필기, 노트 링크와 학습 자료 경로를 보존합니다.

## 검증 범위

공통 필기 수학·기존 버전 호환성·지우개·PDF 및 화이트보드 내보내기 회귀 검사 92개와 메인·렌더러 타입 검사를 통과했습니다. Swift와 TypeScript 구현의 21개 공통 입력에서 95,037개 수치가 허용 오차 안에서 일치했습니다. 동기화·충돌·원본 메타데이터 보존과 실제 Electron 연결 도구를 확인했고, 네 가지 PDF 회전의 내보내기 픽셀 비교도 통과했습니다.

릴리스 CI는 이전 공개 버전 이후 변경 영역의 검사를 실행하고, 양쪽 플랫폼의 패키지 검증 및 설치 파일·업데이트 피드 확인을 마친 뒤 공개합니다. macOS 설치 파일은 서명·공증하며 Windows 설치 파일은 기존과 같이 코드 서명이 없습니다. 이 데스크톱 호환성 배포의 검증 결과는 실제 iPad의 펜 입력 지연 수치를 의미하지 않습니다.
