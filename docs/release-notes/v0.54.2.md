# v0.54.2 — 앱 시작과 과목 전환 개선

- **먼저 열리는 앱 화면**: DB 준비와 중단된 녹음 복구를 별도 프로세스로 옮겼습니다. 준비 중에도 창이 응답하며, 데이터 요청은 준비가 끝난 뒤 처리합니다.
- **최근 과목 바로 돌아가기**: 현재 과목을 포함한 최근 3개 작업 공간을 유지합니다. 과목을 오갈 때 탭 배치·PDF 화면·확대율·스크롤을 다시 만들지 않습니다. 보관 공간을 정리하기 전 필기를 저장하며, 저장에 실패한 편집은 유지합니다.
- **보이는 자료부터 복원**: 저장된 탭이 많아도 현재 보이는 자료부터 준비합니다. PDF 보조 텍스트 추출은 첫 페이지 표시 뒤 실행합니다.
- **자료가 많아도 반응하는 화면**: 폴더 탐색·파일 감시·검색 색인을 별도 프로세스에서 처리하고, 검색 캐시는 사용자 DB와 분리하고, DB 체크포인트도 별도 프로세스에서 실행합니다. 자료 목록은 저장된 내용을 먼저 보여준 뒤 갱신합니다. 긴 파일 목록은 화면 주변의 행만 렌더링합니다.
- **전환 중 상태 보존**: 과목을 빠르게 바꿔도 이전 요청이 새 화면을 덮지 않으며, 복원 중 선택한 자료는 준비 후 열립니다. PDF와 페이지 필기를 나란히 연 직후 페이지를 이동할 때 초기 위치로 돌아가는 경합도 수정했습니다.

로컬 M4 / RAM 16GB의 임시 자료 검증에서 최근 과목 100회 왕복은 P95 약 25ms였고, 파일 1만 개 최초 탐색 중 메인 루프 최대 지연은 약 71ms에서 약 5ms로 줄었습니다. 전체 파일 준비 시간은 파일 크기·저장장치에 따라 달라지며, 그동안 화면 입력을 계속 처리하도록 개선했습니다.

검증: 단위 검사 3,215개, 전체 앱 동작 검사 111개 통과. 시작·과목 전환 성능 검사는 macOS·Windows 설치 패키지에서도 실행합니다.
