# v0.83.0 — 자료 상태 표시와 내용 미리보기

오른쪽 자료 목록에서 파일을 열기 전에 최근 추가한 자료인지, 탭에 열려 있는지, 어떤 내용인지 확인할 수 있습니다.

- **하늘색 점**은 자료를 추가한 뒤 24시간 동안 유지됩니다. 열기·편집·미리보기로 사라지지 않고 앱 재시작 후에도 남은 시간을 유지합니다. 업데이트 이전 자료와 처음 연결한 폴더의 기존 파일에는 표시하지 않습니다. 앱 안에서 이름을 바꾸거나 이동하면 원래 만료 시각을 유지합니다.
- **작은 탭 아이콘**은 같은 자료의 마지막 탭을 닫을 때까지 표시됩니다. 다른 과목으로 옮긴 탭과 비활성 과목에 유지된 탭도 포함합니다. 파일 목록·검색 결과·화이트보드에 동일하게 적용하며 두 표시는 함께 나타날 수 있습니다.
- 자료 행에 마우스를 **450ms** 올려두거나 키보드로 초점을 맞추면 왼쪽에 미리보기 카드가 나타납니다. 전체 이름·내용·파일 정보·상태를 보여주고, 클릭·우클릭·드래그·스크롤·Escape·과목 전환 시 닫힙니다. 내장 브라우저 위에서도 표시됩니다.
- 마크다운은 저장하지 않은 현재 편집 내용까지 서식을 적용해 표시합니다. PDF 첫 페이지, 이미지, 화이트보드 첫 페이지, DOCX·HWP·HWPX 본문, 엑셀·CSV·TSV의 첫 표, PPTX 썸네일 또는 본문, 텍스트·코드, 영상 대표 프레임과 녹음의 저장된 자막을 제공합니다.
- 호버 때문에 탭을 열거나 저장하지 않습니다. 문서 변환·변환기 설치·음성 전사·영상이나 음성 재생도 시작하지 않습니다. 구형 PPT는 이미 준비된 변환 결과만 사용합니다. 빈 자료·자막 없는 녹음·지원하지 않는 형식·처리 한도 초과는 서로 구분해 안내합니다.

## 처리 한도

텍스트는 앞 64KiB를 읽어 본문 최대 1,200자를 표시하고, 표는 최대 8행×6열로 제한합니다. 문서 추출은 별도 프로세스에서 시간·입력 크기·압축 해제량을 제한합니다. 이미지와 화이트보드도 입력 크기·해상도·도형 수를 제한하며, 처리량이 큰 자료는 파일 정보와 안내를 남깁니다. 미리보기 작업은 동시 실행 수와 메모리 캐시를 제한하고 취소된 자료의 응답을 버립니다.

외부 파일 관리자의 이름 변경은 첫 버전에서 새 경로 발견으로 취급합니다.

## 검증 범위

24시간 경계·재시작·최초 폴더 기준선·부분 스캔·추가·복제·이름 변경·이동·검색 결과, 중복 탭과 원본 과목 연결을 단위 검사로 확인합니다. 미리보기는 형식별 추출·빈 내용·손상·처리 한도, 지연·빠른 행 이동·취소·최신 마크다운·화이트보드 상태·화면 경계·숨겨진 자료 목록을 검사합니다.

Electron E2E는 실제 파일의 미리보기, 신규·열림 상태, 밝은/어두운 테마, 네이티브 브라우저와 카드의 겹침 및 드래그 시작 후 브라우저 복원을 확인합니다. 드래그 검사는 실제 파일 경로가 전달되는 IPC와 같은 파일의 Chromium 드롭·로컬 업로드를 연결해 검증합니다. 공통 E2E 실행기는 OS의 네이티브 드래그 루프를 비활성화하므로 **실제 OS 드래그 제스처와 개인 ChatGPT 계정의 업로드 완료는 자동 검증에 포함하지 않습니다.**

같은 커밋의 영향 범위 CI, macOS·Windows 패키지의 관련 E2E, macOS 서명·공증, 설치 파일 업로드 무결성과 두 플랫폼 업데이트 피드가 확인된 뒤 공개합니다. Windows는 기존 정책대로 미서명 배포입니다.
