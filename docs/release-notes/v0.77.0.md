# v0.77.0

- 과목 폴더 위 탭 드래그 대기를 300ms로 줄였습니다. 출발·현재 과목과 지나간 폴더의 오래된 타이머는 전환하지 않습니다.
- 과목 전환 뒤 남던 분할 안내를 없애고 유효한 목적지 안내 하나만 표시합니다. 취소하거나 이동에 실패하면 출발 화면으로 돌아오며, 새 드래그나 사용자의 다른 선택을 이전 작업이 덮지 않습니다.
- 이동 중 이미 열린 브라우저의 화면 미리보기를 유지합니다. 기존 페이지·로그인·미저장 내용과 실제 창은 재생성하지 않습니다.
- 새 버전이 있으면 왼쪽 레일의 파란 버튼으로 다운로드합니다. 진행률·오류 복구와 명시적인 재시작을 연결했고, 재시작 전 열린 필기의 저장 실패가 있으면 설치하지 않습니다.
- 프로필과 더보기 메뉴를 간결한 행과 부드러운 표면으로 다듬었습니다. 프로필 메뉴의 키보드 탐색·화면 경계 보정·로그아웃 실패와 재시도를 보완했습니다.

변경 영역의 단위·타입 검사와 실제 탭 드래그·프로필·업데이트 회귀를 선택해 실행합니다. 자동 검사에는 임시 프로필·고정 웹 페이지·모의 로그인과 업데이트 응답을 사용하며, 개인 계정의 실제 인증과 실행 중인 사용자 앱의 설치·재시작은 직접 확인하지 않습니다. 설치 파일 서명·공증, 업로드 해시와 공개 업데이트 피드는 기존 배포 검증을 유지합니다.
