# v0.52.1 — PDF·슬라이드를 이미지로 복사

- PDF 페이지와 PPTX 슬라이드를 우클릭해 **이미지로 복사**할 수 있습니다. 필기·형광펜·텍스트 상자·삽입 이미지를 포함하며, **원본만 이미지로 복사**도 선택할 수 있습니다.
- 우클릭한 페이지 전체를 PNG로 복사합니다. 화면 배율이나 보이는 영역에 영향을 받지 않으며, 반달 노트·화이트보드·PDF에 이미지로 붙여넣을 수 있습니다.
- 키보드 메뉴 조작, 복사 중 상태 표시, 중복 실행 방지, 탭 종료 시 취소를 지원합니다. 복사할 수 없는 간단 미리보기에는 이유를 표시합니다.
- PDF 페이지 번호로 이동한 뒤 클릭할 때 페이지 이동이 다시 실행되던 문제를 수정했습니다.

macOS·Windows 패키지의 실제 클립보드 복사 검사를 릴리스 과정에 추가했습니다. 외부 앱별 붙여넣기는 해당 앱의 이미지 지원 여부에 따라 달라집니다.
