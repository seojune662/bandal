# v0.79.0

- 주소창 오른쪽의 **프로필 · 기본** 버튼에서 학교용·개인용 브라우저 프로필을 만들고 현재 탭의 로그인 계정을 분리할 수 있습니다. 입력칸·선택 상태·작업 버튼을 명확하게 표시하고, 새 프로필은 만든 직후 현재 탭에 적용합니다. 다른 탭에서도 이름 변경이 바로 반영됩니다.
- 프로필 전환을 취소하면 기존 로그인과 페이지를 유지합니다. 전환할 때 이전 오류 화면·페이지 검색 상태를 정리하고, 진행 중이던 Google/OpenAI 인증 주소는 새 프로필에서 사이트 로그인을 새로 시작하도록 처리합니다. 이전 프로필의 화면 갱신이 새 탭을 정리해 빈 화면이 되거나, 사이트가 연 로그인 팝업에서 프로필 변경이 거절되던 문제도 수정합니다.
- Google이 내장 브라우저 로그인을 제한하면 늦게 표시되는 오류도 감지해 원래 서비스를 기본 브라우저에서 열도록 안내합니다. 외부 브라우저의 별도 쿠키와 맞지 않는 OAuth state 주소를 그대로 전달하지 않습니다. 일반적인 비밀번호 오류는 내장 브라우저 거부로 판단하지 않습니다.
- ‘마이페이지’, ‘홈’, ‘로그인’ 같은 즐겨찾기 이름에는 사이트 도메인을 함께 표시합니다. 기존 항목에도 표시 개선이 적용되고 직접 지정한 고유 이름은 유지합니다. 주소창 추천은 현재 프로필과 현재 탭의 과목을 따르며, 같은 프로필의 공통 즐겨찾기도 포함합니다.
- 탐색 제스처 화살표는 앱의 밝은/어두운 기본 테마에 맞춘 중립색을 사용합니다. 첫 가로 스크롤을 뒤로가기로 잘못 인식하거나 별개의 짧은 제스처가 합산되는 문제를 수정합니다.
- 독립된 로그인 팝업도 부모의 프로필 수명에 포함해, 팝업 사용 중 부모 탭을 닫아도 시크릿 세션이 먼저 정리되지 않게 합니다.

## 사용 방법

ChatGPT 탭에서 **프로필 · 기본 → 새 프로필 만들기 → 개인 등의 이름 입력 → 만들고 이 탭에서 사용**을 선택한 뒤 원하는 웹사이트 계정으로 로그인합니다. 이미 만든 프로필은 같은 목록에서 선택합니다. 프로필마다 쿠키·저장된 로그인·방문 기록이 분리되며, Bandal 앱 계정과 웹사이트 구독은 별개입니다.

Google은 앱에 내장된 브라우저의 로그인을 제한할 수 있습니다. 프로필을 나누어도 제공자의 제한이 해제되지는 않습니다. 제한 안내의 **기본 브라우저에서 사이트 열기**로 외부 브라우저에서 서비스를 이용할 수 있으며, 그 로그인은 Bandal에 자동으로 전달되지 않습니다.

## 검증

변경된 로그인 감지·인증 시작 주소·팝업 프로필 수명, 프로필 UI, 즐겨찾기·주소 제안, 브라우저 전환 상태 및 탐색 제스처의 단위 회귀와 main/renderer 타입을 검사합니다. Electron에서는 지연된 Google 거부 화면, 프로필 생성과 즉시 전환, 쿠키 분리, 팝업·재시작·전환 취소, 즐겨찾기 이름, 밝은/어두운 테마와 제스처의 관련 사용 흐름을 검사합니다.

CI는 관련 검사만 선택하고 릴리스는 같은 커밋의 성공한 CI 결과를 재사용합니다. macOS·Windows의 관련 패키지 E2E, macOS 서명·공증, 설치 파일·업데이트 피드의 체크섬과 공개 상태를 확인합니다. Windows 설치 파일은 기존과 같이 미서명입니다.

자동 검사는 임시 프로필·로컬 자료·고정 로그인 오류 화면을 사용합니다. 실제 개인 Google/ChatGPT 계정의 로그인·구독, 실제 손가락의 제스처 감각과 사용자 앱의 업데이트 설치·재시작은 자동 검증 범위에 포함하지 않습니다.
