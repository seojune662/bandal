# v0.91.0 — iPad 앱 출시 안내

iPad 앱 "반달 노트" App Store 출시를 데스크톱 앱 안에서 알린다.

- 메인 화면에 들어온 기존 사용자에게 NEW 안내 모달을 한 번 보여 준다. App Store 열기·QR 코드(앱에 포함, 네트워크 불필요)·"다음에"를 제공한다. X·Esc·바깥 클릭·버튼 중 어떤 방식으로 닫아도 설정에 기록해 다시 띄우지 않는다.
- 이번 실행에서 온보딩을 보는 신규 사용자, 투어·로그인 진행 중, 설정 화면이 열린 동안에는 띄우지 않는다.
- 도움말 메뉴의 "iPad 앱 받기"로 언제든 다시 열 수 있다.
- 공지는 id 기반 범용 컴포넌트로 만들어 다음 공지에 재사용한다. 다크·라이트 테마와 한국어·영어를 지원한다.

## 검증 범위

설정 저장값 검증 단위 테스트와 node/web 타입 검사를 수행한다. 실제 Electron에서 기존 사용자 1회 표시·닫힘 저장·재시작 후 미표시·도움말 메뉴 재열기·온보딩 중 미표시·라이트 테마를 검사하고, 두 테마 화면의 QR이 App Store 주소로 읽히는지 확인했다. 모달 비주얼은 공개된 스토어 스크린샷(라이트)을 임시로 쓴다.
