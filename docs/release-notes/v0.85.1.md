# v0.85.1 — 노트·계정·동기화 통합

[v0.85.0의 기능 변경](v0.85.0.md)을 포함한다. 창 추가와 설정의 탭 종류는 노트 → 브라우저 → 마크다운 → AI → 녹음 순서다. PDF 노트·편집 가능한 화이트보드 이전·계정별 로컬 프로필·로그인 전 백업·동기화 동의·공통 구독·탈퇴 경로를 통합한다.

공개 전 설치본 검사에서 발견한 PDF 라이브러리 누락을 수정했다. 동기화 변환기는 앱의 런타임 의존성에서 `pdf-lib`를 읽으며, 기존과 같은 1.17.1을 설치 파일에 포함한다. 종이 폭에 맞춰 페이지를 표시할 때 일반 스크롤바의 생성·제거가 페이지 폭을 반복 변경하지 않도록 공간을 유지한다. 녹음 설정 패널·최근 녹음 선택·채팅 승인 및 노트의 실제 보이는 종이 영역을 사용하도록 회귀 검사를 갱신했다.

이미 열린 노트에 PDF 클립을 추가하면 저장 완료 뒤 해당 파일·버전의 필기 뷰를 갱신한다. 이전 버전의 PDF와 저장 중인 필기 보호는 유지하며 전체 자료 목록을 다시 읽지 않는다.

## 검증

- 로컬: PDF 복사·붙여넣기·텍스트 편집 8개, 녹음·채팅 사용 흐름 3개 검사 통과.
- 클립 전달: 필기 저장·갱신 회귀 23개와 연속 클립 배치 E2E 2개, renderer 타입 검사 통과.
- 로컬 macOS 설치본: 이전 PDF 구조에 남은 미전송 필기를 동기화 동의 없이 복구하는 검사 통과. 실제 `app.asar`의 런타임 PDF 라이브러리와 배포용 companion을 사용했다. 이 로컬 설치본은 서명하지 않았으며 공개 배포용 서명·공증과 구분한다.
- 실제 Mac ↔ 운영 Supabase ↔ iPad: 별도 QA 계정으로 PDF·마크다운·V5 필기 왕복 통과. iPad에서 2페이지를 재배치하고 빈 페이지를 추가한 뒤 Mac에서 같은 PDF SHA-256, 3페이지, 기존 필기의 2페이지 이동과 새 필기의 3페이지 배치, 마크다운 변경을 확인했다. 양쪽 대기·충돌은 0이다.
- QA 동기화 권한 만료 후 쓰기 차단과 기존 4개 파일의 다운로드·SHA-256 일치를 확인했다. 시험 계정·프로필·동기화 레코드·전송 작업·Storage 객체·베타 권한은 모두 정리해 0건을 확인했다. 상세 기록은 [서버 검증 문서](../apple-billing-and-account-deletion.md)를 따른다.
- 배포용 CI, macOS·Windows 설치본 검사·서명·공증·공개 링크·업데이트 피드는 성공을 확인한 뒤 기록한다.

## 남은 외부 준비

Apple 앱·구독 상품은 아직 App Store Connect에 등록되지 않았다. Apple 구매 코드와 서버 원장을 구현한 상태이며, 별도 IAP 서버 키·로그인 설정·계약 준비 후 Sandbox·TestFlight·심사·공개 검증이 필요하다. 실제 Apple 로그인·결제·사용자 개인 자료 검증을 완료한 것으로 보고하지 않는다. Windows의 기존 미서명 설치 상태와 macOS의 서명·공증을 구분한다.
