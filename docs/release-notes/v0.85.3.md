# v0.85.3 — 노트·계정·동기화 통합

[v0.85.0의 기능 변경](v0.85.0.md), [v0.85.1의 PDF 수정](v0.85.1.md), [v0.85.2의 Windows 경로·백업 수정](v0.85.2.md)을 포함한다. 앞선 세 버전은 공개 전 검사에서 중단됐다.

첫 Windows 설치본 검사에서 새 PDF 노트의 페이지 추가 후 화면이 1쪽으로 유지되는 사례가 한 번 발생해 공개를 보류했다. 제품 코드를 바꾸지 않은 계측 검사 11회가 통과한 뒤 같은 커밋의 Windows 작업만 재실행했고, 최종 120개 통과·3개 제외로 완료됐다. 최초 실패 원인은 미확정이며 수정으로 해결됐다고 주장하지 않는다.

창 추가와 탭 종류는 노트 → 브라우저 → 마크다운 → AI → 녹음 순서다. A4 PDF 노트와 페이지 편집, 기존 화이트보드의 편집 가능한 이전, 계정별 로컬 프로필·로그인 전 백업, 모든 과목의 동기화 동의, 공급자 공통 구독 상태와 탈퇴 경로를 연결한다.

Windows의 동기화 보조 프로그램이 한글 충돌 정보를 기본 문자 인코딩으로 출력하다 멈추는 문제를 수정한다. 통신의 UTF-8 경계를 명시하고 한글·이모지 보존을 검사한다. 녹음과 편집기 단축키 패키지 검사는 실제 좁은 창 상태와 편집기 서식 우선 정책에 맞춘다.

## 공개 결과

[v0.85.3 릴리스](https://github.com/seojune662/bandal/releases/tag/v0.85.3)는 2026-10-17 11:35 KST에 공개됐다. 앱 소스는 `fa9f9d72a289fce51142b773e9f90ff363b3682f`이며 태그와 패키지 버전이 일치한다. macOS arm64·x64 DMG/ZIP, Windows 설치 EXE, 각 blockmap 및 두 자동 업데이트 피드 등 12개 파일의 업로드 크기·SHA-256이 일치했다. 릴리스 본문에도 체크섬을 게시했고 [전체 산출물 기록](../validation/release-v0.85.3-assets.json)을 보존했다.

12개 공개 URL은 모두 인증 없이 부분 다운로드(HTTP 206)가 가능했고 전체 파일 크기가 일치했다. 두 업데이트 피드는 전체 다운로드의 해시·버전 `0.85.3`·대상 파일 경로·크기를 확인했다. 공개 Windows NSIS 설치 파일의 PE 인증서 테이블은 offset/size가 모두 0이므로 내장 Authenticode 서명은 없다. macOS 서명·공증 성공과 구분한다.

iPad의 반영 커밋은 [`d40342620d34ba14732322f71c28d19eb76c2cb1`](https://github.com/seojune662/bandal_iPad/commit/d40342620d34ba14732322f71c28d19eb76c2cb1)이며 원격 main에 푸시했다. 데스크톱 `fa9f9d7`의 공통 코드와 snapshot·통신 경계가 일치한다. 기존 iPad 작업 중 변경과 로컬 빌드 설정은 보존했다. 이는 App Store 또는 TestFlight 배포 완료를 뜻하지 않는다.

웹은 Apple 로그인 준비 상태를 표시하는 `af0753f`와 공개 버전을 반영한 [`c6b050770ac93b7e908deffa4a8ff1f660edf743`](https://github.com/seojune662/bandal_web/commit/c6b050770ac93b7e908deffa4a8ff1f660edf743)를 main에 푸시했다. [버전 동기화](https://github.com/seojune662/bandal_web/actions/runs/38995666219)와 Vercel Production 배포 `7133719196`이 성공했다. [공개 사이트](https://bandal.io)의 `Bandal v0.85.3` 표시와 세 다운로드 링크의 `v0.85.3` 연결, [계정 화면](https://bandal.io/billing)의 Apple 로그인 준비 중·비활성 상태를 새 브라우저 문맥에서 확인했다. 두 페이지 HTTP 200, pageerror 0, 390px 화면의 가로 넘침 없음도 확인했다. 실제 OAuth나 결제는 실행하지 않았다.

## 검증과 공개 상태

- Mac ↔ 운영 Supabase ↔ 실제 iPad 왕복과 [Windows ↔ 실제 iPad 왕복](https://github.com/seojune662/bandal/actions/runs/38990356385)이 통과했다. PDF 페이지 재구성 뒤 기존 필기·새 필기·Markdown 및 PDF 해시가 일치했고, 최종 대기·보류·충돌은 0이었다.
- 구독 권한 만료 후 업로드 중단과 기존 자료 다운로드를 확인했다. 합성 검증 계정·파일·임시 토큰은 모두 정리했다.
- [실제 Windows 경로·통신 검사](https://github.com/seojune662/bandal/actions/runs/38992680562)에서 한글·이모지 경로의 PDF·Markdown·v5 필기 5개 레코드와 충돌 정보가 정확히 보존됐다. cp1252·ASCII 출력 설정에서도 UTF-8 JSON이 유지되고 잘못된 UTF-8은 거절됐다. 드라이브·상위 경로·junction을 통한 저장 폴더 탈출도 차단했다.
- [Windows 전용 패키지 검사](https://github.com/seojune662/bandal/actions/runs/38992678824)는 새 companion과 실제 unpacked 앱에서 7개 통과·3개 제외였다. 이전에 실패한 한글 충돌 복구, 녹음 PDF 2쪽 이동, Markdown 인용문 우선 처리와 앱 탭 단축키가 모두 통과했다. 제외한 3개는 별도 모델·음원이 필요한 검사다.
- 최종 커밋 `fa9f9d72a289fce51142b773e9f90ff363b3682f`의 [CI](https://github.com/seojune662/bandal/actions/runs/38992634245)가 통과했다. 영향 범위의 타입·스크립트·Python·서버 검사와 Vitest 250개 파일·1,953개 검사가 통과했고 2개 파일·12개 검사는 제외됐다. 릴리스는 같은 커밋의 성공 결과를 재사용한다.
- [첫 릴리스 Windows 설치본 검사](https://github.com/seojune662/bandal/actions/runs/38993116323/attempts/1)는 119개 통과·3개 제외·1개 실패였다. 기존 한글 충돌 복구·녹음 페이지 이동·탭 단축키 사례는 통과했고, 새 PDF의 페이지 추가 후 화면 갱신이 실패했다. 이 결과로는 공개하지 않았다.
- 같은 릴리스의 macOS 설치본은 120개 통과·3개 제외(7.9분)였다. arm64·x64의 Developer ID 서명·공증, 캘린더와 브라우저 가져오기 도우미 검사가 모두 통과했다. Windows 재실행에서도 이 성공 산출물을 재사용했다.
- 제품 코드를 바꾸지 않고 Electron 화면·입력·IPC·PDF 파일을 기록한 [Windows 진단 검사](https://github.com/seojune662/bandal/actions/runs/38994350962)는 기존 7개 통과·3개 제외와 페이지 편집 10회 반복 통과였다. 총 11개 실행에서 클릭 후 284~370ms 안에 2쪽이 표시됐고, 최종 PDF는 모두 3쪽이며 파일 SHA와 조회 revision이 일치했다. 처리 오류·진단 시간 초과는 없었다. [진단 요약](../validation/windows-note-page-edit-20261017.json)을 보존했다.
- 같은 `fa9f9d7`의 [Windows 릴리스 재실행](https://github.com/seojune662/bandal/actions/runs/38993116323/attempts/2)은 120개 통과·3개 제외(7.4분)였다. 해당 페이지 편집 검사는 3.6초에 통과했고 도우미 자체 검사도 통과했다. 검사 조건과 제한 시간은 완화하지 않았다.

## Apple 및 인증 외부 준비

`app.bandal.ipad` Bundle ID와 Apple 로그인 capability는 등록됐다. App Store 앱·구독 그룹·상품, 별도 IAP 서버 키·Apple 로그인 키·계약/정산 설정과 Sandbox·TestFlight·심사·공개 검증이 남아 있다. Apple 구매는 준비 완료 전 서버에서 비활성 상태를 유지한다. [등록 기록](../apple-ipad-register.md)을 따른다.

Supabase 수동 로그인 수단 연결 설정은 활성화했다. 현재 Google 공급자는 활성이고 Apple·Kakao는 외부 설정이 남아 있다. 실제 OAuth 로그인·계정 연결·Apple 결제는 모의 검사 및 설정 확인과 구분한다. Windows 설치 파일의 기존 미서명 상태와 macOS의 서명·공증도 구분한다.
