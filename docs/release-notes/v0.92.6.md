# v0.92.6 — 미리보기로 찾고 넓게 보는 자료

오른쪽 자료 목록에 첫 페이지 미리보기, 두 줄 제목, 수정일과 자료 유형을 표시한다. 폴더를 열면 그 안의 자료를 보고, 상위 폴더와 경로 버튼으로 이동한다. 기존 한 줄 트리는 ‘간단히’로 남기고 아이콘·열·갤러리 보기와 이름·수정일·종류 정렬을 제공한다.

자료 제목 옆 ‘넓게 보기’는 같은 탐색 화면을 최대 980px로 펼친다. 폴더·검색·선택·스크롤과 원래 사이드바 폭을 유지하며, 문서를 열면 원래 작업창으로 돌아간다. 가려진 문서와 네이티브 브라우저 세션을 유지하고 배경 입력을 막는다. 프로젝트의 유형별 학습 자료와 외부 자료 기능은 유지한다.

파일명과 본문을 현재 폴더 및 하위 폴더에서 함께 검색한다. ‘전체 자료에서 검색’으로 현재 과목·프로젝트 전체까지 넓힐 수 있다. 본문 결과는 해당 PDF 페이지나 마크다운 문단으로 이동한다. 처음 여는 PDF도 별도 백그라운드 프로세스에서 페이지별로 색인하며 200페이지·20만자 제한을 적용하지 않는다. 색인 중·일부 실패를 표시하며 스캔 이미지와 손글씨 OCR은 포함하지 않는다. 검색 캐시는 사용자 자료 DB와 분리한다.

일반 PDF와 PDF 노트 모두 저장된 첫 페이지 필기·하이라이트를 미리보기에 합성한다. 원본 버전을 검증하고 파일별 저장 알림으로 갱신하며, 160개 이후 필기도 표시한다. 목록 가상화와 최대 2개 동시 썸네일 생성으로 긴 폴더를 탐색한다.

## 검증

로컬에서 자료 표시·정렬·이름 변경·확장 상태·열기 콜백·본문 검색·PDF 색인·미리보기와 영향 검사 선택기의 단위 검사를 수행했다. main/renderer/demo 타입 검사와 앱 빌드를 통과했다. 웹 체험판의 실제 샘플 PDF 버전·검색·저장 필기 미리보기 응답도 검증했다. Electron에서 1,200개 자료의 가상 목록과 키보드 이동, 폴더별·전체 검색, 미리 열지 않은 205페이지 PDF의 본문 이동, 저장된 필기 165개와 삭제 후 미리보기 갱신을 확인했다. 확장 전후 편집 영역의 크기·사이드바 폭·브라우저 세션·입력·스크롤 보존 및 중첩 메뉴의 Escape 처리도 통과했다. 50개 탭 복원 시 선택한 노트만 읽는지와 가상 목록 도입의 영향을 받는 다수 탭·좁은 창·4분할 검사도 통과했다.

최종 커밋의 CI·플랫폼별 설치본 검사 및 공개 자산 검증 결과는 배포 완료 후 기록한다.

실제 개인 계정 로그인·OS 권한 허용·물리적 OS 파일 드래그는 자동 검증 범위와 구분한다. 기존 Windows 설치 파일 서명 정책을 유지하고, macOS는 Developer ID 서명·공증을 검증한다.
