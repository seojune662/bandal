# v0.79.6

- 독립 로그인 비교 실행기에 `--identity native` 조건을 추가합니다. Electron의 원래 브라우저 식별값을 유지하며 다른 브라우저를 사칭하거나 인증 쿠키를 가져오지 않습니다.
- 페이지 개입 여부와 식별 방식을 별도로 선택하고, 시험 공간을 재시작할 때도 처음 선택한 조건을 유지합니다. 기능을 지원하지 않는 구버전 앱에서는 새 조건의 실행을 거절합니다.
- 기존 v0.79.4 시험 공간은 기본 식별 방식으로 계속 재시작할 수 있습니다. 일반 제품의 로그인 저장소·프로필·UA 정책은 유지합니다.

이 변경은 **Google 로그인 문제의 원인이나 해결을 확정한 변경이 아닙니다.** 제품의 기존 식별값 가공이 영향을 주는지 같은 계측 모드·새 저장소에서 비교하기 위한 조건을 추가했습니다. 실제 계정 입력과 2단계 인증은 디버거를 연결하지 않은 공개 패키지에서 계정 소유자가 직접 완료해야 합니다.

자동 검증은 시험 환경의 격리, 조건 불일치 거절, 기존 시험 공간 호환, 새 조건에서 UA 설정 호출이 없고 보안 정책은 유지되는지에 한정합니다. 개인·학교 계정 신규 로그인, Drive·Gmail 원본 화면, Google 계정 추가, 두 프로필 왕복 전환, 다른 탭의 로그인 유지, 재시작과 재로그인은 [수동 검증 절차](../browser-auth-probe.md)로 별도 확인합니다.

macOS 설치 파일은 서명·공증 및 업로드 무결성을 확인합니다. Windows는 기존과 같이 미서명이며, 양쪽 설치 파일과 자동 업데이트 피드의 공개 상태를 확인합니다.
