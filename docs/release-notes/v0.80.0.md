# v0.80.0 — 바로 찾는 단어 뜻과 자료 학습 팔레트

영어 글에서 단어를 클릭하면 선택 위치에 한국어 뜻·원형·품사·발음 기호가 나타납니다. 내장 사전을 사용해 인터넷과 AI 연결 없이 조회하며, 없는 표현은 직접 적거나 온라인 사전을 열어 확인할 수 있습니다. 단어를 저장해도 AI 설명을 자동 실행하지 않습니다.

단어장은 필요할 때 열고, 키보드로 본문 단어를 이동할 수 있습니다. 읽던 위치는 화면 폭이 바뀌어도 문단을 기준으로 복원합니다. 사전 뜻의 출처와 원문 예문을 저장하며 기존에 직접 적은 뜻을 보존합니다.

자료 우클릭의 **이 자료로 학습하기…**에서 핵심 요약·퀴즈·복습 카드와 설치한 도구를 한눈에 고를 수 있습니다. 검색과 실행 설정을 한 창에 모았으며, 클릭한 자료·저장 공간·AI를 확인한 뒤 실행합니다. 설정 화면을 여는 것만으로 실행 중이라고 안내하던 문제도 수정했습니다.

## 검증

사전 데이터·활용형·출처 보존, 읽기 선택·저장·접근성, 팔레트 대상 고정·설정·실행의 관련 단위 검사와 타입 검사를 통과했습니다. 실제 Electron 앱에서 네트워크를 차단한 사전 조회·저장, 키보드 이동, 화면 폭 변경 후 문단 복원, 밝은/어두운 테마, 자료 선택부터 도구 실행까지 확인했습니다. 로컬 반복 조회 10회의 단어 선택→뜻 표시 시간은 최대 20ms, IPC 조회 30회의 p95는 0.2ms였습니다(기기별로 다를 수 있습니다).

릴리스 워크플로는 macOS·Windows 패키징 앱의 관련 E2E, macOS 서명·공증, 설치 파일 업로드 무결성과 업데이트 피드 검증을 통과한 뒤 공개합니다. 실제 외부 AI의 응답 품질과 네이버 사전의 수록 범위는 자동 검증 대상이 아닙니다.
