# v0.79.3

- Google 로그인 도움말을 로그인 거절로 오인하지 않도록 실제 거절 화면과 사유를 함께 확인합니다. 정상 화면으로 복구하면 안내를 해제합니다.
- 안내를 현재 탭·웹페이지·문서에 연결해 이전 페이지나 닫힌 로그인 팝업의 결과가 남지 않도록 합니다. 프로필 전환과 팝업을 탭으로 여는 중 도착한 결과도 해당 페이지에만 적용합니다.
- 일반 제품 구성과 페이지 개입을 끈 구성을 비교하는 수동 로그인 실행기를 추가합니다. 배포 앱을 복사하고 각각 별도 데이터 폴더에서 실행하며, 기존 계정과 브라우저 프로필을 보존합니다.

## 로그인 검증 범위

브라우저 프로필은 사이트의 로그인 상태를 보관하는 공간입니다. Google 계정 자체가 아니며, 새 프로필에서는 원하는 계정으로 직접 로그인해야 합니다. 이번 변경은 **Google 신규 로그인이 해결됐다는 뜻이 아닙니다.** 실제 Google 서비스의 계정 인증 결과가 확인되기 전에는 로그인 성공으로 표시하거나 계정 전환 구조를 확정하지 않습니다.

단위 검사와 Electron 회귀에서는 정상 로그인 화면, 도움말 오탐, 지연 거절, 같은 문서의 복구와 재거절, 이전 문서 이벤트, 팝업의 원래 POST 요청·opener·세션, 프로필 격리·재시작·전환 취소를 검증합니다. 실제 Google 로그인 검증에서는 자동화와 디버거를 연결하지 않은 배포 앱을 사용하며, 비밀번호와 2단계 인증은 계정 소유자가 직접 입력해야 합니다.

비교 실행기는 앱 버전과 시험 조건만 기록합니다. 인증 페이지 내용·이메일·쿠키·토큰을 수집하지 않습니다. 새 시험 공간에 실제 로그인하면 그 공간에 세션이 저장되므로 해당 폴더를 공유하지 않습니다. `clean` 구성은 같은 UA·네트워크 정책·보안 설정에서 진단·로그인 감지·선택·영상·인증 오류 감지 스크립트와 제스처 preload를 제외합니다. Electron 최소 구성 비교 결과를 대신하지 않습니다.

공개 설치 파일은 macOS 서명·공증, Windows 패키지, 업로드 무결성, 양쪽 자동 업데이트 피드를 검증합니다. Windows 설치 파일은 기존 배포와 같이 미서명입니다. 개인·학교 계정의 신규 로그인, Drive·Gmail 원본 화면, Google 계정 추가, 두 프로필 왕복 전환, 다른 탭의 로그인 유지, 재시작과 재로그인은 [수동 검증 절차](../browser-auth-probe.md)로 별도 확인합니다.
