# 반달 v0.74.0

- PDF 메모와 화이트보드의 저장 상태를 정확히 표시하고, 저장 실패 시 작성 내용을 유지한 채 다시 저장할 수 있게 했습니다. 내보내기는 진행 중 저장과 이미지 준비가 끝난 뒤 실행하며 화이트보드의 이미지·PDF 클립도 포함합니다.
- 과목을 바꾸거나 탭을 옮기는 동안 끝난 작업이 현재 선택과 초안을 덮지 않게 했습니다. 작업 공간 복원에 실패하면 기존 구성을 보존하고 다시 불러올 수 있습니다.
- AI 대화·브라우저 실행의 취소와 승인 대상을 일치시키고, 전송 후 새로 입력한 초안과 첨부 자료를 보존합니다. 같은 브라우저 탭을 여러 대화가 동시에 제어하지 않게 했습니다.
- 학습 생성의 즉시 실패를 안내하고, 퀴즈 답 저장이 완료되지 않았을 때 잘못 채점하지 않게 했습니다. PDF 출처는 해당 페이지로 이동합니다.
- 검색·설정·즐겨찾기·일정·학교 선택·피드백에서 늦은 응답과 실패 복구를 개선했습니다. 메뉴의 Esc, 숨겨진 요소의 키보드 포커스, 사이드바 키보드 크기 조절도 다듬었습니다.
- 플러그인 실행을 격리된 Chromium 샌드박스로 옮기고, 앱 IPC와 화이트보드 첨부 자료의 권한 검증을 보강했습니다. 업데이트·계정 연결·진단·SDK·웹 체험의 오류 처리도 수정했습니다.

기능별 재현과 수정·검증 범위는 [전체 검토 기록](https://github.com/seojune662/bandal/blob/v0.74.0/docs/audit-2026-10-07.md)에 정리했습니다. 실제 개인 계정 인증과 운영체제 권한 허용은 모의 응답 자동 검사와 구분합니다. Windows 설치 파일은 기존과 같이 미서명입니다.
