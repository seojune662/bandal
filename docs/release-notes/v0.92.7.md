# v0.92.7 — 미리보기로 찾고 넓게 보는 자료

자료의 첫 페이지 미리보기 목록·폴더 탐색·정렬·넓게 보기와 폴더별 본문 검색을 추가한다. 열지 않은 긴 PDF도 별도 백그라운드 프로세스에서 색인하고, 저장된 첫 페이지 필기·하이라이트를 미리보기에 반영한다. 기존 간단히·아이콘·열·갤러리 보기와 프로젝트 자료를 유지한다. 구현 범위는 [v0.92.6](v0.92.6.md)에 기록했다.

v0.92.6은 공개 전 설치본 검사에서 기존 AI 단축키 기대값과 좁은 분할창의 전환 중 좌표 검사 실패를 발견해 공개하지 않았다. AI 단축키는 현재 제품 설계대로 오른쪽 AI를 열고 기존 브라우저 탭을 유지하는지 확인한다. 분할창 조절은 사이드바 전환과 분할선의 화면 좌표가 안정된 뒤 시작하며, 기존 실제 이동·필기 보존·복원 검증을 유지한다.

## 검증

이 버전도 공개하지 않았다. 설치본의 정상 미연결 AI 상태를 입력란 미표시로 오판하는 검사와, 닫힌 자료 목록의 저장 후 갱신이 문서 전체를 가로 스크롤하는 문제를 추가 확인했다. 최종 수정과 공개 결과는 [v0.92.8](v0.92.8.md)에 기록한다.

- 최초 앱 커밋의 CI는 관련 225개 파일·1,549개 단위 검사와 main/renderer/demo 타입 검사, 영향 검사 선택기 87개 및 대비 검사를 통과했다.
- v0.92.6 설치본에서 Windows 95개·macOS 94개 E2E가 통과했다. 신규 자료 목록·확장·미리보기·저장 필기 갱신·205페이지 본문 검색 및 이동은 양쪽 모두 통과했다.
- 수정 후 로컬에서 AI 단축키 흐름 1개와 1440px·1024px/125% 배율의 4분할 흐름 2개를 통과했다. 제품 코드는 변경하지 않았다.
- 최종 커밋과 플랫폼별 설치본 검사, 공개 자산 검증 결과는 배포 완료 후 기록한다.

실제 개인 계정 로그인·OS 권한 허용·물리적 OS 파일 드래그는 자동 검증 범위와 구분한다. Windows 설치 파일은 기존 설정대로 미서명이며 macOS 앱의 Developer ID 서명과 공증을 검증한다.
