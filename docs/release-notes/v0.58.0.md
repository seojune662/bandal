# 반달 v0.58.0

- 앱 전체를 중립적인 라이트·다크 화면으로 정돈했습니다. 새 설치에서는 기기의 화면 모드를 따릅니다. 기존 테마는 밝기에 맞는 모드로 자동 전환되며 과목·자료·필기·탭은 유지됩니다.
- 왼쪽에 과목·학업 보드·함께하기·더 보기·계정·설정을 여는 전역 메뉴를 추가했습니다. 사이드바 하단 메뉴를 옮기고 창 상단의 사이드바 버튼을 고정했습니다.
- 탭, 과목과 자료 목록의 중복 구분선과 장식을 줄였습니다. 검색·메뉴·설정·글꼴·여백을 같은 기준으로 정리했습니다.
- PDF 주석 도구를 필요할 때 펼치고 색상·굵기·투명도와 도형 도구를 팝오버에서 선택합니다. 좁은 화면에서도 도구와 내보내기에 접근할 수 있습니다.
- 기존 색상 계열과 플러그인의 전역 테마 적용을 종료했습니다. 설치된 플러그인과 글자 크기·필기 글꼴·밀도 설정은 유지됩니다.
- 시작 과정의 중복 설정 조회를 8회에서 1회로 줄였습니다. 어시스턴트 보조 창을 연 뒤 앱이 정상 종료되지 않던 문제도 수정했습니다.

변경 화면, 성능 측정 방법과 회귀 검증 범위는 [UI 개편 검증 기록](../ui-redesign.md)에 정리했습니다.
