# v0.78.0

- 탭 수와 영역 너비에 맞춰 탭을 자동으로 줄입니다. 제목을 표시할 공간이 부족하면 아이콘으로 전환하고, 더 많은 탭은 분할별 열린 탭 목록에서 검색·선택·닫을 수 있습니다.
- 웹사이트 파비콘과 PDF·마크다운 등 자료 종류 아이콘을 표시합니다. 각 영역의 선택 탭과 현재 입력 대상 영역을 구별합니다.
- 단일 영역, 좌우·상하 2분할, 2×2 4분할 배치를 제공합니다. 열린 탭을 순서대로 나누며 빈 영역도 재시작 후 복원합니다. 기존 편집기·브라우저 세션은 유지합니다.
- 분할 경계 전체 길이에서 크기를 조절할 수 있습니다. 창 버튼 여백과 전역 사이드바 버튼이 모든 분할에 반복되던 문제를 수정했습니다.
- 영역의 + 버튼과 비동기 문서 생성은 시작한 과목·영역을 기억합니다. 네이티브 브라우저 본문 클릭과 새 탭 단축키도 해당 영역을 대상으로 동작합니다.
- 탭을 과목 이름에 바로 놓아 이동할 수 있습니다. 300ms 호버 후 원하는 영역에 놓는 방식도 유지하며, 처음 여는 과목이 준비될 때까지 원본을 보존합니다.
- 실제 드롭 없이 드래그 종료만으로 분할되던 문제를 수정했습니다. 같은 과목·다른 과목 모두 본문 가장자리 36px에서만 분할을 안내하고, 취소·이동 실패 시 원래 배치로 복귀합니다.
- 이동 후에도 문서 원래 위치, 필기 실행 취소, PDF 읽기 위치, 브라우저·채팅·녹음 세션을 유지합니다. 이동한 문서의 경로 복사도 원래 과목을 사용합니다.
- 사이드바 크기에 따라 PDF 도구 모음의 줄 수가 바뀌어도 본문 높이 변화를 함께 반영해 읽던 지점을 유지합니다.

## 검증

변경 영역의 단위 검사와 main/renderer 타입 검사를 실행합니다. 실제 Electron 포인터로 탭 순서 변경·분할·취소·과목 이동, 4분할 경계 조절, 빈 영역 복원, 압축 탭 목록과 네이티브 브라우저 포커스를 확인합니다. 밝은/어두운 테마와 좁은 창·125% 확대를 포함합니다. 기존 문서·화이트보드·브라우저·채팅·녹음 이동 회귀도 검증합니다.

CI는 변경 의존성에 연결된 검사만 실행하고 릴리스가 동일 커밋의 결과를 재사용합니다. macOS·Windows 패키지에서는 해당 기능 E2E를 실행하고, macOS 서명·공증 및 모든 설치 파일·업데이트 피드의 업로드 무결성과 공개 여부를 확인합니다.

자동 검사는 임시 프로필과 로컬 웹 페이지, 모의 마이크·채팅 응답을 사용합니다. 실제 개인 사이트 로그인과 OS 마이크 권한, 사용 중인 앱의 업데이트 설치·재시작은 직접 확인한 범위에 포함하지 않습니다.
