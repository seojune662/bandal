# v0.89.0 — 자료 도구 모음과 공유

PDF·마크다운·노트·이미지·파일·녹음의 탭 아래에 제목과 AI만 반복하던 줄을 제거했다. AI와 공유 버튼은 각 자료의 기존 도구 모음에서 사용할 수 있다.

- 공유 버튼으로 자료마다 저장 위치를 골라 내보낸다. 마크다운은 아직 저장 중인 편집을 먼저 반영하고, 이미지·문서·영상·오디오는 원본 형식을 보존한다.
- PDF는 주석 도구를 펼치지 않아도 공유할 수 있다. 필기·텍스트·하이라이트 저장을 기다린 후 주석 포함 PDF를 만들며 원본 PDF는 유지한다. 화이트보드도 PDF로 내보낸다.
- 좁은 탭은 마우스를 올리거나 키보드 초점을 주면 아이콘 자리에 닫기 버튼이 나타난다. 탭 닫기는 원본 자료 삭제와 별개다.
- 사이트가 여러 파비콘을 제공하면 사용 가능한 후보를 찾고 기본 favicon.ico도 확인한다. 이미지의 실제 형식을 검사해 잘못된 서버 MIME 응답과 인라인 이미지도 처리하며 일시적인 실패는 다시 시도한다.

## 로컬 검증

- 파비콘·탭 아이콘 단위 21개, 내보내기·화이트보드 단위 35개, PDF 저장 세션·주석·마크다운 세션 단위 44개와 AI 보조 패널 단위 16개 통과.
- node/web/web-demo 타입 검사, 앱 빌드와 영향 검사 선택 스크립트 78개 통과.
- 실제 Electron에서 최신 Markdown·편집 중인 PDF 텍스트의 내보내기, 원본 바이너리 보존, 화이트보드·녹음 자막 저장/취소, 32px·compact 탭 닫기, 실제 파비콘 디코딩, 마크다운 서식과 좁은 PDF 도구 모음을 확인했다.
- 일반 폭과 1024px 창의 양 사이드바·좌우 분할에서 공유·AI 버튼 배치와 밝은/어두운 테마를 확인했다. 같은 PDF를 여러 탭에 열었을 때 모든 해당 저장 세션을 기다리며, 다른 파일의 저장 실패는 내보내기를 막지 않는다.

파일 선택 결과와 녹음은 합성 fixture로 검증했다. 실제 마이크 권한·음성 인식 모델 다운로드·개인 로그인 사이트는 이번 자동 검증 범위에 포함하지 않는다. Windows 설치 파일은 기존과 같이 미서명이다.

## 공개 검증

macOS·Windows 설치본 검사 및 배포 산출물 검증 결과는 배포 완료 후 기록한다.
