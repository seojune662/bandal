# v0.98.2 — iPad 같은 설정창, 동기화 탭 (v0.98.0·v0.98.1 공개분)

앱 변경은 v0.98.1과 같다. [`v0.98.1.md`](v0.98.1.md)와 [`v0.98.0.md`](v0.98.0.md)의 변경을 모두 담는다. v0.98.1은 Windows 설치본 E2E의 검사 한 줄이 타이밍에 따라 실패해 공개하지 않았다.

## 바뀌는 점 (v0.98.1 대비)

- 앱 코드 변경은 없다.
- `e2e/recordingUx.spec.ts`의 AI 연결 상태 검사를 고쳤다. AI 패널의 과목 이름을 글자로 찾았는데, AI가 연결된 상태에서는 자동 연결 자료 칩이 불러와지면 같은 이름이 한 번 더 나타났다. 이 칩이 검사보다 먼저 뜨면 두 요소가 잡혀 strict mode 위반으로 실패했다. 이제 패널 머리글의 `title`로 찾는다.

## 검증

- v0.98.1 릴리스 run 44240663591의 결과:
  - macOS 빌드와 설치본 E2E(영향 스펙 19개)는 통과했다.
  - Windows는 51개 중 `recordingUx`의 AI 연결 상태 검사 1개만 위 이유로 실패했다.
- `recordingUx` 3개 검사를 개발 빌드에서 세 번 연속 실행해 모두 통과했다.
- 2026-11-18 공개했다. 릴리스 커밋은 `043ad96`, 릴리스 run은 44244988284이다. macOS와 Windows 빌드, 그리고 두 플랫폼의 설치본 E2E(영향 스펙 19개)가 한 번에 통과했다. iPad 도우미 3종도 성공했다.
- 공개 자산 12개를 확인했다. `latest-mac.yml`·`latest.yml`이 0.98.2를 가리키고, 받은 `Bandal-arm64.dmg`의 SHA-512가 피드 값과 일치한다.
- 받은 `Bandal-arm64.dmg` 안의 앱은 Developer ID 서명·공증 검사(`spctl` accepted, Notarized Developer ID)와 스테이플 검사(`stapler validate`)를 통과했고, 버전은 0.98.2다. `app.asar`에 `Bandal-Desktop/` User-Agent가 들어 있다.
- 웹사이트 버전 표시는 bandal_web `b22dd9b`(0.97.0 → 0.98.2)로 갱신했다. 이 커밋은 Vercel이 모르는 작성자 주소로 만들어져 배포가 막혔다. 그래서 이전 동기화 커밋과 같은 작성자로 빈 커밋 `5a497c7`를 올려 배포했고, bandal.io에 0.98.2가 보이는 것을 확인했다.
