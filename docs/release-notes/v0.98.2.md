# v0.98.2 — iPad 같은 설정창, 동기화 탭 (v0.98.0·v0.98.1 공개분)

앱 변경은 v0.98.1과 같다. [`v0.98.1.md`](v0.98.1.md)와 [`v0.98.0.md`](v0.98.0.md)의 변경을 모두 담는다. v0.98.1은 Windows 설치본 E2E의 검사 한 줄이 타이밍에 따라 실패해 공개하지 않았다.

## 바뀌는 점 (v0.98.1 대비)

- 앱 코드 변경은 없다.
- `e2e/recordingUx.spec.ts`의 AI 연결 상태 검사를 고쳤다. AI 패널의 과목 이름을 글자로 찾았는데, AI가 연결된 상태에서는 자동 연결 자료 칩이 불러와지면 같은 이름이 한 번 더 나타났다. 이 칩이 검사보다 먼저 뜨면 두 요소가 잡혀 strict mode 위반으로 실패했다. 이제 패널 머리글의 `title`로 찾는다.

## 검증

- v0.98.1 릴리스 run 44240663591의 결과:
  - macOS 빌드와 설치본 E2E(영향 스펙 19개)는 통과했다.
  - Windows는 51개 중 `recordingUx`의 AI 연결 상태 검사 1개만 위 이유로 실패했다.
- `recordingUx` 3개 검사를 개발 빌드에서 세 번 연속 실행해 모두 통과했다.
