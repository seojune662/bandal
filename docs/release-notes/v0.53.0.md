# v0.53.0 — 일정 기간 설정과 화면 잘림 수정

- **하루 마감 일정 전송 수정**: Apple 캘린더로 보낼 때 마감 시각에 임의의 1시간을 더하던 동작을 제거했습니다. 23:59 마감도 다음 날로 넘어가지 않습니다.
- **기간 지정**: 달력과 학업보드 편집창에서 시작일·종료일, 시작·종료 시각을 지정할 수 있습니다. 여러 날 종일 일정도 지원합니다. 종일 일정은 선택한 마지막 날까지 표시하고, 시간 일정은 종료 시각을 그대로 반영합니다.
- **기간 표시와 기존 데이터 유지**: 월을 넘는 일정도 겹치는 날짜마다 표시합니다. 기존 마감일과 알림 기준은 유지됩니다.
- **화면 잘림 수정**: 학업보드 편집창과 우클릭 메뉴, 새 탭·과목·자료·즐겨찾기·그룹·도움말·브라우저 메뉴·자료 연결 패널이 창의 경계를 벗어나지 않도록 위치와 스크롤을 조정합니다. 창 크기 변경, 화면 확대, 입력 항목 증가에도 대응합니다. 긴 권한·피드백·참여 안내 창과 노트 삽입 메뉴의 스크롤도 보완했습니다.
- **저장 버튼 가림 수정**: 학업보드를 열었을 때 도우미가 저장 버튼을 가리지 않도록 표시 순서를 조정했습니다.

이전 버전에서 이틀로 전송된 일정은 해당 일정을 열고 **저장하고 Apple 캘린더로 보내기**를 다시 누르면 기존 항목이 갱신됩니다. 반달이 개인 캘린더를 자동 수정하지는 않습니다.

검증: 단위 테스트 3,197개 통과(선택 테스트 11개 제외), Electron E2E 106개 통과(선택 테스트 4개 제외), 타입 검사·미사용 코드 검사·프로덕션 빌드. 날짜 경계·기간 중첩·기존 DB 마이그레이션 회귀 테스트, 한국/UTC/뉴욕 시간대 테스트, 작은 창·확대 화면의 실제 Electron 입력/저장 테스트, macOS EventKit 도구 컴파일. 개인 Apple 계정의 권한 허용과 실제 저장은 자동 테스트에 포함하지 않습니다.
