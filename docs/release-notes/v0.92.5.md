# v0.92.5 — 빈 상단 여백 없이 탭 배치

작업 화면의 탭을 창 맨 위에 배치하고, 오른쪽 위 고정 버튼 세 개는 독립된 박스로 유지한다. 실제 모서리와 겹치는 분할에만 제어 영역을 확보하며, 사이드바·분할 변경과 탭·도구 숨김에서도 문서와 브라우저 세션을 보존한다. Windows 자료 사이드바의 중복 상단 여백도 없앴다.

구현과 최초 검증은 [v0.92.4](v0.92.4.md)에 기록했다. 해당 버전은 설치본 검사에서 좁은 화면 분할선의 끝점 상태를 잘못 판정해 공개하지 않았다. 최소 너비에 도달한 분할선도 반대 방향으로 조절할 수 있으므로 해당 상태를 포함하고, 위·중간·아래 각 위치에서 실제 이동까지 검사한다. 탭과 고정 버튼을 보호하는 제품의 최소 너비는 유지한다. macOS의 좁은 브라우저 메뉴는 닫힐 때 버튼으로 포커스를 복원해 툴팁을 표시할 수 있으므로, 포인터 이동과 Escape로 임시 툴팁을 닫고 DOM에서 사라진 뒤 네이티브 웹뷰 표시를 검사한다. 실제 미리보기 합성·비공개 마스킹 검사는 유지한다.

## 검증

- 제품 변경의 모서리·탭·콘텐츠 단위 검사 22개, web·demo 타입 검사, 앱 빌드 및 직접 영향 Electron 검사 16개 통과. 최초 원격 CI는 관련 194개 파일·1,246개 검사 통과.
- 끝점 검사 보완 후 로컬 macOS 4분할 검사 2개 및 Windows 모서리 배치·125% 확대 재현 검사 1개 통과. Windows 배치는 로컬에서 HTML 플랫폼 속성으로 재현했고 실제 OS 동작은 배포 설치본에서 확인한다.
- 시크릿 모드 검사 보완 후 고정 제어·세 표시 모드·실제 미리보기 합성·비공개 가림·프로젝트 전환을 포함한 해당 Electron 시나리오 1개 통과.
- 최종 앱 커밋 `fa87aaecfe8523d78ca7085c779c69c7ed224a33`의 [CI](https://github.com/seojune662/bandal/actions/runs/40382765563)는 영향받는 194개 파일·1,246개 검사와 web 타입 검사를 통과했다.
- 같은 커밋의 [릴리스 작업](https://github.com/seojune662/bandal/actions/runs/40383129868)은 macOS·Windows 설치본 E2E 각각 65개를 통과했다. 실제 OS 전체 화면 전환, 고정 버튼 위치, 분할·사이드바 조절, 표시 모드, 네이티브 웹뷰 미리보기와 비공개 가림을 포함한다. Windows 첫 실행은 자료 드롭 검사에 진입하기 전 앱 시작 대기에서 시간 초과됐으며, 코드·시간 제한·검사 목록을 바꾸지 않고 실패한 Windows 작업만 재실행해 65개 모두 통과했다.

- [v0.92.5](https://github.com/seojune662/bandal/releases/tag/v0.92.5)를 2026-10-27 04:31:42 KST에 공개했다. 태그와 설치본의 앱 커밋은 위의 `fa87aae`로 일치한다.
- macOS Apple Silicon·Intel 설치 파일과 Windows 설치 파일, blockmap, 두 자동 업데이트 피드 등 자산 12개의 업로드 무결성을 릴리스 작업에서 검증했다. 공개 후 모든 자산의 익명 HTTP 200 응답과 파일 크기, 최신 릴리스 및 `latest` 다운로드 경로의 피드 버전 `0.92.5`를 확인했다.

- 홈페이지 [릴리스 동기화](https://github.com/seojune662/bandal_web/actions/runs/40387709902)와 프로덕션 배포가 성공했다. 한국어·영어 홈, 문서, 변경 기록의 6개 경로에서 HTTP 200, 버전 `0.92.5`, macOS 두 종류와 Windows 설치 파일 링크를 확인했다.

실제 개인 계정 로그인·OS 권한 허용은 자동 검증 범위에 포함하지 않는다. Windows 설치 파일은 기존 설정대로 미서명이며 macOS 앱은 Developer ID 서명과 공증을 검증한다.
