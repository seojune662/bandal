# 반달 v0.59.0

- 브라우저 탭을 여러 개 열어도 다른 탭으로 이동한 페이지의 입력·스크롤·탐색 기록을 유지합니다. 로그인 팝업의 POST·opener 연결과 기존 프로필도 보존합니다.
- 탭 닫기·프로필 전환·앱 종료의 확인 흐름을 통합했습니다. 취소한 페이지가 그대로 남고, 재시작할 때 탭 배치가 복원됩니다.
- Chrome·Edge·Firefox 프로필과 Safari 내보내기 파일을 가져올 수 있습니다. 대상 반달 프로필과 쿠키·비밀번호·북마크·기록을 선택하고, 진행·취소·결과를 확인합니다. OS가 허용하지 않는 암호화 데이터와 Safari 쿠키는 다시 로그인해야 합니다.
- 같은 사이트의 여러 비밀번호 계정을 보관하고 로그인할 계정을 선택합니다. 기존 암호화 저장소는 자동으로 변환됩니다.
- 탭 드래그의 회색 가림막을 반투명 이동 안내로 바꾸고 드래그 카드에서 닫기 버튼을 제거했습니다. 재정렬·분할·합치기·Escape 취소를 정돈했습니다.
- 비활성 탭을 닫아도 작업 중인 탭이 바뀌지 않습니다. X·중클릭·메뉴·단축키의 닫기와 복원을 통합하고, 현재 그룹과 전체 그룹의 다른 탭 닫기를 구분합니다. 시크릿 탭은 복원 기록에 남기지 않습니다.
- 늦게 열린 필기 편집기가 탭의 키보드 포커스를 빼앗던 문제를 수정했습니다. 작은 창과 확대 화면에서도 이동 방향 안내 전체를 읽을 수 있습니다.

원본별 지원 범위와 검증 기록은 [브라우저·탭 개편 검증](../browser-0.59.md)에 정리했습니다.
