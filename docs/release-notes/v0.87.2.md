# v0.87.2 — 공식 커뮤니티와 공모 준비

공식 커뮤니티와 공부 도구 공모 기능을 추가하고 학습자료 마켓플레이스의 신규 거래를 종료한다. 공모는 **미공개·일정 미정**으로 유지한다. 기능·보존 정책은 [커뮤니티 변경 안내](v0.87.0.md)와 [운영 문서](../community.md)를 따른다.

같은 배포에 사이드바 여백, 브라우저 마우스 입력과 인증 처리 수정이 포함된다. 해당 기능과 실제 로그인 확인 범위는 [브라우저 변경 안내](v0.87.1.md)에 기록했다.

v0.87.0 배포는 위 변경을 함께 공개하기 위해 중단했다. v0.87.1은 CI에서 새 커뮤니티 IPC 모듈의 검사 수집 경로와 이전 마켓 메뉴 이름을 기대하던 검사 3개가 실패해 공개되지 않았다. 이번 버전은 커뮤니티 계약·핸들러를 정적 검사에 포함하고 메뉴 기대값을 갱신한다. 웹 체험판의 PDF 정보·이전 필기 확인·공유 수신 목록 연결도 보완한다.

## 검증

커뮤니티 API·초안·로그인 복귀·운영 화면, 실제 PostgreSQL 권한·마감·심사본·동시성, 운영 서버의 익명 접근 경계와 신규 거래 차단을 확인했다. 운영 검증에 사용한 글과 캠페인은 트랜잭션 롤백으로 모두 제거했다.

Electron에서 커뮤니티 전환과 기존 작업 보존, 공모 안내창 한 번 표시, 실패 후 응모 재시도·댓글·공감, 실제 딥링크의 응모 화면 연결을 확인했다. 웹 공모 흐름 30개, 기존 결제 복귀 10개, PDF 초기·복원 및 커뮤니티 이동을 포함한 웹 체험판 8개 검사를 통과했다.

실제 개인 계정의 외부 OAuth 로그인과 상금 지급은 커뮤니티 자동 검증 범위에 포함하지 않는다. 공모 접수 시작·마감·발표일과 최종 모집 요강을 확정한 뒤 운영 화면에서 공개한다.
