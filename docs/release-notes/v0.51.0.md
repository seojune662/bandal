# v0.51.0 — Apple 캘린더 연결과 실제 앱 웹 체험

- **설정 → 달력** 또는 **달력 → ···**에서 Apple 캘린더를 연결합니다. Mac에 등록된 캘린더를 선택해 반달 과제와 함께 봅니다.
- 과제를 편집한 뒤 **저장하고 Apple 캘린더로 보내기**로 전송합니다. 다시 보내면 기존 일정을 갱신하며 읽기 전용 캘린더에는 쓰지 않습니다. 자동 양방향 동기화는 하지 않습니다.
- 권한 거절·해제, 삭제된 캘린더, 연결 해제와 조회 중 설정 변경을 처리합니다. 외부 일정은 기기에서 읽고 반달 서버에 보내지 않습니다.
- 분할 화면에서 포커스하지 않은 PDF도 바로 로딩되도록 수정했습니다. 좁은 달력 패널에서는 일정 상세가 아래로 배치되며 다른 화면에서 추가·수정한 과제도 갱신됩니다.
- 웹사이트 체험은 실제 앱의 PDF 뷰어·Milkdown·탭·페이지 필기·보드·달력·AI UI를 사용합니다. 브라우저 저장·복원·Markdown 내보내기를 지원하며 AI 응답은 예시임을 표시합니다.
- 웹사이트의 테마를 하단의 모든 체험 화면에도 즉시 반영합니다. Safari가 색상을 읽는 문서 배경·상단 배경과 브라우저 메타데이터를 함께 갱신합니다.

검증: 앱 타입·미사용 코드 검사, 단위 테스트 3,162개, 격리된 Electron 캘린더 E2E 2개, Swift 도구 arm64·x64 컴파일. 개인 캘린더의 실제 권한 허용·일정 전송은 자동 검사에서 수행하지 않습니다.
