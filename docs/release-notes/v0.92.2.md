# v0.92.2 — 고정 화면 제어와 다중 윈도우

한 과목이나 프로젝트 안에서 여러 작업 화면을 유지하고, 필요한 탭·도구만 표시할 수 있다.

- 오른쪽 위의 둥근 고정 버튼 묶음에서 탭·도구 표시, 윈도우 관리, 오른쪽 사이드바를 제어한다. 공통 44px 상단 영역 아래에 작업 화면과 사이드바를 배치하고 Windows 창 제어 공간을 확보한다.
- 표시 메뉴는 모두 표시, 탭 바만 숨기기, 탭 바와 도구 모음 숨기기를 제공한다. 현재 윈도우의 모든 분할에 적용하며, 문서 내용과 녹음·저장 오류 표시는 유지한다.
- 과목·프로젝트마다 윈도우 추가, 선택, 이름 변경, 순서 변경과 닫기를 제공한다. 각 윈도우의 탭·분할·표시 모드와 PDF 페이지·확대율·노트 보기 위치를 저장한다. 마지막 윈도우는 유지하며, 닫기 전 문서 저장이나 기존 닫기 검사가 실패하면 닫지 않는다.
- 관리 화면에서 실제 작업 화면의 축소본을 보여 준다. 네이티브 브라우저 화면을 합성하고 비공개 탭의 제목·주소·내용을 가린다. 축소본은 프로필별 로컬 캐시에 최신 한 장만 보관한다. 캡처 실패 시 이전 이미지를 유지한다.
- 자료와 오른쪽 AI는 같은 과목·프로젝트의 윈도우끼리 공유한다. 윈도우를 닫아도 자료 파일을 삭제하지 않는다. 관리 화면과 비활성 윈도우에서는 편집기·웹뷰 입력을 차단한다.
- 학교·AI 바로가기는 과목과 프로젝트를 전환해도 같은 위치와 접힘 상태를 유지한다. 자료 헤더의 제목·소속은 왼쪽, 가져오기·추가·새로고침은 오른쪽에 모으고 보기 선택기는 파일 목록 제목에 배치한다.
- 기존 단일 화면은 첫 윈도우로 읽고 다중 윈도우 저장 구조로 이전한다. 자료 이름 변경·삭제와 프로젝트 이동·복사는 비활성 윈도우에도 반영한다. 비동기 열기는 시작한 윈도우를 대상으로 완료한다.

## 검증 범위

변경 영역의 저장 구조·이전·닫기 취소·비동기 전환·탭 이동, 미리보기 IPC·캐시·비공개 마스킹, PDF·노트 보기 상태, 고정 제어·사이드바 회귀 검사를 수행한다. 실제 Electron에서 PDF·브라우저·노트 분할의 세 표시 모드, 고정 좌표와 Windows 창 제어 간격, 미리보기 합성, 프로젝트 전환, 윈도우 관리와 재시작 복원을 검사한다.

v0.92.0은 공개 전 설치본 검사에서 중단했다. v0.92.1에서 화면 전환 중 브라우저 요청과 AI 사이드바 선택을 보존하고, 사이드바 폭 계산과 PDF 연속 확대를 수정한다. 영어 프로젝트의 첫 사용 안내와 다시 보기도 현재 프로젝트 화면에 연결한다. 프로젝트를 읽는 동안의 자료 이름 변경은 잠금이 풀린 뒤 시작하며, 도구 줄을 숨겨도 노트 저장 오류를 표시한다.

로컬 관련 회귀 검사와 Node·Web·웹 데모 타입 검사, 통합 빌드가 통과했다. Electron의 화면 제어·미리보기·과목/프로젝트 독립성, PDF 보기 복원, 노트 보기 복원 3개 시나리오가 통과했다. 네 윈도우 전환 중 편집기 DOM과 네이티브 브라우저 세션 보존도 확인했다. 후속 수정은 실패한 시나리오와 직접 연결된 실제 앱 회귀 25개를 선택해 확인했다. 24개는 통과했으며 AI 전환은 수정 후 해당 시나리오만 재검사했다. 로컬 macOS의 네이티브 전체화면 요청 미처리 현상은 이전 버전과 동일하여, 이 항목은 배포용 macOS 설치본 검사 결과로 구분한다. 실제 Windows 설치본 검사는 릴리스 작업에서 수행한다.

CI는 `scripts/affected-checks.mjs`의 영향 범위를 사용한다. 릴리스는 동일 커밋의 성공한 CI를 재사용하고 macOS·Windows 설치본의 선택된 E2E, macOS 서명·공증, 설치 파일 업로드 무결성과 자동 업데이트 피드 공개를 확인한다.

## v0.92.2 공개 전 보완

v0.92.1 설치본 검사에서 macOS 153개, Windows 157개가 통과했지만 각각 5개와 1개가 실패하여 공개하지 않았다. 두 플랫폼 모두 고정 화면 제어·미리보기, 윈도우별 PDF·노트 보기 복원 시나리오는 통과했다.

Windows의 PDF 페이지 복제는 파일 교체 잠금 대기 중 이벤트 처리를 막던 재시도를 비동기로 바꾼다. 각 실패 시 SQLite와 파일을 원래 상태로 돌린 뒤 대기하며, 그대로인 원본을 불필요하게 덮어쓰지 않는다. 외부 수정이나 복구 실패가 있으면 재시도를 중단하고 복구 기록을 보존한다.

과목 드래그 전환은 요청한 목적지 캔버스가 활성화된 후에만 드롭 미리보기와 놓기를 허용한다. 즐겨찾기·노트 복귀 검사는 현재 작업 공간을 정확히 선택하고, 로그인 카드 검사는 네이티브 페이지가 실제 표시된 후 신뢰된 마우스 입력으로 폼을 제출한다.

로컬에서 PDF 트랜잭션·연결 노트 14개, 드래그 전환·드롭 29개, 비동기 열기·윈도우 저장·활동 기록 101개 집중 검사가 통과했다. Node·Web·웹 데모 타입 검사와 통합 빌드가 통과했고, 실제 앱에서 PDF 페이지 편집·노트 이동·충돌 취소·반복 이동 4개 및 로그인·즐겨찾기 2개 시나리오가 통과했다. 최종 설치본·공개 자산 결과는 검증 완료 후 기록한다.

전환 중 자료 클릭은 목적지 과목·프로젝트와 내부 윈도우를 클릭 시점에 고정한다. 이후 다른 화면으로 이동해도 원래 윈도우에 열리며, 아직 불러오지 않은 작업 공간과 늦은 녹음 조회, 같은 자료의 두 윈도우 동시 열기를 포함해 검증했다.
