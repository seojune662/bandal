# v0.85.0 — 노트·계정·동기화 통합

새 창과 설정의 탭 종류를 **노트 → 브라우저 → 마크다운 → AI → 녹음** 순서로 통일했다. 새 노트는 A4 PDF이며 빈 종이·줄·모눈·점과 세로·가로를 지원한다. 기본값은 흰 줄 종이·세로다. 기존 학업 보드·학습 공간·플러그인 자료와 저장된 창은 유지한다.

기존 화이트보드는 배경 PDF와 편집 가능한 객체로 이전한다. 원본과 첨부파일, 어두운 종이와 밝은 필기, PDF 클립을 보존하며 같은 원본의 중복 이전을 방지한다. 페이지 추가·삭제·복제·회전·순서 변경에는 문서 버전과 페이지 대응 관계를 기록한다. 이전 페이지에 저장하지 못한 필기는 복구 노트로 되살릴 수 있다. PDF 클립은 만들 당시 원문 버전을 보존해 원문의 페이지가 바뀌어도 다른 페이지를 가리키지 않는다. iPad V5 필기의 표시·지우개·내보내기도 공통 코드로 처리한다.

작업공간은 최초 로그인과 로컬 자료의 계정 확인 뒤 열린다. 한 번 인증된 프로필은 오프라인에서도 편집할 수 있으며, 서버 토큰 갱신 실패가 로컬 접근을 취소하지 않는다. 로그인 전 전체 백업을 허용하고 다른 계정은 검증된 백업 후 별도 프로필을 사용한다. 명시적 로그아웃과 계정 삭제는 프로필을 잠근다.

동기화는 현재·미래의 모든 과목에 대한 별도 동의를 받는다. 첫 버전 범위는 과목·자료·PDF 노트·마크다운·필기이며, AI 대화·학습 진도·녹음 세션 등 범위 밖 레코드와 대기는 보존한다. 미구독·용량 초과·권한 거절을 구분해 업로드를 중단하고 기존 자료 다운로드와 로컬 변경을 유지한다. 계정 화면에서 마지막 완료·대기·용량·중단 이유·충돌 복구를 확인할 수 있다.

서버와 웹은 Paddle·Apple의 공통 이용권과 구매처를 표시한다. 5 GiB는 계정당 한 번 제공하며 중복 구매를 줄인다. 계정 삭제는 진행 중 거래·정산을 정리한 뒤 가능하고 완료 거래는 개인정보를 제거해 보관한다. 구독 해지는 구매처에서 별도로 진행한다.

## 검증 및 배포 기록

- 로컬: 계정·프로필 백업·PDF 버전·객체 이전·클립 원문·V5 필기·동기화 범위에 직접 관련된 단위/통합 검사와 main·renderer·web-demo 타입 검사를 통과했다.
- 실제 Electron 화면: 최초 로그인 제한, 로그인 전/계정 기록 손상 시 검증된 전체 백업, 오프라인 프로필의 노트 생성/페이지 편집, 이전 PDF에 남은 필기 복구, 메뉴·설정의 다섯 탭 순서, 클립 배치·텍스트 편집·지우개·과목 이동·이전 노트 미리보기를 통과했다. 전용 도구 메뉴의 기존 플러그인 명령과 패널도 검사했다.
- 이 Mac의 네이티브 전체 화면 검사는 OS 전환 이벤트가 발생하지 않아 실패했다. 동일 Electron의 빈 독립 창에서도 전환이 거절되는 것을 재현했으며 제품 검사 기대값은 유지한다. 서명된 배포 앱의 CI 결과를 별도로 확인한다.
- iPad: 별도 검증 번들로 실제 iPad에서 노트 생성·페이지 추가/삭제·자료 목록 복귀를 43.496초에 통과했고 renderer/IPC 오류가 없었다. 오프라인 미전송 필기 복구·충돌 요약·첫 snapshot 전 native surface 종료의 저장 응답 검사도 통과했다. 개인 계정 또는 실결제 자료를 사용한 검사는 아니다.
- 서버: 운영 기본 스키마/권한 대조 후 추가 마이그레이션과 함수 배포를 확인했다. 상세 증거는 [Apple 구독·계정 삭제 운영 기록](../apple-billing-and-account-deletion.md)을 따른다.
- 배포 설치 파일 및 CI 결과는 공개 확인 후 아래에 기록한다. 검사를 시작하거나 설치 파일을 빌드한 상태만으로 공개 완료라고 보고하지 않는다.

## 외부 준비가 필요한 범위

Apple 앱과 구독 상품은 아직 App Store Connect에 등록되지 않았다. Apple 서버 키도 미설정이므로 Apple 구매/알림 endpoint는 비활성이다. StoreKit 코드·서명 검증·복원·알림 원장은 구현했지만 실제 Apple 로그인, Sandbox/TestFlight 구매, App Store 심사·공개 성공을 의미하지 않는다. iPad의 별도 검증 앱과 원래 사용자 앱을 구분한다.

실제 개인 계정 로그인, OS 권한 허용, 실제 결제와 물리 기기 간 왕복 검증 결과는 자동 검사와 분리해 최종 배포 보고에 기록한다. Windows 설치 파일의 기존 코드 서명 상태를 macOS Developer ID 서명·공증과 혼동하지 않는다.
