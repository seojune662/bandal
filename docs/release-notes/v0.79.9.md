# v0.79.9

- 브라우저의 중복 사이트 제목·AI 행(34px)을 없애고 AI 버튼을 주소 도구 모음에 합쳤습니다. 주소창과 현재 프로필은 유지하며 좁은 분할에서는 보조 기능을 더 보기 메뉴에 모읍니다.
- 화면을 아래로 밀던 비밀번호 저장 배너를 주소창 옆의 작은 안내로 바꿨습니다. 클릭하면 사이트와 계정을 확인하고 저장·업데이트·이번엔 안 함·이 사이트는 묻지 않기를 선택할 수 있습니다. 안내를 닫아도 즉시 저장하거나 거절하지 않습니다.
- 다른 계정을 추가할 때 기존 계정의 비밀번호 업데이트로 잘못 표시하지 않습니다. Google의 패스키·추가 인증·거절 단계에서는 저장을 먼저 묻지 않으며, 만료된 저장 후보도 화면에서 정리합니다.
- 브라우저의 실제 Bandal 이름·버전과 Chromium 버전은 보존하고 Electron 라이브러리 토큰만 제외합니다. 앱 시작 시 한 번 설정하여 일반 탭·리디렉션·팝업·프로필·시크릿에서 요청과 페이지 식별값을 일치시킵니다. 다른 브라우저로 가장하거나 Google 계정의 보호자 승인·연령·서비스 제한을 변경하지 않습니다.
- Google이 Family Link 계정 로그인을 거절하면 해당 사유를 구분합니다. 원래 사이트에서 새 로그인 절차를 시작하거나 외부 브라우저에서 열 수 있으며, 외부 브라우저의 로그인 세션이 반달로 옮겨지지 않는다는 점을 안내합니다.

## 확인한 원인과 검증 범위

동일한 Google 공개 로그인 주소에 계정·쿠키 없이 요청한 비교에서 기존 Electron 토큰 포함 식별값은 `WebLiteSignIn`, Bandal 이름과 실제 Chromium 버전을 보존하고 Electron 토큰만 제거한 값은 `GlifWebSignIn`으로 이동했습니다. 이는 로그인 흐름 선택 차이의 증거이며, Family Link 인증 완료를 의미하지는 않습니다.

v0.79.8에서 실제 확인한 학교·개인 계정과 이번 Family Link 관리 계정은 서로 다릅니다. 이전 버전의 일반 계정 성공으로 관리 계정의 지원까지 검증됐다고 보지 않습니다. Orca에서 같은 관리 계정의 Drive가 열린 것은 확인했고, Orca 구현은 Google 인증 호스트에서 Firefox 식별값을 별도로 사용합니다. 이번 변경은 반달의 실제 브랜드와 엔진을 유지합니다.

직접 회귀는 브라우저 상단·비밀번호 카드의 라이트/다크·좁은 분할·키보드 조작, 계정별 저장 여부·만료·Google 추가 인증 단계, Family Link 거절 감지·공식 승인 화면 오탐 방지, 실제 HTTP 요청과 페이지 식별값의 일관성을 대상으로 합니다.

실제 Family Link 계정의 최종 인증과 설치 앱 결과는 공개 배포본 검증 후 기록합니다. 보호자 승인과 개인 비밀번호 입력은 계정 소유자가 진행합니다.
