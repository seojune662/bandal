# 반달 v0.57.0

- 떠 있는 AI 채팅이 웹페이지 뒤에 가려지던 문제를 수정했습니다. 채팅을 열어 둔 상태에서도 옆의 웹페이지를 사용할 수 있습니다.
- 브라우저에 독립 프로필을 추가했습니다. 같은 과목에서도 탭마다 개인·학교 등 다른 계정을 선택하고 전환할 수 있습니다. 기존 로그인은 기본 프로필로 유지됩니다.
- 로그인·방문 기록·사이트 권한·확장 설정을 프로필별로 분리했습니다. 다운로드와 PDF 원본 요청에도 해당 탭의 로그인을 사용합니다.
- 두 손가락으로 가로로 쓸어 뒤로·앞으로 이동할 수 있습니다. 페이지의 가로 스크롤과 확대 동작을 구분하며 설정에서 끌 수 있습니다.
- 프로필 전환 시 작성 중인 페이지의 이탈 확인을 거치고, 재시작 시 선택한 프로필과 로그인 상태를 복원합니다.

Chrome 웹 스토어 전반 지원은 별도 호환성 평가를 마쳤으며 상용 라이선스 확보 후 통합·배포할 예정입니다. 이번 버전에는 기존 범위의 확장 폴더 설치를 프로필별로 제공합니다.
