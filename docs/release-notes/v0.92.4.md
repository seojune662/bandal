# v0.92.4 — 빈 상단 띠 없이 탭 배치

작업 화면의 탭을 창 맨 위로 올리고, 오른쪽 위 고정 버튼 세 개는 독립된 박스로 유지한다.

- 중앙 작업 화면이 기존 44px 상단 행까지 사용하므로 탭 위에 빈 띠가 생기지 않는다. 왼쪽 학교·AI 영역과 오른쪽 자료·AI 사이드바는 고정 제어 버튼 아래에 유지한다.
- OS 창 버튼·왼쪽 사이드바 버튼·오른쪽 고정 제어와 겹치는 상단 분할에만 가로 공간을 예약한다. 사이드바 폭 조절·접기·전체화면·분할 재배치 시 실제 좌표로 다시 계산한다. Windows의 좁은 오른쪽 사이드바에서도 창 제어 버튼과 충돌하지 않는다.
- 탭을 숨기면 고정 버튼과 겹치는 모서리 패널만 필요한 높이를 확보한다. 나머지 패널은 상단까지 사용하며, 네이티브 웹 화면도 같은 범위로 조정해 고정 버튼을 가리지 않는다. 문서와 브라우저 세션은 다시 생성하지 않는다.
- 창 이동 영역은 빈 탭 줄과 왼쪽 상단 여유 영역으로 제한해 상단 도구·문서 입력을 가로채지 않는다. 윈도우 관리·설정·커뮤니티 같은 별도 화면은 자체 상단 제어 공간을 유지한다.
- Windows 자료 사이드바에 중복되던 상단 여백도 제거한다.

## 검증 범위

모서리 사각형 계산, 탭 최소 폭과 압축, 숨긴 탭 아래 콘텐츠 높이·편집기 DOM 보존을 직접 검사한다. 실제 앱에서 상단 탭 좌표, 고정 박스의 위치와 클릭, 양쪽 사이드바 접기·폭 변경, 세 표시 모드, 분할별 도구·네이티브 페이지 좌표, 프로젝트 전환과 재시작 복원을 확인한다. CI와 배포용 macOS·Windows 설치본 검사는 `scripts/affected-checks.mjs`가 영향 범위를 선택한다.

로컬 검증: 모서리 계산·탭 압축·콘텐츠 높이 단위 검사 22개, web·demo 타입 검사와 앱 빌드가 통과했다. Electron 회귀 검사는 사이드바 9개·네이티브 브라우저 배치 2개·좁은 탭 2개·윈도우/재시작 3개로 총 16개가 통과했다. 미리보기 검사는 사이드바 폭 애니메이션과 네이티브 페이지 위치 갱신이 끝난 뒤 캡처하도록 기준을 명확히 했다. 로컬 환경에서 실제 macOS 전체화면 전환은 확인하지 않았으며, 해당 기존 OS 검사는 양쪽 배포 설치본 검증에 유지한다.

공개 결과는 검증 완료 후 기록한다. 실제 개인 계정 로그인·OS 권한 허용은 자동 검증 범위에 포함하지 않는다. Windows 설치 파일은 기존 배포 설정과 같이 미서명이며 macOS 앱은 Developer ID 서명·공증을 검증한다.
