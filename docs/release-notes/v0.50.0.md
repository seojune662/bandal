# v0.50.0 — AI 채팅·오브 입력창과 승인 흐름 개선

## 모델과 Effort

- 일반 채팅, 인앱 오브, 데스크톱 오브의 입력창에서 제공자·Model·Effort를 선택할 수 있습니다.
- 설정은 대화별로 저장하고 같은 대화를 연 창에 함께 반영합니다. 설치된 AI가 지원하는 Effort만 표시하며 응답·승인 처리 중에는 설정 변경을 제한합니다.
- 입력창, 말풍선, 도구 실행 기록과 승인 카드를 라이트·다크 테마에 맞게 정리했습니다. 오브 메뉴는 화면과 오브의 너비 안에 배치됩니다.

## 추가 메뉴와 생성 결과

- **+ 메뉴**에서 사진·파일, 과목 자료, 현재 브라우저 페이지, 데스크톱 화면, 설치된 스킬을 추가할 수 있습니다.
- 연결된 생성 스킬로 이미지·문서·PDF·스프레드시트·슬라이드 만들기를 요청할 수 있습니다. 생성된 파일을 확인한 뒤 열기·폴더 보기 카드를 표시합니다.
- 기존 AI 계정과 로컬 스킬을 사용합니다. 스킬이 요구하는 서비스·런타임의 지원 여부는 실제 실행 시 확인되며, 연결되지 않은 생성 기능은 안내와 함께 비활성화합니다.
- 전송 실패 시 초안과 첨부를 유지합니다. 파일 첨부를 비동기로 처리하고, 이미 가져온 파일은 재시도할 때 중복 복사하지 않습니다.

## 승인과 안정성

- 대기 중인 승인은 한 장씩 보여 주고 완료·거절·만료·취소 상태를 동기화합니다. 승인 전송에 실패하면 같은 카드에서 재시도할 수 있습니다.
- 이전 요청에서 선택한 허용 범위가 다음 요청에 남지 않도록 수정했습니다. 완료된 승인과 변경 내역은 작업 기록으로 정리합니다.
- 여러 창의 중복 전송, 시작 중 취소한 AI 프로세스의 뒤늦은 실행, 생성 파일 알림과 응답 완료 이벤트의 순서 충돌을 수정했습니다.
- 오브에서 Esc로 메뉴·파일 목록을 닫을 때 오브까지 닫히거나 목록이 다시 열리던 문제를 수정했습니다. 승인 요청이 입력 중인 포커스를 빼앗지 않도록 했습니다.

## 검증 범위

- 단위 테스트 **3,144개**, macOS 패키징 앱의 채팅·오브 E2E **6개**, 타입 검사·미사용 코드 검사·프로덕션 빌드를 통과했습니다.
- E2E는 실제 Electron 화면에 AI 응답을 주입해 설정 동기화, 첨부, 실패 복구, 승인 대기열·만료와 메뉴 동작을 검증합니다. 외부 AI 계정의 모든 모델·생성 스킬을 실사용 검증한 것은 아닙니다.

자세한 동작과 지원 범위: [AI 채팅 입력창과 승인](https://github.com/seojune662/bandal/blob/v0.50.0/docs/chat-composer.md).
