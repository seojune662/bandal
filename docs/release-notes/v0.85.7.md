# v0.85.7 — 노트 섹션 정리와 iPad 볼펜 표시

[v0.85.4](v0.85.4.md)·[v0.85.5](v0.85.5.md)·[v0.85.6](v0.85.6.md)는 공개 전 검사에서 멈춰 공개하지 않았다. 기능 변경은 같다. 자료 트리의 `노트/` 폴더는 처음 한 번 펼쳐진 상태로 보이고, 이번 범위의 브라우저 패키지 검사 3개 파일을 현재 새 탭 메뉴 이름(`브라우저 <주소>`)에 맞췄다. 같은 이름 변경이 남은 브라우저 검사 파일 6개(`browser`·`browserPerformance`·`browserPlacement`·`browserChrome`·`browserPasswordPrompt`·`featureLauncher`)는 v0.85.0 이후 선택된 적이 없으며 Windows 좁은 창·드래그 계측 전제까지 손봐야 해 이번 범위에 넣지 않았다.

자료 사이드바의 **노트** 섹션을 없앴다. 노트는 과목의 `노트/` 폴더에 있는 PDF이며 이제 **파일** 트리에서 다른 자료와 같은 행으로 보이고, 이름 변경·이동·삭제·공유도 같은 방식이다. 사이드바 머리글의 **새 노트 만들기** 버튼과 새 탭 메뉴의 **노트**로 만든다. 기존 화이트보드를 PDF 노트로 바꾸는 이전은 과목을 열 때 계속 실행되며 실패는 알림으로만 표시한다. 섹션에 있던 "이전 대기 중인 원본 열기" 목록은 제거했다. 쓰지 않던 옛 화이트보드 그룹 구성 요소와 스타일도 삭제했다.

iPad의 새 **볼펜** 도구가 남기는 필기(`style.fixedWidth`)를 데스크톱 표시·미리보기·PDF 내보내기에서 같은 일정 굵기로 그린다. 형광펜의 곱하기 혼합은 적용하지 않는다. 표시를 바꾸지 않는 기존 필기는 영향이 없다. iPad 측 반영은 [`a1945bd`](https://github.com/seojune662/bandal_iPad/commit/a1945bd)(빌드 46)이다.

## 검증 상태

- 로컬에서 타입 검사와 Vitest 572개 파일·4,627개 검사가 통과했다(9개 파일·59개 검사 제외). 잉크 기하·PDF 내보내기·자료 사이드바 검사를 포함한다.
- 사이드바 변경에 대한 Electron 화면 확인은 릴리스 워크플로의 macOS·Windows 패키지 검사 결과로 대신한다. 결과는 공개 후 아래에 기록한다.
- Apple 로그인·결제·실제 OAuth는 이 버전에서 변경하지 않았다. 외부 준비 상태는 [v0.85.3](v0.85.3.md)과 같다.

## 공개 결과

[v0.85.7 릴리스](https://github.com/seojune662/bandal/releases/tag/v0.85.7)는 2026-10-18 03:02 KST에 공개됐다. 앱 소스는 `933060b`이며 태그와 패키지 버전이 일치한다. macOS arm64·x64 DMG/ZIP, Windows 설치 EXE, 각 blockmap과 두 자동 업데이트 피드 등 12개 파일이 올라갔고, 두 피드의 버전은 `0.85.7`, Windows 설치 파일은 인증 없이 부분 다운로드(HTTP 206)가 가능했다. 파일별 SHA-256 재검증은 이번에 수행하지 않았다.

[릴리스 워크플로](https://github.com/seojune662/bandal/actions/runs/39054514637)에서 macOS·Windows 패키지 검사와 iPad 보조 프로그램 빌드가 모두 통과했다. 공개 전 로컬에서는 같은 검사 계획의 121개 중 118개가 통과했고, 가운데 클릭 백그라운드 탭·중첩 iframe 스크롤 검사는 로컬 환경에서만 실패했다.

웹은 [`bandal_web` 버전 동기화](https://github.com/seojune662/bandal_web/actions/runs/39056437103)가 `9f49e0b`를 main에 커밋했고, [공개 사이트](https://bandal.io)가 `v0.85.7`을 표시하는 것을 확인했다(HTTP 200). iPad 빌드 46(`a1945bd`)은 개발 기기에 설치돼 있으며 App Store·TestFlight 배포는 아니다.
