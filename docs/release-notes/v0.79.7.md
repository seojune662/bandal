# v0.79.7

- 두 손가락으로 앞뒤 이동한 직후 다시 쓸어도 입력을 놓치지 않습니다. 한 번의 긴 쓸기와 이어지는 관성 입력은 멈출 때 한 번만 이동합니다.
- 가로로 넓은 웹페이지, 중첩된 스크롤 영역과 오른쪽에서 왼쪽으로 읽는 페이지에서 가로 스크롤을 먼저 처리합니다. 스크롤 도중 가장자리에 도달하거나 방향을 바꿔도 같은 동작이 갑자기 앞뒤 이동으로 바뀌지 않습니다.
- 사이트가 직접 처리하는 휠 입력, 세로 스크롤과 확대·축소 입력을 가로채지 않습니다. 페이지의 스크롤 경계 제한도 존중합니다.
- 열린 페이지에서 바뀐 방문 기록과 설정을 새 제스처에 반영합니다. 늦게 도착한 이전 상태 응답이 최신 상태를 덮어쓰지 않도록 합니다.
- 탭을 숨기거나 창을 떠난 뒤 예약된 이동이 실행되는 것을 막습니다. 닫히거나 분리된 프레임의 요청도 무시합니다.
- 웹페이지 안의 iframe에서도 앞뒤 이동이 동작하도록 전용 입력 처리 코드의 실행 설정을 바로잡았습니다. 페이지와 iframe의 샌드박스·격리를 유지하며 Node 및 앱 API를 사이트에 노출하지 않습니다.
- 다른 출처의 중첩 iframe도 부모 페이지의 가로 스크롤과 스크롤 경계 제한을 먼저 확인합니다. 부모 스크롤이 끝에 도달한 같은 동작은 탐색으로 바뀌지 않으며, 부모 응답이 늦거나 프레임이 숨겨지면 이동을 취소합니다.

## 검증 범위

단위 검사는 문서·중첩·RTL 스크롤, 방향 반전, 긴 입력, 짧은 입력의 분리, 취소, 설정·기록 갱신, 비활성 탭과 프레임 수명 처리를 확인합니다. Electron 회귀는 신뢰된 휠 입력을 실제 프레임 preload와 IPC로 전달하여 같은 문서 및 새 문서의 앞뒤 연속 이동, 가로 스크롤 끝에서 다음 동작의 이동, 설정 변경, 숨은 탭과 다른 출처의 iframe을 검사합니다. iframe 검사는 Chromium hit testing을 거쳐 실제 자식 프레임의 입력 수신과 부모·자식 렌더러의 OS 샌드박스를 확인합니다. 바깥 페이지에 직접 입력하던 기존 iframe 검사는 이 검사로 대체했습니다.

macOS와 Windows 배포 앱에서는 전용 `browserSwipe`와 프레임 실행 설정에 연결된 브라우저 호환성 E2E를 실행합니다. macOS 설치 파일의 서명·공증, 모든 설치 파일의 업로드 무결성, 버전 일치와 양쪽 자동 업데이트 피드를 기존 배포 절차로 확인합니다. Windows 설치 파일은 기존 배포와 같이 미서명입니다.

자동 검사는 Chromium이 받는 신뢰된 휠 입력을 사용합니다. 실제 하드웨어의 두 손가락 접촉, OS의 관성·손가락 종료 신호와 기기별 감도는 직접 조작으로 확인하지 않았습니다.
