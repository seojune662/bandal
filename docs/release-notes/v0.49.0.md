# v0.49.0 — 슬라이드 이미지 복사와 필기·탭 사용성 개선

## 슬라이드 이미지 복사

- 슬라이드를 우클릭해 **이미지로 복사**를 선택하면 필기·텍스트 상자·삽입 이미지를 포함한 슬라이드 전체를 복사합니다. **원본만 이미지로 복사**도 지원합니다.
- 선택 테두리와 편집 도구는 제외하고, 슬라이드 비율을 유지한 가로 1,600px PNG로 복사합니다. 복사 중 중복 실행을 막고 실패하면 안내합니다.

## 나란히 필기와 탭 이동

- PDF·슬라이드와 노트를 나란히 열었을 때 연결 스크롤의 되튐과 상호 간섭을 줄였습니다. 반대쪽 화면을 직접 스크롤하면 새 입력을 반영하며, 연결을 끄면 대기 중인 동기화도 취소합니다.
- 슬라이드의 스크롤 위치와 배율을 탭별로 유지하고, 확대·축소와 패널 너비 변경 후에도 읽던 위치를 복원합니다.
- 탭이 많을 때 드래그로 탭 바 가장자리에 접근하면 자동으로 스크롤합니다. 탭 순서 변경·분할·합치기와 드래그 취소 동작을 보완했습니다.
- 슬라이드에서 키보드·붙여넣기 입력을 받는 포커스 처리를 개선하고, 어두운 테마에서도 흰 종이 위 필기 색상이 잘 보이도록 수정했습니다.

## 반응 속도와 안정성

- 슬라이드 렌더링의 동시 실행 수와 캐시 메모리를 제한하고, 화면 이동으로 불필요해진 대기 작업을 취소합니다. 확대 시 렌더링 크기도 제한합니다.
- 펜 입력 중 기존 획을 반복 계산하는 작업과 탭 배치 저장 횟수를 줄였습니다.
- 자료 파일 읽기를 비동기로 바꿔 파일을 읽는 동안 메인 프로세스가 멈추는 구간을 줄였습니다.

## 검증 범위

- 단위 테스트 **3,129개**, 관련 Electron E2E **33개**, 타입 검사·미사용 코드 검사·프로덕션 빌드를 통과했습니다. 선택 실행 항목인 LibreOffice 런타임 다운로드 E2E 1개는 제외했습니다.
- 100페이지 PDF·슬라이드와 여러 탭을 사용한 연결 스크롤, 많은 필기가 있는 상태의 펜 입력, 탭 이동·재시작 후 복원, 이미지 클립보드 복사와 앱 안 붙여넣기를 확인했습니다.
- macOS 무지개 대기 커서 자체는 이번 테스트에서 재현하지 못했습니다. 장시간 실사용의 모든 멈춤 현상이 해소되었다고 검증한 것은 아닙니다.
