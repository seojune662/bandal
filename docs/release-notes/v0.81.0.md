# v0.81.0 — ChatGPT·Claude 간편 연결

ChatGPT·Claude를 웹에서만 사용하던 사용자도 반달의 AI 설정이나 대화 화면에서 **연결하기**를 누르면 필요한 도구 설치와 계정 로그인을 이어서 진행할 수 있습니다. 설치 명령이나 Node.js를 직접 준비할 필요가 없습니다. 이미 설치·연결된 도구는 확인 후 바로 사용합니다.

로그인은 반달 안의 브라우저에서 진행합니다. 설치 준비, 로그인 대기, 실제 연결 확인을 구분해 보여주고, 계정 연결이 확인되면 대화를 시작할 수 있습니다. 연결 과정은 설정과 대화 화면에서 공유되어 화면을 이동해도 중복 설치·로그인이 시작되지 않습니다.

ChatGPT는 Codex를 통한 ChatGPT 계정 연결을 사용하며 이용 가능 여부와 한도는 계정 요금제에 따릅니다. Claude는 Pro·Max 또는 조직에서 제공한 Claude Code 이용 권한이 필요합니다. 브라우저의 대화 기록을 가져오는 기능은 아닙니다. 서비스가 반달 안의 로그인을 제한하는 경우에는 사용자가 외부 브라우저로 이어서 진행할 수 있습니다.

로그인 기능을 지원하지 않는 구버전은 공식 도구를 한 번 자동 업데이트한 뒤 다시 연결합니다. 로그인 페이지를 다시 열어도 같은 전용 탭을 사용하며, 완료·취소·실패 시 원래 화면으로 돌아옵니다. 과목을 아직 만들지 않은 사용자도 AI 설정에서 시작할 수 있습니다. 인증 주소와 코드는 방문 기록·작업 공간 복원 데이터에 저장하지 않습니다.

## 공식 동작 근거

- [Codex 설치](https://learn.chatgpt.com/docs/codex/cli): macOS·Windows 공식 독립 실행형 설치.
- [Codex 인증](https://learn.chatgpt.com/docs/auth) 및 [App Server](https://learn.chatgpt.com/docs/app-server): ChatGPT 브라우저 인증과 연결 상태 확인.
- [Claude Code 설치](https://code.claude.com/docs/en/setup) 및 [인증](https://code.claude.com/docs/en/authentication): 독립 실행형 설치와 Claude 구독 로그인.

## 검증 범위

설치·인증 단위 검사에서는 Node/npm 없는 설치, Windows의 구버전 npm 설치와 새 네이티브 설치 공존, 중복 실행·취소·재시도·시간 초과, 잘못된 인증 주소 거절, CLI 자격 증명 확인 전 완료 방지와 프로세스 정리를 확인합니다.

실제 Codex 0.158.0과 Claude 2.1.296을 임시 설정으로 실행하여 공식 로그인 주소·localhost 콜백 준비와 즉시 취소를 확인했습니다. Claude의 현재 `claude.com/cai/oauth/authorize` 주소도 이 과정에서 확인했습니다. 별도 Node 경로가 없는 Electron 실행 환경에서 한글·공백 경로의 브라우저 도우미, 인증 URL 전달과 임시 파일 정리를 검사합니다.

릴리스는 같은 커밋의 CI 성공 결과를 재사용하고 macOS·Windows 패키지의 영향 범위 E2E, macOS 서명·공증, 설치 파일 업로드 무결성과 자동 업데이트 피드 공개를 확인합니다. 화면 검사는 설치→반달 로그인 페이지→연결 확인, 설정·대화 상태 공유와 과목 생성 전 취소·실패·재시도를 포함합니다.

실제 사용자의 비밀번호·추가 인증·조직 계정 승인과 구독 권한은 해당 서비스의 로그인 화면에서 사용자가 완료해야 합니다. 개인 계정으로의 실제 인증 완료와 모든 외부 SSO 조합의 성공을 자동 검사 결과로 간주하지 않습니다.
