# 단어 수 예제 플러그인

현재 과목의 필기를 읽어 필기별 단어 수와 글자 수를 보여 주는 Bandal v1 플러그인입니다. 명령, 읽기 전용 과목·필기 API, 알림, 패널 메시지 통신을 한 번에 보여 주는 최소 예제입니다.

## 설치와 실행

1. Bandal 설정의 **플러그인** 화면에서 **폴더에서 설치**를 선택합니다.
2. 이 `word-count` 폴더를 고릅니다.
3. 표시된 권한을 검토해 승인하고 플러그인을 활성화합니다.
4. `현재 과목 필기 단어 수` 명령을 실행합니다.

패널의 **새로고침** 버튼은 `window.bandal.postMessage()`로 호스트에 요청을 보내고, 호스트는 새 결과를 `bandal.panel.post()`로 돌려줍니다. 패널은 고정 CSP를 따르므로 인라인 스크립트나 외부 리소스를 사용하지 않습니다.

플러그인 형식과 전체 API는 [플러그인 개발 문서](../../../docs/plugins.md)를 참고하세요.
